## 📌 题目描述
> （请在此处粘贴题目描述）

在一个 3×3 的网格中，1∼8 这 8 个数字和一个 `x` 恰好不重不漏地分布在这 3×3 的网格中。

例如：

```
1 2 3
x 4 6
7 5 8
```

在游戏过程中，可以把 `x` 与其上、下、左、右四个方向之一的数字交换（如果存在）。

我们的目的是通过交换，使得网格变为如下排列（称为正确排列）：

```
1 2 3
4 5 6
7 8 x
```

例如，示例中图形就可以通过让 `x` 先后与右、下、右三个方向的数字交换成功得到正确排列。

交换过程如下：

```
1 2 3   1 2 3   1 2 3   1 2 3
x 4 6   4 x 6   4 5 6   4 5 6
7 5 8   7 5 8   7 x 8   7 8 x
```

现在，给你一个初始网格，请你求出得到正确排列至少需要进行多少次交换。

#### 输入格式

输入占一行，将 3×3 的初始网格描绘出来。

例如，如果初始网格如下所示：

```
1 2 3 
x 4 6 
7 5 8 
```

则输入为：`1 2 3 x 4 6 7 5 8`

#### 输出格式

输出占一行，包含一个整数，表示最少交换次数。

如果不存在解决方案，则输出 −1。

#### 输入样例：

```
2 3 4 1 5 x 7 6 8
```

#### 输出样例

```
19
```

## 💻 代码实现
> my answer
```cpp
#include <iostream>
#include <queue>
#include <string>
#include <unordered_map>

using namespace std;

int bfs(string start) {
    string end = "12345678x"; // 定义终点状态
    queue<string> q; // 队列
    unordered_map<string, int> d; // 对于每个状态记录对应距离
    // 使用了距离数组可不用每次遍历一层。
    
    q.push(start);
    d[start] = 0;
    
    while (q.size()) {
        auto t = q.front();
        q.pop();
        
        int dis = d[t]; // 记录当前起始状态到当前状态的距离
        if (t == end) {
            return dis;
        }
        
        int dx[4] = {-1, 0, 1, 0}, dy[4] = {0, 1, 0, -1}; // x和y方向上的偏移
        
        int k = t.find('x'); // 找到 x 的位置，化为矩阵中的坐标
        int x = k / 3, y = k % 3;
        for (int i = 0; i < 4; i++) {
            int a = x + dx[i], b = y + dy[i];
            if (0 <= a && a < 3 && 0 <= b && b < 3) {
                swap(t[k], t[a * 3 + b]); // 更新状态
                if (!d.count(t)) {
                    // 这个状态没搜到过
                    d[t] = dis + 1; // 更新距离
                    q.push(t); // 将新的状态存到队列中去
                }
                swap(t[k], t[a * 3 + b]); // 恢复现场--由于可能还有其他方向的移动所以得恢复原样
            }
        }
    }
    return -1;
}

int main()
{
    string start;
    
    for (int i = 0; i < 9; i++) {
        char c;
        cin >> c;
        start += c;
    }
    
    cout << bfs(start) << endl;
    
    return 0;
}
```
- **时间复杂度**：$O(9!)$.
	- **总时间**：
	    *   BFS 会访问每一个可达状态恰好一次。
	    *   总时间 $\approx$ 状态数 $\times$ 单节点处理时间。
	    *   $T(n) \approx \frac{9!}{2} \times C$。
	    *   由于 $9$ 是固定常数，严格来说对于该特定问题是 $O(1)$。但作为算法通用分析（针对 $N \times N$ 拼图，此处 $N=3$），其复杂度随状态数指数级增长，即 **$O((N^2)!)$**。对于本题 $N=3$，就是 **$O(9!)$**。
- **空间复杂度**：$O(9!)$
	- **总空间**：
	    *   $S(n) \approx \text{状态数} \times \text{单个状态大小}$。
	    *   即 $O(9!)$。
	    *   具体数值估算：$181,440 \times (\text{string overhead} + 9 \text{ bytes} + \text{int})$。在现代计算机上，这大约占用几十 MB 的内存，完全在可接受范围内。
