> 🔗[886 - 求组合数Ⅱ](https://www.acwing.com/problem/content/888/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定 n 组询问，每组询问给定两个整数 a，b，请你输出 $C_b^a \,mod\,(10^9 + 7)$ 的值。

#### 输入格式

第一行包含整数 n。

接下来 n 行，每行包含一组 a 和 b。

#### 输出格式

共 n 行，每行输出一个询问的解。

#### 数据范围

$1 ≤ n ≤ 10000$,  
$1 ≤ b ≤ a ≤ 10^5$

#### 输入样例：

```
3
3 1
5 3
2 2
```

#### 输出样例：

```
3
10
1
```

## 💡 解题思路 
乘法逆元的作用：
对于任意整数 $a$ 而言，如果 $a$ 和 $p$ 互质，存在一个整数 $x$ 使得 $a \times x \equiv 1 \pmod{p}$ 则有：
$(b \div a) \bmod {p} = (b \div a * (a * x)) \bmod {p} = (b * x) \bmod {p}$ 。（$x$ 为 $a$ 在模 $p$ 意义下的乘法逆元，记作 $a^{-1}$）。
有了乘法逆元后，如果 $a, p$ 互质， $(b \div a) \bmod {p} = (b \bmod p) * (a ^ {-1} \bmod {p})$ 。
$$ 
\begin{align}
C{b \choose a} &=\frac{a!}{(a-b)!b!}\\
fact[i]\,&=i!\quad mod\quad10^9+7\\
infact[i]\,&=(i!)^{-1}\quad mod\quad10^9+7\, 其中infact[i]表示\,i!\,的逆元\\
C{b \choose a}&=fact[a]\quad *\quad infact[a-b] * \quad infact[b]
\end{align}
$$
注意**数据范围**：$1 ≤ n ≤ 10000， 1 ≤ b ≤ a ≤ 10^5$,
## 💻 代码实现
> my answer
```cpp
#include <iostream>

using namespace std;
typedef long long LL;
const int N = 100010, mod = 1e9 + 7;
int fact[N], infact[N];

int qmi(int a, int k, int p) {
    int res = 1;
    while (k) {
        if (k & 1) res = (LL)res * a % p;
        k >>= 1;
        a = (LL) a * a % p;
    }
    return res;
}

int main()
{
    int n;
    scanf("%d", &n);
    
    fact[0] = infact[0] = 1; // 0! 及其逆元 都是1
    for (int i = 1; i < N; i++) {
        fact[i] = (LL)fact[i-1] * i % mod;
        infact[i] = (LL)infact[i-1] * qmi(i, mod - 2, mod) % mod; //费马小定理 且mod是质数
    }
    
    while (n--) {
        int a, b;
        scanf("%d%d", &a, &b);
        // 两个 10^9 相乘 不会溢出 long long 而 3 个相乘 则会溢出 及时取模
        int res = 1LL * fact[a] * infact[b] % mod * infact[a-b] % mod;
        printf("%d\n", res);
    }
    
    return 0;
}
```
- **时间复杂度**：`O(nlogm)`
- **空间复杂度**：`O(1)`
