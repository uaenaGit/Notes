> 🔗[787 - 归并排序](https://www.acwing.com/problem/content/789/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定你一个长度为 n 的整数数列。

请你使用归并排序对这个数列按照从小到大进行排序。

并将排好序的数列按顺序输出。

#### 输入格式

输入共两行，第一行包含整数 n。

第二行包含 n 个整数（所有整数均在 $1∼10^9$ 范围内），表示整个数列。

#### 输出格式

输出共一行，包含 n 个整数，表示排好序的数列。

#### 数据范围

1≤n≤100000

#### 输入样例：

```
5
3 1 2 4 5
```

#### 输出样例：

```
1 2 3 4 5
```

## 💡 解题思路 
归并排序（基于分治）模板：
1. 确定分界点 $mid = (l + r) / 2$；
2. 递归排序左半区间`[l, mid]`和右半区间`[mid + 1, r]`。
3. 归并——合二为一

## 💻 代码实现
> my answer
```cpp
#include <iostream>

using namespace std;

const int N = 100010;
int a[N], tmp[N]; // tmp是归并时使用到的中间数组

void mergeSort(int a[], int l, int r) {
    if (l >= r) return; // 区间没有元素或只有一个元素 区间已然有序
    int mid = (l + r) >> 1; // 分界点
    
    // 递归排序
    mergeSort(a, l, mid), mergeSort(a, mid + 1, r);
    
    int k = 0, i = l, j = mid + 1;
    // 归并
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else tmp[k++] = a[j++];
    }
    
    // 扫尾
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    
    // 复原
    for (int i = l, j = 0; i <= r; i++, j++) { 
    // 注意 i 一定是从 l（左端点）开始而不是从0开始 因为归并右半区间的时候就不是0了
        a[i] = tmp[j];
    }
}

int main()
{
    int n;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d", &a[i]);
    
    // 归并排序
    mergeSort(a, 0, n - 1);
    
    for (int i = 0; i < n; i++) {
        printf("%d", a[i]);
        printf(i < n - 1 ? " " : "\n"); // 行末没有空格
    }
    
    return 0;
}
```
- **时间复杂度**：`O(nlogn)`。归并复杂度是$O(n)$，最多$\log n$层。
- **空间复杂度**：`O(n)`。`tmp`数组大小
