> 🔗[877 - 扩展欧几里得算法](https://www.acwing.com/problem/content/879/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定 n 对正整数 $a_i, b_i$，对于每对数，求出一组 $x_i, y_i$，使其满足 $a_i × x_i + b_i × y_i = gcd(a_i, b_i)$。

#### 输入格式

第一行包含整数 n。

接下来 n 行，每行包含两个整数 $a_i, b_i$。

#### 输出格式

输出共 n 行，对于每组 $a_i, b_i$，求出一组满足条件的 $x_i, y_i$，每组结果占一行。

本题答案不唯一，输出任意满足条件的 $x_i, y_i$ 均可。

#### 数据范围

$1 ≤ n ≤ 10^5$,  
$1 ≤ a_i, b_i ≤ 2×10^9$

#### 输入样例：

```
2
4 6
8 18
```

#### 输出样例：

```
-1 1
-2 1
```

## 💡 解题思路 
裴蜀定理：对于任意正整数 $a, b$，一定存在非零整数 $x, y$（非全 $0$），使得 $a * x + b * y = gcd (a, b)$。
怎样求系数 $x, y$？
由于 $(a, b) = (b, a \,mod\, b)$ （小括号表示最大公约数 ）
当 $b == 0$ 时，$(a, 0) = a$ 要使 $a * x + b * y = a$ 则 $x = 1, y = 0$；
当 $b \,!= 0$ 时，因为 $b * y + (a \,mod\, b) * x = d$，则 $b * y + (a - \lfloor\frac{a}{b}\rfloor * b) * x = d$，即 $a * x + b * (y - \lfloor \frac{a}{b}\rfloor *x) = d$。所以 `a` 系数 `x`不变，`b`系数变为 $y - \lfloor \frac{a}{b} \rfloor * x$。 
## 💻 代码实现
> my answer
```cpp
#include <iostream>

using namespace std;

int exgcd(int a, int b, int &x, int &y) {
    if (!b) { // b为0 最小公约数为a
        x = 1, y = 0; // a * 1 + b * 0 = a, 所以 x = 1, y = 0
        return a;
    }
    int d = exgcd(b, a % b, y, x); // 递归求解a和b的系数 由于b和a%b交换了所以x和y交换
    y -= a / b * x; // 更新b的系数 a的系数保持不变
    return d;
}


int main()
{
    int n;
    scanf("%d", &n);
    
    while (n--) {
        int a, b, x, y;
        scanf("%d%d", &a, &b);
        
        exgcd(a, b, x, y); // x是a的系数，y是b的系数
        printf("%d %d\n", x, y);
    }
    
    
    return 0;
}
```
