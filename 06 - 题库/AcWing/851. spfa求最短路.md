> 🔗[851 - spfa求最短路](https://www.acwing.com/problem/content/853/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定一个 n 个点 m 条边的有向图，图中可能存在重边和自环， **边权可能为负数**。

请你求出 1 号点到 n 号点的最短距离，如果无法从 1 号点走到 n 号点，则输出 `impossible`。

数据保证不存在负权回路。

#### 输入格式

第一行包含整数 n 和 m。

接下来 m 行每行包含三个整数 x,y,z，表示存在一条从点 x 到点 y 的有向边，边长为 z。

#### 输出格式

输出一个整数，表示 1 号点到 n 号点的最短距离。

如果路径不存在，则输出 `impossible`。

#### 数据范围

$1 ≤ n , m ≤ 10^5$,  
图中涉及边长绝对值均不超过 10000。

#### 输入样例：

```
3 3
1 2 5
2 3 -3
1 3 4
```

#### 输出样例：

```
2
```

## 💡 解题思路 
**SPFA 算法**
SPFA 是对 Bellman-Ford 算法中 `dist[b] = min(dist[b], dist[a] + w)` 这一步的优化：
- 核心思想：如果 `dist[b]` 被更新，那么一定是 `dist[a]` 变小才会触发 `dist[b]` 的更新。

```text
queue <- 1  // 起点入队
// queue 存储等待用来更新其他点的节点
while queue 不为空:
    ① t <- q.front()  // 取出队头
      q.pop()
    ② 更新 t 的所有出边 t --w--> b:
        if dist[b] 可被更新:
            dist[b] = dist[t] + w
            queue <- b  // 将更新后的节点 b 入队，用于后续松弛操作
```

注意 `spfa` 与 `bellman_ford` 算法判断能否到达的区别
1. `bellman_ford` 会枚举所有边 所以可能存在一点 该点并不在起点到终点的路径上 但是该点到终点有一条负权边 这也使得终点的距离被更新 故不能直接使用相等来判断 得用 `dist[n] > 0x3f3f3f3f / 2 `来判断
2. `spfa` 是将能联通的点加入队列 **不能到达的点即使该点到终点有负权回路也不会被更新** 所以 `dist[n] == 0x3f3f3f3f` 来判断能否到达

## 💻 代码实现
> my answer
```cpp
#include <iostream>
#include <queue>
#include <vector>
#include <cstring>

using namespace std;
const int N = 100010; // 用邻接表来存储
int n, m;
typedef pair<int, int> PII;
vector<vector<PII>> g(N);
int dist[N]; // 距离数组
bool st[N]; // 存储当前点是否在队列中 防止存储重复点

void spfa()
{
    memset(dist, 0x3f, sizeof(dist));
    dist[1] = 0; // 起点距离初始化
    
    queue<int> q;
    q.push(1); // 将起点放入队列
    st[1] = true; // 加入队列
    
    while(q.size()) {
        int t = q.front();
        q.pop();
        
        st[t] = false; // 出队就将其置为false
        
        // 遍历以t为起点的出边
        for (auto &[j, w] : g[t]) {
            if (dist[j] > dist[t] + w) {
                // 更新距离
                dist[j] = dist[t] + w;
                if (!st[j]) {
                    q.push(j); // 只有这个点不在队列中才加入队列
                    st[j] = true; // 加入队列
                }
            }
        }
    }
    if (dist[n] == 0x3f3f3f3f) puts("impossible");
    else printf("%d\n", dist[n]);
}

int main()
{
    scanf("%d%d", &n, &m);
    while (m--) {
        int a, b, w;
        scanf("%d%d%d", &a, &b, &w);
        g[a].push_back({b, w});
    }
    
    spfa();
    
    return 0;
}
```
- **时间复杂度**：$O(n * m)$。一般 $O(m)$，最坏 $O(n*m)$。
- **空间复杂度**：$O(m)$
