> 🔗[868 - 筛质数](https://www.acwing.com/problem/content/870/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定一个正整数 n，请你求出 1∼n 中质数的个数。

#### 输入格式

共一行，包含整数 n。

#### 输出格式

共一行，包含一个整数，表示 1∼n 中质数的个数。

#### 数据范围

$1 ≤ n ≤ 10^6$

#### 输入样例：

```
8
```

#### 输出样例：

```
4
```

## 💡 解题思路 
筛质数：
算数基本定理：$1 \sim n$ 中有 $\frac {n} {\log n}$ 个质数。

## 💻 代码实现
> my answer
```cpp
#include <iostream>

using namespace std;
const int N = 1e6 + 10;
int a[N];
bool st[N]; // 存储是否被筛过
int primes[N], cnt; // primes存储素数

//埃氏筛法
void get_primes(int n)
{
    for(int i = 2; i <= n; i ++)
    {
        if(st[i]) continue; //表明该数已经被筛过
        primes[cnt++] = i; //将质数存储进primes数组
        for(int j = i + i; j <= n; j += i)
            st[j] = true; //每次只用筛质数的倍数  复杂度为O(nloglogn)近乎线性级别
    }
}

int main()
{
    int n; cin >> n;
    get_primes(n);
    
    cout << cnt << endl;
    return 0;
}
```
- **时间复杂度**：`O(nloglogn)`
- **空间复杂度**：`O(1)`

> to optimize

线性筛法：保证 `n` 只会被其最小质因子筛掉
1. `i % primes[j] == 0` ：`primes[j]` 一定是`i` 的最小质因子，`primes[j]` 一定是`primes[j] * i`的最小质因子。
2. `i % primes[j] != 0` ：`primes[j]` 一定小于 `i` 的最小质因子，`primes[j]` 也一定是 `primes[i] * j`的最小质因子。
![image.png](https://cdn.jsdelivr.net/gh/uaenaGit/image-host@main/images20260309211103970.png)

```cpp
#include <iostream>

using namespace std;
const int N = 1e6 + 10;
int a[N];
bool st[N]; // 存储是否被筛过
int primes[N], cnt; // primes存储素数

//线性筛法
void get_primes(int n)
{
    for(int i = 2; i <= n; i ++)
    {
        if(!st[i]) primes[cnt++] = i; // 是质数 加入primes数组
		
		// 变形得到primes[j]*i<=n 把大于n的合数筛掉没有意义 所以primes[j]<=n/i;
        for(int j = 0; primes[j] <= n / i; j ++)
        {
            st[primes[j] * i] = true; // 每次用i的最小质因子primes[j]筛掉 保证每个数只被筛一次
            
			// 如果不break 则j++ 会用primes[j+1]筛掉i 就不能保证是最小质因子筛掉的也不能保证合数只被筛掉一次 所以要break
			if(i % primes[j] == 0) break;
        }
    }
}

int main()
{
    int n; cin >> n;
    get_primes(n);
    
    cout << cnt << endl;
    return 0;
}
```
- **时间复杂度**：`O(n)`
- **空间复杂度**：`O(1)`
