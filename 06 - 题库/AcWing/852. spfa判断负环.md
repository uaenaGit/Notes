> 🔗[852 - spfa判断负环](https://www.acwing.com/problem/content/854/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定一个 n 个点 m 条边的有向图，图中可能存在重边和自环， **边权可能为负数**。

请你判断图中是否存在负权回路。

#### 输入格式

第一行包含整数 n 和 m。

接下来 m 行每行包含三个整数 x,y,z，表示存在一条从点 x 到点 y 的有向边，边长为 z。

#### 输出格式

如果图中**存在**负权回路，则输出 `Yes`，否则输出 `No`。

#### 数据范围

1≤n≤2000,  
1≤m≤10000,  
图中涉及边长绝对值均不超过 10000。

#### 输入样例：

```
3 3
1 2 -1
2 3 4
3 1 -4
```

#### 输出样例：

```
Yes
```

## 💡 解题思路 
SPFA 是对 Bellman-Ford 算法中 `dist[b] = min(dist[b], dist[a] + w)` 这一步的优化：
- 核心思想：如果 `dist[b]` 被更新，那么一定是 `dist[a]` 变小才会触发 `dist[b]` 的更新。

```text
queue <- 1  // 起点入队
// queue 存储等待用来更新其他点的节点
while queue 不为空:
    ① t <- q.front()  // 取出队头
      q.pop()
    ② 更新 t 的所有出边 t --w--> b:
        if dist[b] 可被更新:
            dist[b] = dist[t] + w
            queue <- b  // 将更新后的节点 b 入队，用于后续松弛操作
```

**负环判断**
- **定义**：负环即存在一条回路，其边权之和为负值。
- **变量含义**：
  - `dist[x]`：代表从起点到 `x` 的最短距离
  - `cnt[x]`：代表走到 `x` 的最短路径所包含的边数
- **判断逻辑**：
  当更新 `dist[x] = dist[t] + w` 时，同时更新 `cnt[x] = cnt[t] + 1`。
  若 `cnt[x] >= n`（`n` 为图中总节点数），则表示走到 `x` 存在一条包含超过 `n` 条边的最短路径。
  根据**抽屉原理**：`n` 条边的路径至少经过 `n+1` 个节点，而图中只有 `n` 个节点，因此必然存在重复节点，即存在**负环**。
## 💻 代码实现
> my answer
```cpp
#include <iostream>
#include <queue>
#include <vector>

using namespace std;
const int N = 2010;
int n, m;
typedef pair<int, int> PII;
int dist[N], cnt[N];
bool st[N];
vector<vector<PII>> g(N); // 邻接矩阵存储图

bool spfa()
{
    // 不用初始化dist数组 因为存在负环 dist没有任何意义
    queue<int> q;
    for (int i = 1; i <= n; i++) {
        st[i] = true;
        q.push(i); // 得把所有点加入队列 否则有可能从某一点走不到负环
    }
    
    while (q.size())
    {
        int t = q.front();
        q.pop();
        
        st[t] = false; // 出队 置为false
        
        // 遍历以 t 为起点的出边
        for (auto &[j, w] : g[t]) {
            if (dist[j] > dist[t] + w) { // 从负边出现时开始统计的
                dist[j] = dist[t] + w;
                cnt[j] = cnt[t] + 1; // 更新 cnt节点
                
                if (cnt[j] >= n) { 
                // 由抽屉原理 被更新了n次至少n + 1个点 但是只有n个点所以存在负环
                    return true;
                }
                if (!st[j]) { 
                    q.push(j); // 加入队列
                    st[j] = true; // 置为true 表示加入队列
                }
            }
        }
    }
    return false;
}

int main ()
{
    scanf("%d%d", &n, &m);
    while (m--) {
        int a, b, w;
        scanf("%d%d%d", &a, &b, &w);
        g[a].push_back({b, w});
    }
    
    if (spfa()) puts("Yes");
    else puts("No");
    
    return 0;
}
```
- **时间复杂度**：$O(m 或 n * m)$
SPFA 检测负环的时间复杂度分两种情况：
（1）平均 / 理想情况
大多数场景下，每个节点入队次数很少，时间复杂度接近 **`O(m)`**（`m` 为边数），这也是 SPFA 作为 Bellman-Ford 优化的核心优势。
（2）最坏情况
如果图中存在构造性的特殊结构（比如链式负权边），每个节点可能入队 `n` 次，此时时间复杂度退化为 **`O(n × m)`**（与 Bellman-Ford 一致）。
- **空间复杂度**：$O(n + m)$
空间复杂度主要由存储图的结构、距离数组、计数数组、状态数组和队列决定：
- **邻接表 `g`**：存储 `m` 条边，空间为 `O(m)`
- **数组 `dist`/`cnt`/`st`**：每个数组大小为 `n`，总空间 `O(n)`
- **队列 `q`**：最坏情况下存储所有节点，空间 `O(n)`
