> 🔗[854 - Floyd求最短路](https://www.acwing.com/problem/content/856/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定一个 n 个点 m 条边的有向图，图中可能存在重边和自环，边权可能为负数。

再给定 k 个询问，每个询问包含两个整数 x 和 y，表示查询从点 x 到点 y 的最短距离，如果路径不存在，则输出 `impossible`。

数据保证图中不存在负权回路。

#### 输入格式

第一行包含三个整数 n,m,k。

接下来 m 行，每行包含三个整数 x,y,z，表示存在一条从点 x 到点 y 的有向边，边长为 z。

接下来 k 行，每行包含两个整数 x,y，表示询问点 x 到点 y 的最短距离。

#### 输出格式

共 k 行，每行输出一个整数，表示询问的结果，若询问两点间不存在路径，则输出 `impossible`。

#### 数据范围

1≤n≤200,  
$1 ≤ k ≤ n^2$  
1≤m≤20000,  
图中涉及边长绝对值均不超过 10000。

#### 输入样例：

```
3 3 2
1 2 1
2 3 2
1 3 1
2 1
1 3
```

#### 输出样例：

```
impossible
1
```

## 💡 解题思路 
`Floyd` 算法:
核心代码
```cpp
// d[i, j] 存储所有边的权值，初始化时 d[i][i] = 0，不可达为无穷大
for (int k = 1; k <= n; k++)  // 注：必须先循环 k（中间点）
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
// 最终 d[i][j] 表示从 i 到 j 的最短路径长度
```

核心思想（动态规划视角）
- **状态定义**：`d[k, i, j]` 表示从 `i` 点出发，**只经过 1~k 这些中间点**，走到 `j` 点的最短距离。
- **状态转移**：
  ```text
  d[k, i, j] = min(
      d[k-1, i, j],          // 不经过 k 点
      d[k-1, i, k] + d[k-1, k, j]  // 经过 k 点：i -> ... -> k -> ... -> j
  )
  ```
  其中：
  - `d[k-1, i, k]`：从 `i` 到 `k`，只经过 1~k-1 这些点的最短距离
  - `d[k-1, k, j]`：从 `k` 到 `j`，只经过 1~k-1 这些点的最短距离

注意事项
- Floyd 算法可以处理**负权边**，但**无法处理负权回路**（负环会导致最短路径不存在）。
- 时间复杂度：$O(n^3)$，空间复杂度：$O(n^2)$（滚动数组优化后）。

## 💻 代码实现
> my answer
```cpp
#include <iostream>

using namespace std;
const int N = 210, INF = 1e9;
int d[N][N];
int n, m, k;

// floyd算法：允许有负权边 不允许有负权回路
void floyd()
{
    for (int k = 1; k <= n; k++) {
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n; j++) {
                d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
            }
        }
    }
}

int main()
{
    scanf("%d%d%d", &n, &m, &k);
    
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (i == j) d[i][j] = 0; // i 到 i距离为0 预防自环
            else d[i][j] = INF;
        }
    }
    
    while (m--) {
        int a, b, w;
        scanf("%d%d%d", &a, &b, &w);
        d[a][b] = min(d[a][b], w); // 可能存在重边 记录最小的那条就行
    }
    
    floyd();
    
    while (k--)
    {
        int a, b;
        scanf("%d%d", &a, &b);
        if (d[a][b] > INF / 2) puts("impossible"); // 与bellman_ford类似
        else printf("%d\n", d[a][b]);
    }
    
    return 0;
}
```
- **时间复杂度**：$O(n^3)$
- **空间复杂度**：$O(n^2)$
