> 🔗[858 - Prim算法求最小生成树](https://www.acwing.com/problem/content/860/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定一个 n 个点 m 条边的无向图，图中可能存在重边和自环，边权可能为负数。

求最小生成树的树边权重之和，如果最小生成树不存在则输出 `impossible`。

给定一张边带权的无向图 G=(V,E)，其中 V 表示图中点的集合，E 表示图中边的集合，n=|V|，m=|E|。

由 V 中的全部 n 个顶点和 E 中 n−1 条边构成的无向连通子图被称为 G 的一棵生成树，其中边的权值之和最小的生成树被称为无向图 G 的最小生成树。

#### 输入格式

第一行包含两个整数 n 和 m。

接下来 m 行，每行包含三个整数 u,v,w，表示点 u 和点 v 之间存在一条权值为 w 的边。

#### 输出格式

共一行，若存在最小生成树，则输出一个整数，表示最小生成树的树边权重之和，如果最小生成树不存在则输出 `impossible`。

#### 数据范围

1≤n≤500,  
$1 ≤ m ≤ 10^5$,  
图中涉及边的边权的绝对值均不超过 10000。

#### 输入样例：

```
4 5
1 2 1
1 3 2
1 4 3
2 3 2
3 4 4
```

#### 输出样例：

```
6
```

## 💡 解题思路
朴素 Prim 算法（最小生成树）

- **适用范围**：最小生成树中**正边和负边都可以处理**。
核心步骤
```text
dist[i] <- +∞  // 初始化所有点到生成树集合的距离为无穷大

for (i = 0; i < n; i++)  // 迭代 n 次（Dijkstra 迭代 n-1 次，因为 Dijkstra 先选了起点）
    t <- 找到集合外距离最近的点
    用 t 更新其他点到**集合**的距离（区别：Dijkstra 是更新到**起点**的距离）
    st[t] = true  // 将 t 加入生成树集合
```

关键说明
- **dist 数组含义**：`dist[i]` 表示点 `i` 到当前已生成的最小生成树集合的最短距离。
- **与 Dijkstra 的区别**：
  - Prim：更新的是点到**生成树集合**的距离，目标是构建最小生成树。
  - Dijkstra：更新的是点到**起点**的距离，目标是求单源最短路径。
- **迭代次数**：Prim 迭代 `n` 次（逐个将所有点加入集合）；Dijkstra 迭代 `n-1` 次（起点已预先选定）。

## 💻 代码实现
> my answer
```cpp
#include <iostream>
#include <cstring>

using namespace std;
// 0x3f3f3f3f = 1,061,109,567 > 1e9 但 < 2147483647(int)
const int N = 510, INF = 0x3f3f3f3f; // 邻接矩阵存储
int g[N][N];
int dist[N]; // 距离数组 初始为正无穷 存储其他点到当前最小生成数的距离
bool st[N]; // 存储节点是否在生成树中
int n, m;

int prim()
{
    memset(dist, 0x3f, sizeof(dist)); // 距离数组初始化
    int res = 0;
    for (int i = 0; i < n; i++) // 一定循环n次
    {
        int t = -1;
        for (int j = 1; j <= n; j++) {
            if (!st[j] && (t == -1 || dist[t] > dist[j])) {
                t = j; // 找到距离当前生成数集合最小的点
            }
        }
        
        // 注意不能是第一个点 因为第一个点的dist值一定是无穷大
        if (i && dist[t] == INF) return INF; // 若距生成树最近的点的距离为正无穷大 则不存在最小生成树
        
        // 先更新res 再用t去更新其他距离 否则可能出现负的自环将自身dist更新 
        if (i) res += dist[t]; 
        st[t] = true; // 加入最小生成树集合
        
        for (int j = 1; j <= n; j++) {
            dist[j] = min(dist[j], g[t][j]); // 注意与dijkstra不一样
        }
    }
    
    return res;
}

int main()
{
    scanf("%d%d", &n, &m);
    
    // 邻接矩阵初始化
    memset(g, 0x3f, sizeof(g));
    
    while (m--) {
        int a, b, w;
        scanf("%d%d%d", &a, &b, &w);
        g[a][b] = g[b][a] = min(g[a][b], w); // 无向图存储 可能有重复边
    }
    
    int res = prim();
    if (res == INF) puts("impossible");
    else printf("%d\n", res);
    
    return 0;
}

```
- **时间复杂度**：$O(n^2 + m)$
- **空间复杂度**：$O(n^2)$
