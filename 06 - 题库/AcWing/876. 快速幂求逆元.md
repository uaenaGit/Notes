> 🔗[876 - 快速幂求逆元](https://www.acwing.com/problem/content/878/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定 n 组 $a_i, p_i$，其中 $p_i$ 是质数，求 $a_i$ 模 $p_i$ 的乘法逆元，若逆元不存在则输出 `impossible`。

**注意**：请返回在 0∼p−1 之间的逆元。

##### 乘法逆元的定义

> 若整数 b，m 互质，并且对于任意的整数 a，如果满足 $b | a$，则存在一个整数 x，使得 $\frac{a} {b} ≡ a × x (mod\, m)$，则称 x 为 b 的模 m 乘法逆元，记为 $b^{−1}(mod \,m)$。
> b 存在乘法逆元的充要条件是 b 与模数 m 互质。当模数 m 为质数时，$b^{m−2}$ 即为 b 的乘法逆元。

#### 输入格式

第一行包含整数 n。

接下来 n 行，每行包含一个数组 $a_i, p_i$，数据保证 $p_i$ 是质数。

#### 输出格式

输出共 n 行，每组数据输出一个结果，每个结果占一行。

若 $a_i$ 模 $p_i$ 的乘法逆元存在，则输出一个整数，表示逆元，否则输出 `impossible`。

#### 数据范围

$1 ≤ n ≤ 10^5$,  
$1 ≤ a_i, p_i ≤ 2∗10^9$

#### 输入样例：

```
3
4 3
8 5
6 3
```

#### 输出样例：

```
1
2
impossible
```

## 💡 解题思路 
费马小定理：
如果 $p$ 是一个质数，而**整数 $a$ 不是 $p$ 的倍数**，则有 $a ^ {p - 1} \equiv 1 \pmod {p}$  。
给定一组 $a, p$，求 $a \bmod p$ 的逆元，只有当 $a$ 不是 $p$ 的倍数时才有解。 且由费马小定理得：
逆元为 $a^{p - 2}$。因为 $a^{p - 1} = a * a^{p - 2} \equiv 1\pmod{p}$。

## 💻 代码实现
> my answer
```cpp
#include <iostream>

using namespace std;
typedef long long LL;

/*
要求p必须是素数 若p不是素数 则不能使用费马小定理
可以使用扩展欧几里得算法求逆元
a * b ≡ 1 (mod p) 即 a * b = k * p +1
a * b + k' * p = 1(其中k'=-k) 等价于 a * x + p * y = 1(其中 x = b, y = k')
int d = exgcd(a, b, x, y)  if d==1 输出 (x % mod + mod ) % mod 否则 不存在逆元
*/

// 快速幂模版
int qmi(int a, int k, int p) {
    LL res = 1;
    while (k) {
        if (k & 1) res = (LL) res * a % p;
        k >>= 1;
        a = (LL) a * a % p;
    }
    return res;
}


int main()
{
    int n;
    scanf("%d", &n);
    
    while (n--) {
        int a, p;
        scanf("%d%d", &a, &p);
        
        int res = qmi(a, p-2, p);
        if (a % p) printf("%d\n", res);
        else puts("impossible");
    }
    
    return 0;
}
```
- **时间复杂度**：`O(logn)`
- **空间复杂度**：`O(1)`

> to optimize

使用扩展欧几里得算法求逆元。（当 $p$ 不是质数时也可以使用）。

**1. 核心原理**

==目标==
求 $a$ 在模 $m$ 意义下的逆元 $x$，即满足：
$$
a \cdot x \equiv 1 \pmod m
$$

==转化为线性方程==
上述同余方程等价于存在一个整数 $y$，使得：
$$
a \cdot x + m \cdot y = 1
$$
这是一个典型的**二元一次不定方程**（贝祖等式）。

==裴蜀定理（Bézout's identity）==
方程 $ax + by = \gcd(a, b)$ 一定有整数解。
*   如果 $\gcd(a, m) = 1$，则方程 $ax + my = 1$ 有解，这个 $x$ 就是 $a$ 的逆元。
*   如果 $\gcd(a, m) \neq 1$，则逆元不存在。

**扩展欧几里得算法**的作用就是求出这组特解 $(x, y)$。

---

**2. 算法推导过程**

欧几里得算法（辗转相除法）的核心是：
$$
\gcd(a, b) = \gcd(b, a \bmod b)
$$

假设我们已经求出了下一层递归的解 $x', y'$，满足：
$$
b \cdot x' + (a \bmod b) \cdot y' = \gcd(b, a \bmod b) = \gcd(a, b)
$$

我们需要利用 $x', y'$ 推导出当前层 $x, y$，使得：
$$
a \cdot x + b \cdot y = \gcd(a, b)
$$

将 $a \bmod b$ 展开为 $a - \lfloor \frac{a}{b} \rfloor \cdot b$，代入上式：
$$
\begin{aligned}
b \cdot x' + (a - \lfloor \frac{a}{b} \rfloor \cdot b) \cdot y' &= \gcd(a, b) \\
b \cdot x' + a \cdot y' - \lfloor \frac{a}{b} \rfloor \cdot b \cdot y' &= \gcd(a, b) \\
a \cdot y' + b \cdot (x' - \lfloor \frac{a}{b} \rfloor \cdot y') &= \gcd(a, b)
\end{aligned}
$$

对比系数 $a \cdot x + b \cdot y$，可得递推关系：
$$
\begin{cases}
x = y' \\
y = x' - \lfloor \frac{a}{b} \rfloor \cdot y'
\end{cases}
$$

**边界条件**：
当 $b = 0$ 时，$\gcd(a, 0) = a$。此时方程为 $a \cdot x + 0 \cdot y = a$，显然解为 $x = 1, y = 0$。

---
```cpp
#include <iostream>

using namespace std;

typedef long long ll;

/**
 * 扩展欧几里得算法
 * 求解 ax + by = gcd(a, b) 的一组整数解 (x, y)
 * 
 * @param a 系数 a
 * @param b 系数 b
 * @param x 引用传递，返回解 x
 * @param y 引用传递，返回解 y
 * @return 返回 gcd(a, b)
 */
ll exgcd(ll a, ll b, ll &x, ll &y) {
    if (b == 0) {
        // 边界条件：gcd(a, 0) = a
        // 此时方程为 a*x + 0*y = a => x = 1, y = 0 (y可以是任意值，通常取0)
        x = 1;
        y = 0;
        return a;
    }
    
    // 递归调用，注意这里交换了 x 和 y 的位置
    // 递归返回后，x 存储的是上一层的 y', y 存储的是上一层的 x'
    ll d = exgcd(b, a % b, y, x);
    
    // 根据推导公式更新 y: y = x' - (a/b)*y'
    // 因为递归时交换了变量，此时 x 已经是 y'，y 已经是 x'
    // 所以公式变为：y = y - (a/b)*x
    y -= (a / b) * x;
    
    return d;
}

/**
 * 求 a 在模 m 意义下的乘法逆元
 * 即求解 x 使得 (a * x) % m == 1
 * 
 * @param a 底数
 * @param m 模数
 * @return 如果逆元存在，返回最小正整数逆元；否则返回 -1
 */
ll modInverse(ll a, ll m) {
    ll x, y;
    ll g = exgcd(a, m, x, y);
    
    // 只有当 gcd(a, m) == 1 时，逆元才存在
    if (g != 1) {
        return -1; 
    }
    
    // exgcd 求出的 x 可能是负数，需要调整为 [0, m-1] 范围内的正整数
    // C++ 中 % 运算对负数的结果取决于实现，通常是负数或零
    // (x % m + m) % m 确保结果一定是正数
    return (x % m + m) % m;
}

int main() {
    // 示例 1: 模数是素数
    ll a1 = 3, m1 = 11;
    ll inv1 = modInverse(a1, m1);
    if (inv1 != -1) {
        cout << a1 << " 模 " << m1 << " 的逆元是: " << inv1 << endl;
        cout << "验证: " << a1 << " * " << inv1 << " = " << (a1 * inv1) % m1 << " (应为 1)" << endl;
    } else {
        cout << a1 << " 模 " << m1 << " 的逆元不存在" << endl;
    }

    cout << "-----------------" << endl;

    // 示例 2: 模数是合数 (费马小定理不可用，必须用 ExGCD)
    // 求 3 在模 10 下的逆元 (gcd(3, 10)=1, 存在)
    ll a2 = 3, m2 = 10;
    ll inv2 = modInverse(a2, m2);
    if (inv2 != -1) {
        cout << a2 << " 模 " << m2 << " 的逆元是: " << inv2 << endl;
        cout << "验证: " << a2 << " * " << inv2 << " = " << (a2 * inv2) % m2 << " (应为 1)" << endl;
    } else {
        cout << a2 << " 模 " << m2 << " 的逆元不存在" << endl;
    }

    cout << "-----------------" << endl;

    // 示例 3: 逆元不存在的情况 (gcd != 1)
    // 求 2 在模 4 下的逆元 (gcd(2, 4)=2 != 1, 不存在)
    ll a3 = 2, m3 = 4;
    ll inv3 = modInverse(a3, m3);
    if (inv3 != -1) {
        cout << a3 << " 模 " << m3 << " 的逆元是: " << inv3 << endl;
    } else {
        cout << a3 << " 模 " << m3 << " 的逆元不存在 (gcd != 1)" << endl;
    }

    return 0;
}
```
- **时间复杂度**：`O(logm)`
**结论**：无论哪种情况，**每经过两次迭代（或两层递归），较小的那个数至少变为原来的一半**。
**计算总次数**
假设初始值为 $m$。
- 2 次迭代后，数值 $\le m / 2$
- 4 次迭代后，数值 $\le m / 4 = m / 2^2$
- $2k$ 次迭代后，数值 $\le m / 2^k$

算法在数值变为 0 时停止。设总迭代次数为 $T$。
我们需要 $m / 2^{T/2} < 1$，即 $2^{T/2} > m$。
两边取对数：
$$
\frac{T}{2} > \log_2 m \implies T > 2 \log_2 m
$$
所以，迭代次数 $T$ 与 $\log m$ 成正比。
每次迭代内部只进行了常数时间的加减乘除和取模操作（$O(1)$）。
**总时间复杂度 = 迭代次数 $\times$ 单次操作耗时 = $O(\log m)$。**

> **注**：最坏情况其实是斐波那契数列相邻两项（例如 $\gcd(F_{n}, F_{n-1})$），此时每次只减去一次，缩减最慢，但即便如此，斐波那契数列也是指数增长的，其项数 $n$ 与数值大小 $m$ 依然呈对数关系 ($F_n \approx \phi^n$)，所以复杂度依然是 $O(\log m)$。
- **空间复杂度**：`O(logm)`
在 C++ 实现中，我们通常使用递归：
```cpp
ll exgcd(ll a, ll b, ll &x, ll &y) {
    if (b == 0) return a;
    return exgcd(b, a % b, y, x); // 递归调用
}
```
- 每一次递归调用，系统都需要在**栈（Stack）** 上分配一个新的栈帧（Stack Frame），用来保存当前的局部变量（如 `a`, `b`, `x`, `y` 的地址等）和返回地址。
- 既然我们已经证明了递归的深度（层数）是 $O(\log m)$。
- 那么栈上同时存在的最大栈帧数量就是 $O(\log m)$。
- 每个栈帧的大小是常数 $O(1)$。
- **总空间复杂度 = 递归深度 $\times$ 单帧大小 = $O(\log m)$。**
>✨ tips

- 为什么要 `(x % m + m) % m`？
C++ 中的 `%` 运算符对于负数的行为是：`-5 % 3` 结果是 `-2`。  
但在数论中，逆元通常定义为 `[0,m−1]` 之间的正整数。

- `x % m`：将 x 缩小到 `(−m,m)` 范围。
- `+ m`：确保数值变为正数（即使原来是负数，加一个 `m` 后肯定大于 0）。
- `% m`：防止原本就是正数且大于 `m` 的情况（虽然 `exgcd` 产生的解通常绝对值不会超过 `m` ，但这步是保险起见）。
