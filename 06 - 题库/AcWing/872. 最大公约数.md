> 🔗[872 - 最大公约数](https://www.acwing.com/problem/content/874/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定 n 对正整数 $a_i, b_i$，请你求出每对数的最大公约数。

#### 输入格式

第一行包含整数 n。

接下来 n 行，每行包含一个整数对 $a_i, b_i$。

#### 输出格式

输出共 n 行，每行输出一个整数对的最大公约数。

#### 数据范围

$1 ≤ n ≤ 10^5$,  
$1 ≤ a_i, b_i ≤ 2×10^9$

#### 输入样例：

```
2
3 6
4 6
```

#### 输出样例：

```
3
2
```

## 💡 解题思路 
性质：若 $d | a$， $d | b$，则 $d | (a*x + b*y)$。（`|` 读作整除）
例如：$2 | 6$， $2 | 4$，则 $2 | (6 * x + 4 * y)$。
所以有 $(a, b) = (b, a \,mod\, b)$ 即`a` 和 `b` 的最大公约数等于`b` 和 `a % b` 的最大公约数
证明：
$$
a \,mod\, b = a - \lfloor a / b \rfloor * b = a - c * b
$$
对于左边：任取 `a` 和 `b` 的最大公约数 `d`，因为 `d | a` ，`d | b`，所以 `d | (a - c * b)`。（性质）
对于右边：任取 `b` 和 `a - c * b`的最大公约数 `d`，因为 `d | a`，`d | (a - c * b)`。 所以 `d | (a - c * b + c * b)`即 `d | a`。
正确性证明：
欧几里得算法（辗转相除法）的正确性证明主要包含两个部分：
1.  **原理正确性**：证明 $\gcd(a, b) = \gcd(b, a \bmod b)$。这是算法每一步迭代的理论基础。
2.  **终止性与结果正确性**：证明算法一定会在有限步内停止，且停止时的结果就是最大公约数。

以下是详细的数学证明过程。

---

### 第一部分：核心引理证明
**命题**：对于任意非负整数 $a$ 和正整数 $b$，有：
$$ \gcd(a, b) = \gcd(b, a \bmod b) $$

**证明**：
设 $d = \gcd(a, b)$，$r = a \bmod b$。
根据带余除法定义，我们可以将 $a$ 表示为：
$$ a = k \cdot b + r $$
其中 $k = \lfloor a/b \rfloor$ 是商，$r$ 是余数，且 $0 \le r < b$。
移项可得：
$$ r = a - k \cdot b $$

我们需要证明 $a$ 和 $b$ 的公约数集合与 $b$ 和 $r$ 的公约数集合完全相同。

**1. 证明 $a, b$ 的任意公约数也是 $b, r$ 的公约数：**
设 $c$ 是 $a$ 和 $b$ 的任意一个公约数。
即 $c \mid a$ 且 $c \mid b$（$c$ 整除 $a$， $c$ 整除 $b$）。
根据整除的线性性质，若 $c \mid a$ 且 $c \mid b$，则 $c$ 必整除它们的线性组合 $a - k \cdot b$。
因为 $r = a - k \cdot b$，所以 $c \mid r$。
既然 $c \mid b$ 且 $c \mid r$，那么 $c$ 也是 $b$ 和 $r$ 的公约数。

**2. 证明 $b, r$ 的任意公约数也是 $a, b$ 的公约数：**
设 $c'$ 是 $b$ 和 $r$ 的任意一个公约数。
即 $c' \mid b$ 且 $c' \mid r$。
根据 $a = k \cdot b + r$，由于 $c'$ 整除 $b$ 和 $r$，它必然整除它们的线性组合 $k \cdot b + r$。
所以 $c' \mid a$。
既然 $c' \mid a$ 且 $c' \mid b$，那么 $c'$ 也是 $a$ 和 $b$ 的公约数。

**结论**：
由于两组数的公约数集合完全相同，那么它们的**最大**公约数也必然相等。
即：
$$ \gcd(a, b) = \gcd(b, a \bmod b) $$
**证毕。**

---

### 第二部分：算法终止性与最终结果证明

欧几里得算法的过程是构造一个序列：
$$
\begin{aligned}
r_0 &= a \\
r_1 &= b \\
r_2 &= r_0 \bmod r_1 \\
r_3 &= r_1 \bmod r_2 \\
&\vdots \\
r_{n+1} &= r_{n-1} \bmod r_n \\
&\vdots
\end{aligned}
$$

**1. 终止性证明**
观察余数序列 $r_1, r_2, r_3, \dots$：
根据取模运算的定义，对于每一步 $r_{i+1} = r_{i-1} \bmod r_i$，都有：
$$ 0 \le r_{i+1} < r_i $$
这意味着余数序列是一个**严格递减**的非负整数序列：
$$ b = r_1 > r_2 > r_3 > \dots \ge 0 $$
由于非负整数不能无限严格递减下去，该序列必然在有限步内达到 $0$。
假设在第 $n$ 步时，$r_{n+1} = 0$，此时算法停止。

**2. 结果正确性证明**
当算法停止时，我们有 $r_{n+1} = 0$，即 $r_{n-1} \bmod r_n = 0$。
这意味着 $r_n$ 整除 $r_{n-1}$。
根据最大公约数的定义：
$$ \gcd(r_{n-1}, r_n) = r_n $$
（因为 $r_n$ 是 $r_{n-1}$ 的约数，且显然是 $r_n$ 自身的最大约数）。

结合第一部分的引理，我们可以向前推导：
$$
\begin{aligned}
\gcd(a, b) &= \gcd(r_0, r_1) \\
&= \gcd(r_1, r_2) \quad (\text{由引理}) \\
&= \gcd(r_2, r_3) \\
&\vdots \\
&= \gcd(r_{n-1}, r_n)
\end{aligned}
$$
因为 $\gcd(r_{n-1}, r_n) = r_n$，所以：
$$ \gcd(a, b) = r_n $$
即算法最后得到的非零余数 $r_n$ 就是 $a$ 和 $b$ 的最大公约数。
**证毕。**

---

### 补充：时间复杂度证明（拉梅定理）

虽然用户没问，但通常证明正确性后会关心效率。
**拉梅定理 (Lamé's Theorem)** 指出：欧几里得算法求 $\gcd(a, b)$ 所需的除法次数不超过较小数 $b$ 的十进制位数的 5 倍。
更精确地，最坏情况发生在 $a$ 和 $b$ 是连续的斐波那契数时。
因此，算法的时间复杂度为 **$O(\log(\min(a, b)))$**。

### 总结
1.  **逻辑基础**：$\gcd(a, b) = \gcd(b, a \bmod b)$ 保证了每一步变换不改变最大公约数的值。
2.  **收敛保证**：余数严格递减且非负，保证了算法必然在有限步内以余数为 0 结束。
3.  **最终状态**：当余数为 0 时，除数即为最大公约数。

这就是欧几里得算法绝对正确的数学基石。
## 💻 代码实现

```cpp
#include <iostream>

using namespace std;

//求最大公约数 或者 判断两个数是否互质（检查gcd是否等于1，等于1则互质）
int gcd(int a, int b)
{
	//当b不为0时，返回gcd(b,a % b); 当b为0时，则a和0的最大公约数一定是a 0可以被任何数整除
    return b ? gcd(b, a % b) : a;
}
/*
若写成 gcd(a % b, b)则 当 a < b 时,可能陷入死循环 
若要 求a 和 b的最小公倍数 记为res
则 res = a / gcd(a, b) * b  即两者的乘积除以最大公约数即可
*/

int main()
{
    int n;
    scanf("%d", &n);
    
    while (n--) {
        int a, b;
        scanf("%d%d", &a, &b);
        printf("%d\n", gcd(a, b));
    }
    
    return 0;
}
```
