> 🔗[867 - 分解质因数](https://www.acwing.com/problem/content/description/869/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定 n 个正整数 $a_i$，将每个数分解质因数，并按照质因数从小到大的顺序输出每个质因数的底数和指数。

#### 输入格式

第一行包含整数 n。

接下来 n 行，每行包含一个正整数 $a_i$。

#### 输出格式

对于每个正整数 $a_i$，按照从小到大的顺序输出其分解质因数后，每个质因数的底数和指数，每个底数和指数占一行。

每个正整数的质因数全部输出完毕后，输出一个空行。

#### 数据范围

1≤n≤100,  
$2 ≤ a_i ≤ 2×10^9$

#### 输入样例：

```
2
6
8
```

#### 输出样例：

```
2 1
3 1

2 3
```

## 💡 解题思路 
分解质因数——试除法
优化：`n` 中最大只包含一个大于$\sqrt {n}$ 的质因数。
## 💻 代码实现
> my answer
```cpp
#include <iostream>

using namespace std;

//分解质因数
void divide(int x)
{
    for(int i = 2; i <= x / i; i ++) //从2开始枚举 
        if(x % i == 0) // 枚举到i 意味着从2 ~ i-1中给所有质因子都除干净了 所以 i 一定是质数
        {
            int s = 0; // 记录质因数次数
            while(x % i == 0)
            {
                x /= i; //将因数中i的倍数除尽
                s++;
            }
            cout << i << " " << s << endl;
        }
    if(x > 1) cout << x << " " << 1 << endl;//剩下一个不能再继续分解的数
    puts("");
}

int main()
{
    int n; cin >> n;
    while (n--) {
        int x; cin >> x;
        divide(x);
    }
    
    return 0;
}
```
- **时间复杂度**：$O(\sqrt n)$。最好情况下$O(\log n)$，最坏情况下$O(\sqrt n)$。
- **空间复杂度**：`O(1)`
