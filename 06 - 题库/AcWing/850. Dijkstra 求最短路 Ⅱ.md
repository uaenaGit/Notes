> 🔗[850 - Dijkstra求最短路 Ⅱ](https://www.acwing.com/problem/content/852/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定一个 n 个点 m 条边的有向图，图中可能存在重边和自环，所有边权均为非负值。

请你求出 1 号点到 n 号点的最短距离，如果无法从 1 号点走到 n 号点，则输出 −1。

#### 输入格式

第一行包含整数 n 和 m。

接下来 m 行每行包含三个整数 x,y,z，表示存在一条从点 x 到点 y 的有向边，边长为 z。

#### 输出格式

输出一个整数，表示 1 号点到 n 号点的最短距离。

如果路径不存在，则输出 −1。

#### 数据范围

$1 ≤ n , m ≤ 1.5×10^5$,  
图中涉及边长均不小于 0，且不超过 10000。  
数据保证：如果最短路存在，则最短路的长度不超过 $10^9$。

#### 输入样例：

```
3 3
1 2 2
2 3 1
1 3 4
```

#### 输出样例：

```
3
```

## 💡 解题思路 
使用堆优化的`dijkstra`算法，使用`priority_queue`（小根堆）来维护集合中最短路径以及顶点。

## 💻 代码实现
> my answer
```cpp
#include <iostream>
#include <vector>
#include <cstring>
#include <queue>

using namespace std;
const int N = 1000010, INF = 0X3f3f3f3f;
int n, m;
typedef pair<int, int> PII;
int dist[N]; // 距离数组
struct Edge{
  int to;
  int w;
  Edge(int t, int v) : to(t), w(v) {} // 构造函数
};

// 堆优化版dijkstra
int dijkstra(vector<vector<PII>>& g)
{
    memset(dist, 0x3f, sizeof(dist)); // 初始化dist数组为无限大
    
    priority_queue<PII, vector<PII>, greater<PII>> q; // 小根堆 .first存储距离 .second存储节点编号
    dist[1] = 0;// 起点的距离为0
    q.push({0, 1});
    
    while (q.size()) {
        // 注意这里不能用引用 因为后面pop这会使引用指向被弹出的（已失效的）对象，属于未定义行为（undefined behavior），
        // 所以结果会不确定（你看到的是6）
        auto [dis, ver] = q.top();
        // cout << dis << ' ' << ver << " " << "***" << endl;
        q.pop();
        
        if (dis > dist[ver]) {
            continue; // ver之前出堆过
        }
        // 遍历以ver为起点的出边
        for (auto &[j, w] : g[ver]) {
            if (dist[j] > dis + w) {
                dist[j] = dis + w;
                q.push({dist[j], j});
            }
        }
    }
    if (dist[n] == INF) return -1;
    return dist[n];
}

int main()
{
    scanf("%d%d", &n, &m);
    vector<vector<PII>> g(n + 1); // 邻接表存储图
    while (m--) {
        int a, b, w;
        scanf("%d%d%d", &a, &b, &w);
        g[a].push_back({b, w});
    }

    int res = dijkstra(g);
    printf("%d\n", res);
    
    return 0;
}
```
- **时间复杂度**：$O(mlogn)$
- **空间复杂度**：$O(m)$
