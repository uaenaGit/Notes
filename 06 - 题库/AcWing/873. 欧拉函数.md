> 🔗[873 - 欧拉函数](https://www.acwing.com/problem/content/875/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定 n 个正整数 ai，请你求出每个数的欧拉函数。

##### 欧拉函数的定义

> 1∼N 中与 N 互质的数的个数被称为欧拉函数，记为 $ϕ(N$)。  
> 若在算数基本定理中，$N = p_1^{\alpha_1}p_2^{\alpha_2}…p_m^{\alpha_m}$，则：  
> $ϕ(N) = N × (\frac {p_1−1} {p1} × \frac {p_2−1} {p_2} × … × \frac {p_m − 1} {p_m})$

#### 输入格式

第一行包含整数 n。

接下来 n 行，每行包含一个正整数 $a_i$。

#### 输出格式

输出共 n 行，每行输出一个正整数 $a_i$ 的欧拉函数。

#### 数据范围

1≤n≤100,  
$1 ≤ a_i ≤ 2×10^9$

#### 输入样例：

```
3
3
6
8
```

#### 输出样例：

```
2
2
4
```

## 💡 解题思路 
若在算数基本定理中，$N = p_1^{\alpha_1}p_2^{\alpha_2}…p_m^{\alpha_m}$，则： $ϕ(N) = N × (\frac {p_1−1} {p1} × \frac {p_2−1} {p_2} × … × \frac {p_m − 1} {p_m})$
证明：
$1 \sim N$中和 $N$ 互质的数的个数：
1. 从 $1 \sim N$ 中去掉 $p_1, p_2, ..., p_k$ 的所有倍数（有的数可能会被去掉 $2$ 次，比如即是 $p_1$ 又是 $p_2$ 的倍数的数）
2. 加上所有 $p_i * p_j$的倍数（`i` 和 `j` 从 `1` 枚举到 `k`）。
3. 减去所有 $p_i * p_j * p_k$ 的倍数
4. ...
即：
$$
N - N / p_1 - N / p_2 - .... - N / p_k - ...
+ N / (p_1 * p_2) + N / (p_1 * p_3) + ... 
- N / (p_1 * p_2 *p_3) - N / (p_1 * p_2 * p_4) - ...
$$

## 💻 代码实现
> my answer
```cpp
#include <iostream>

using namespace std;

int main()
{
    int n;
    cin >> n;
    
    while (n--) {
        int a;
        cin >> a;
        
        int res = a; // 最开始是 a
        // 分解质因数
        for (int i = 2;  i <= a / i; i++) {
            if (a % i == 0) { // i 一定是 a 的一个质因子
                res = res / i * (i - 1); // res * (1 - 1 / i) 变形 res / i * (i - 1)
                while (a % i == 0) {
                    a /= i; // 将 i 除干净
                }
            }
            
        }
        if (a > 1) res = res / a * (a - 1);
        cout << res << endl;
    }
    
    return 0;
}
```
- **时间复杂度**：$O(n * max(\sqrt {a_i}))$。
- **空间复杂度**：`O(1)`
