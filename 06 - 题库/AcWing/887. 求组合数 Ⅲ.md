## 💡 解题思路 
**卢卡斯定理（Lucas' Theorem）** 是数论中用于计算大组合数取模的核心工具。它由法国数学家 Édouard Lucas 提出，能够将一个巨大的组合数 $\binom{n}{m}$ 模素数 $p$ 的问题，分解为若干个小组合数的乘积。

---

### 1. 定理内容

设 $p$ 是一个**素数**，$n$ and $m$ 是非负整数。
将 $n$ 和 $m$ 分别写成 **$p$ 进制** 的形式：
$$
n = n_k p^k + n_{k-1} p^{k-1} + \dots + n_1 p + n_0
$$
$$
m = m_k p^k + m_{k-1} p^{k-1} + \dots + m_1 p + m_0
$$
其中 $0 \le n_i, m_i < p$。

则有以下同余式成立：
$$
\binom{n}{m} \equiv \prod_{i=0}^{k} \binom{n_i}{m_i} \pmod p
$$

**递归形式（编程常用）：**
$$
\binom{n}{m} \equiv \binom{n \bmod p}{m \bmod p} \cdot \binom{\lfloor n/p \rfloor}{\lfloor m/p \rfloor} \pmod p
$$
边界条件：$\binom{n}{0} = 1$，若 $m > n$ 则 $\binom{n}{m} = 0$。

---

### 2. 定理证明

卢卡斯定理的证明非常优美，主要基于**生成函数**和**二项式定理**在模 $p$ 意义下的性质。

#### 第一步：关键引理
对于素数 $p$ 和 $0 < k < p$，有：
$$
\binom{p}{k} \equiv 0 \pmod p
$$
**证明**：
$$
\binom{p}{k} = \frac{p!}{k!(p-k)!} = \frac{p \cdot (p-1)!}{k!(p-k)!}
$$
由于 $p$ 是素数且 $0 < k < p$，分母 $k!(p-k)!$ 中不包含因子 $p$，而分子包含一个因子 $p$。因此 $\binom{p}{k}$ 是 $p$ 的倍数。

#### 第二步：二项式展开的性质
考虑多项式 $(1+x)^p$ 在模 $p$ 意义下的展开：
$$
(1+x)^p = \sum_{k=0}^{p} \binom{p}{k} x^k = \binom{p}{0}x^0 + \binom{p}{1}x^1 + \dots + \binom{p}{p}x^p
$$
根据第一步的引理，中间项 $\binom{p}{k} \equiv 0 \pmod p$ ($0 < k < p$)，只剩下首尾两项：
$$
(1+x)^p \equiv 1 + x^p \pmod p
$$
这是一个极其重要的恒等式。

#### 第三步：推广到 $p$ 的幂次
利用上述恒等式，我们可以推导 $(1+x)^{p^i}$：
$$
(1+x)^{p^i} = ((1+x)^p)^{p^{i-1}} \equiv (1+x^p)^{p^{i-1}} \equiv \dots \equiv 1 + x^{p^i} \pmod p
$$
即：
$$
(1+x)^{p^i} \equiv 1 + x^{p^i} \pmod p
$$

#### 第四步：综合推导
现在回到 $\binom{n}{m}$。我们将 $n$ 按 $p$ 进制展开：$n = \sum_{i=0}^k n_i p^i$。
考察生成函数 $(1+x)^n$ 的系数：
$$
(1+x)^n = (1+x)^{\sum_{i=0}^k n_i p^i} = \prod_{i=0}^k \left( (1+x)^{p^i} \right)^{n_i}
$$
利用第三步的结论 $(1+x)^{p^i} \equiv 1 + x^{p^i} \pmod p$，代入上式：
$$
(1+x)^n \equiv \prod_{i=0}^k (1 + x^{p^i})^{n_i} \pmod p
$$
展开右边的每一项 $(1 + x^{p^i})^{n_i}$（注意这里 $n_i < p$，直接二项式展开即可）：
$$
(1 + x^{p^i})^{n_i} = \sum_{j=0}^{n_i} \binom{n_i}{j} (x^{p^i})^j = \sum_{j=0}^{n_i} \binom{n_i}{j} x^{j \cdot p^i}
$$
所以：
$$
(1+x)^n \equiv \prod_{i=0}^k \left( \sum_{j=0}^{n_i} \binom{n_i}{j} x^{j \cdot p^i} \right) \pmod p
$$
我们需要求的是 $(1+x)^n$ 展开式中 $x^m$ 的系数，即 $\binom{n}{m}$。
将 $m$ 也写成 $p$ 进制：$m = \sum_{i=0}^k m_i p^i$。
在右边的乘积中，要凑出 $x^m = x^{\sum m_i p^i}$，我们必须从第 $i$ 个括号 $\left( \sum_{j=0}^{n_i} \binom{n_i}{j} x^{j \cdot p^i} \right)$ 中选取 $x^{m_i \cdot p^i}$ 这一项（因为 $p$ 进制表示是唯一的，指数必须对应相等）。
- 如果 $m_i \le n_i$，则该项系数为 $\binom{n_i}{m_i}$。
- 如果 $m_i > n_i$，则第 $i$ 个括号里最高次项只有 $x^{n_i \cdot p^i}$，无法凑出 $x^{m_i \cdot p^i}$，系数为 0。

因此，$x^m$ 的总系数就是各位置系数的乘积：
$$
\binom{n}{m} \equiv \prod_{i=0}^k \binom{n_i}{m_i} \pmod p
$$
**证毕。**

```cpp
#include <iostream>

using namespace std;

typedef long long LL;

int p; // 使用lucas定理要求p是素数

// 由于 p 是素数使用费马小定理求逆元（快速幂）
int qmi(int a, int k) {
    int res = 1;
    while (k) {
        if (k & 1) res = 1LL * res * a % p;
        k >>= 1;
        a = 1LL * a * a % p;
    }
    return res;
}

int C(int a, int b) {
    int res = 1;
    // 使用组合数的定义求
    for (int i = 1, j = a; i <= b; i++, j--) {
        res = (LL)res * j % p;
        res = (LL)res * qmi(i, p - 2) % p;
    }
    return res;
}

int lucas(LL a, LL b) {
    if (a < p && b < p) return C(a, b);
    return (LL)C(a % p, b % p) * lucas(a/p, b/p) % p;
}


int main()
{
    int n;
    cin >> n;
    
    while (n--) {
        LL a, b; // a和b是 10^18量级
        cin >> a >> b >> p;
        cout << lucas(a, b) << endl;
    }
    
    
    return 0;
}
```
- **时间复杂度**：$O(p + \log_p n \cdot \log p)$
1.  **时间复杂度**：
    *   **Lucas 递归**：递归深度为 $n$ 在 $p$ 进制下的位数，即 $\log_p n$。
    *   **每层递归**：调用一次 `C`，其中涉及常数次乘法和一次求逆元（快速幂 $O(\log p)$）。
    *   **总复杂度**：$O(p + \log_p n \cdot \log p)$。
    *   通常 $p$ 较小（如 $10^5$），$\log_p n$ 也很小（对于 $10^{18}$，$p=10^5$ 时深度仅为 4 左右），所以效率极高。
- **空间复杂度**：`O(...)`
2.  **空间复杂度**：
    *   **递归栈**：$O(\log_p n)$。
