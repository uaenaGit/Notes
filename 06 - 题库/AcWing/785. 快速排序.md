> 🔗[785 - 快速排序](https://www.acwing.com/problem/content/787/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定你一个长度为 n 的整数数列。

请你使用快速排序对这个数列按照从小到大进行排序。

并将排好序的数列按顺序输出。

#### 输入格式

输入共两行，第一行包含整数 n。

第二行包含 n 个整数（所有整数均在 $1∼10^9$ 范围内），表示整个数列。

#### 输出格式

输出共一行，包含 n 个整数，表示排好序的数列。

#### 数据范围

1≤n≤100000

#### 输入样例：

```
5
3 1 2 4 5
```

#### 输出样例：

```
1 2 3 4 5
```

## 💻 代码实现
> my answer
```cpp
#include <iostream>

using namespace std;

const int N = 100010;
int q[N];

void quickSort(int q[], int l, int r)
{	
    if(l >= r) return;//递归出口 当区间只有一个数或者没有数 证明已经有序 或者写为l==r也行

    int i = l - 1, j = r + 1, x = q[l + r >> 1]; //枢轴取中点比较保险
    while(i < j)
    {
        do i++; while(q[i] < x);//遇到第一个大于等于x的数时i停止
        do j--; while(q[j] > x);//遇到第一个小于等于x的数时j停止
        if(i < j) swap(q[i], q[j]);//交换
    }
	/*
	因为是 j 指针后面的数都大于等于 x 所以左区间是[l, j] 右区间是 [j+1, r]
	若用 i 作为分界点的话 由于i前面的所有数都小于等于 x 所以左区间是[l, i-1] 右区间是[i, r]
	*/
    quickSort(q, l, j), quickSort(q, j+1, r);//递归处理左右区间
}

int main()
{
    int n;
    scanf("%d", &n);
    
    for (int i = 0; i < n; i++) scanf("%d", &q[i]);
    
    quickSort(q, 0, n - 1);
    
    for (int i = 0; i < n; i++) {
        printf("%d", q[i]);
        printf(i < n - 1 ? " " : "\n");
    }
    
    return 0;
}
```
- **时间复杂度**：`O(nlogn)`。平均情况下是`O(nlogn)`，最坏是$O(n^2)$。
- **空间复杂度**：`O(logn)`。递归的栈开销。
