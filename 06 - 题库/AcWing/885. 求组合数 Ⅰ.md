> 🔗[885 - 求组合数 Ⅰ](https://www.acwing.com/problem/content/887/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定 n 组询问，每组询问给定两个整数 a，b，请你输出 $C_b^a \,mod\,(10^9 + 7)$ 的值。

#### 输入格式

第一行包含整数 n。

接下来 n 行，每行包含一组 a 和 b。

#### 输出格式

共 n 行，每行输出一个询问的解。

#### 数据范围

1≤n≤10000,  
1≤b≤a≤2000

#### 输入样例：

```
3
3 1
5 3
2 2
```

#### 输出样例：

```
3
10
1
```

## 💡 解题思路 
求组合数：
$C_b^a = C_{a - 1}^b + C_{a - 1}^{b - 1}$ 。 
类似 $dp$ ：
![image.png](https://cdn.jsdelivr.net/gh/uaenaGit/image-host@main/images20260310120748117.png)
注意**数据范围**：$1 ≤ n ≤ 10000, 1 \leq b \leq a \leq 2000$。
## 💻 代码实现
> my answer
```cpp
#include <iostream>

using namespace std;

const int N = 2010, mod = 1e9 + 7;
int c[N][N];

int main()
{
    int n;
    scanf("%d", &n);
    
    for (int i = 0; i < N; i++) {
        for (int j = 0; j <= i; j++) { // 注意 j 不可能大于 i
            if (!j) c[i][j] = 1; // 从 i 中选0个只有1种方案
            else c[i][j] = (c[i-1][j] + c[i-1][j-1]) % mod;
        }
    }
    
    while (n--) {
        int a, b;
        scanf("%d%d", &a, &b);
        printf("%d\n", c[a][b]);
    }
    
    
    return 0;
}
```
- **时间复杂度**：$O(a ^ 2)$。注意 `a`是更大的那个数
- **空间复杂度**：$O(a ^ 2)$
