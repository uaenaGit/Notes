> 🔗[795 - 前缀和](https://www.acwing.com/problem/content/797/)

## 📌 题目描述
> （请在此处粘贴题目描述）

输入一个长度为 n 的整数序列。

接下来再输入 m 个询问，每个询问输入一对 l,r。

对于每个询问，输出原序列中从第 l 个数到第 r 个数的和。

#### 输入格式

第一行包含两个整数 n 和 m。

第二行包含 n 个整数，表示整数数列。

接下来 m 行，每行包含两个整数 l 和 r，表示一个询问的区间范围。

#### 输出格式

共 m 行，每行输出一个询问的结果。

#### 数据范围

`1 ≤ l ≤ r ≤ n,`  
`1 ≤ n,m ≤ 100000,`  
`−1000 ≤ 数列中元素的值 ≤ 1000`

#### 输入样例：

```
5 3
2 1 3 6 4
1 2
1 3
2 4
```

#### 输出样例：

```
3
6
10
```

## 💻 代码实现
> my answer
```cpp
#include <iostream>

using namespace std;

const int N = 100010;
int a[N], s[N];

int main()
{
    int n, m;
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= n; i++) {
        // 从下标 1 开始读入
        scanf("%d", &a[i]);
    }
    
    // s数组预处理
    for (int i = 1; i <= n; i++) {
        s[i] = s[i-1] + a[i];
    }
    
    while (m--) {
        int l, r;
        scanf("%d%d", &l, &r);
        printf("%d\n", s[r] - s[l-1]);
    }
    
    
    return 0;
}
```
- **时间复杂度**：`O(n)`。
- **空间复杂度**：`O(n)`。使用了前缀和数组

> to optimize

从下标`0`开始读入。
```cpp
#include <iostream>

using namespace std;

const int N = 100010;
int a[N], s[N];

int main()
{
    int n, m;
    scanf("%d%d", &n, &m);
    for (int i = 0; i < n; i++) {
        // 从下标 0 开始读入
        scanf("%d", &a[i]);
    }
    
    // s数组预处理
    for (int i = 0; i < n; i++) {
        s[i + 1] = s[i] + a[i]; // 也从 0 开始预处理
    }
    
    while (m--) {
        int l, r;
        scanf("%d%d", &l, &r);
        printf("%d\n", s[r] - s[l-1]); // 也是 s[r] - s[l-1]
    }
    
    return 0;
}
```
- **时间复杂度**：`O(n)`
- **空间复杂度**：`O(1)`
