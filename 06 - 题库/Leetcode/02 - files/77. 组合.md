> 🔗[77 - 组合](https://leetcode.cn/problems/combinations/description/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定两个整数 `n` 和 `k`，返回范围 `[1, n]` 中所有可能的 `k` 个数的组合。

你可以按 **任何顺序** 返回答案。

**示例 1：**

**输入：** n = 4, k = 2
**输出：**
[
  [2,4],
  [3,4],
  [2,3],
  [1,2],
  [1,3],
  [1,4],
]

**示例 2：**

**输入：** n = 1, k = 1
**输出：**[[1]]

**提示：**

- `1 <= n <= 20`
- `1 <= k <= n`

## 💡 解题思路 
![image.png](https://cdn.jsdelivr.net/gh/uaenaGit/image-host@main/images20260313195538897.png)
剪枝：
设 `path` 长度为 `m`，那么还需要 `d = k - m` 个数；设当前需要从 `[1, i]`这`i` 个数中选数 `i < d`，最后必然无法选出 `k` 个数，不需要再递归。
## 💻 代码实现
> my answer

逆序枚举：
```cpp
class Solution {
public:
    vector<vector<int>> combine(int n, int k) {
        vector<vector<int>> ans;
        vector<int> path;

        // 枚举选哪个：在1到i中选一个数，加到path末尾
        auto dfs = [&](this auto &&dfs, int i) ->void {
            int d = k - path.size(); // 还需要选d个数
            if (i < d) {
                return; // 就算将[1,i]的数选完也不够d个
            }
            if (d == 0) {
                ans.push_back(path);
                return;
            }
            for (int j = i; j >= 1; j--) {
                path.push_back(j);
                dfs(j - 1);
                path.pop_back(); // 恢复现场
            }
        };

        dfs(n); // 倒着枚举 剪枝的判断更简化
        return ans;
    }
};
```
- **时间复杂度**：$O(k⋅C(n,k))$。分析回溯问题的时间复杂度，有一个简易公式：**路径长度×搜索树的叶子数**。对于本题，路径长度始终为 `k`，叶子个数为 $C(n,k)$，所以时间复杂度为 $O(k⋅C(n,k))$。

- **空间复杂度**：$O(k)$。

选或不选。
```cpp
class Solution {
public:
    vector<vector<int>> combine(int n, int k) {
        vector<vector<int>> ans;
        vector<int> path;

        // 枚举选哪个：在1到i中选一个数，加到path末尾
        auto dfs = [&](this auto &&dfs, int i) ->void {
            int d = k - path.size(); // 还需要选d个数
            if (d == 0) { // 选好了
                ans.push_back(path);
                return;
            }
            // 1. 不选 必须要保证 i 比 d 大，这样这次不选后面才至少有d个可选
            if (i > d) {
                dfs(i - 1); // 注意这里不能return
            }

            // 2. 选 i
            path.push_back(i);
            dfs(i - 1);
            path.pop_back(); // 恢复现场
        };

        dfs(n); // 倒着枚举 剪枝的判断更简化
        return ans;
    }
};
```
- **时间复杂度**：$O(k⋅C(n,k))$
- **空间复杂度**：$O(k)$
