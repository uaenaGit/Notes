> 🔗[34 - 在排序数组中查找元素的第一个和最后一个位置](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/description/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给你一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 `target`，返回 `[-1, -1]`。

你必须设计并实现时间复杂度为 `O(log n)` 的算法解决此问题。

**示例 1：**

**输入：** nums = [`5,7,7,8,8,10]`, target = 8
**输出：**[3,4]

**示例 2：**

**输入：** nums = [`5,7,7,8,8,10]`, target = 6
**输出：**[-1,-1]

**示例 3：**

**输入：** nums = [], target = 0
**输出：**[-1,-1]

**提示：**

- $0 <= nums.length <= 10^5$
- $-10^9 <= nums[i] <= 10^9$
- `nums` 是一个非递减数组
- $-10^9 <= target <= 10^9$

## 💡 解题思路 
利用二分。
- 对于**整数**数组`nums`，最后一个小于等于`x`的数的位置即相当于第一个大于等于`x + 1`的数的位置再减1。
## 💻 代码实现
> my answer
```cpp
class Solution {
public:
    int binarySearch(vector<int> &nums, int l, int r, int target) {
        while (l <= r) { // 注意是 l <= r
            int mid = l + (r - l) / 2;
            if (nums[mid] >= target) { // [mid, r]满足要求
                r = mid - 1; // 更新 r = mid - 1;
            } else { // [l, mid] 不满足要求
                l = mid + 1; // 更新l = mid + 1
            }
        }
        return l; // l可能等于数组长度
    }
    
    vector<int> searchRange(vector<int>& nums, int target) {
        int l = 0, r = nums.size() - 1;
        if (l > r) return {-1, -1};
        int st = binarySearch(nums, l, r, target);
        // 若 st == nums.size() 或者 nums[st] != target 
        // 表明 nums 中找不到一个等于 target的数
        if (st >= nums.size() || nums[st] != target) return {-1, -1};
        // 若st存在 则ed一定存在
        int ed = binarySearch(nums, l, r, target + 1) - 1;
        return {st, ed};
    }
};
```
- **时间复杂度**：`O(logn)`
- **空间复杂度**：`O(1)`
