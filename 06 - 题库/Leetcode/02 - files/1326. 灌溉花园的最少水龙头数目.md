> 🔗[1326 - 灌溉花园的最少水龙头数目](https://leetcode.cn/problems/minimum-number-of-taps-to-open-to-water-a-garden/description/)

## 📌 题目描述
> （请在此处粘贴题目描述）

在 x 轴上有一个一维的花园。花园长度为 `n`，从点 `0` 开始，到点 `n` 结束。

花园里总共有 `n + 1` 个水龙头，分别位于 `[0, 1, ..., n]` 。

给你一个整数 `n` 和一个长度为 `n + 1` 的整数数组 `ranges` ，其中 `ranges[i]` （下标从 0 开始）表示：如果打开点 `i` 处的水龙头，可以灌溉的区域为 `[i -  ranges[i], i + ranges[i]]` 。

请你返回可以灌溉整个花园的 **最少水龙头数目** 。如果花园始终存在无法灌溉到的地方，请你返回 **-1** 。

**示例 1：**

![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2020/01/19/1685_example_1.png)

**输入：** n = 5, ranges = [3,4,1,1,0,0]
**输出：** 1
**解释：**
点 0 处的水龙头可以灌溉区间 [-3,3]
点 1 处的水龙头可以灌溉区间 [-3,5]
点 2 处的水龙头可以灌溉区间 [1,3]
点 3 处的水龙头可以灌溉区间 [2,4]
点 4 处的水龙头可以灌溉区间 [4,4]
点 5 处的水龙头可以灌溉区间 [5,5]
只需要打开点 1 处的水龙头即可灌溉整个花园 [0,5] 。

**示例 2：**

**输入：** n = 3, ranges = [0,0,0,0]
**输出：**-1
**解释：** 即使打开所有水龙头，你也无法灌溉整个花园。

**提示：**

- $1 <= n <= 10^4$
- `ranges.length == n + 1`
- `0 <= ranges[i] <= 100`

> my answer

这个解法并不能得到最优解。因为在进行区间合并的时候后面的区间可能会涵盖前面已经合并的区间造成`ans`偏大。
```cpp
class Solution {
public:
    int minTaps(int n, vector<int>& ranges) {
        vector<PII> segs;
        // 预处理区间范围
        for (int i = 0; i < ranges.size(); i++) {
            int l = i - ranges[i], r = i + ranges[i];
            l = max(l, 0), r = min(r, n);
            if (l < r) segs.push_back({l, r});
        }
        if (segs.size() == 0) {
            // 没加入任何合法区间
            return -1;
        }
        sort(segs.begin(), segs.end(), [](const PII &a, const PII &b) {
            // 将区间按照左端点从小到大排序 再按照右端点从大到小排序
            if (a.first != b.first) return a.first < b.first;
            else return a.second > b.second;
        });
        // ---调试---
        for (auto &seg : segs) {
            cout << seg.first << ' ' << seg.second << endl;
        }
        int ans = 1; 
        int st = -1, ed = -1;
        vector<PII> res;
        for (auto &seg : segs) {
            if (seg.first > ed) {
                if (st != -1) {
                    res.push_back({st, ed});
                }
                st = seg.first, ed = seg.second;
            } else if (seg.second > ed) {
                ed = seg.second;
                ans++;
            }
        }
        if (st != -1) res.push_back({st, ed});
        if ((res.size() > 1) || (res.front().first > 0) || (res.back().second < n)) {
            ans = -1;
        }
        return ans;
    }
private:
    typedef pair<int, int> PII;
};
```
- **时间复杂度**：`O(nlog)`。`sort`排序复杂度为$O(nlogn)$。
- **空间复杂度**：`O(n)`。`n`为`res`数组长度

> to optimize

参考[[45. 跳跃游戏 Ⅱ]]的思路，等价替换为过河问题。预处理`ranges[i]`所能代表的区间`[left, right]`。
```cpp
class Solution {
public:
    int minTaps(int n, vector<int>& ranges) {
        vector<int> right_most(n + 1);
        // 预处理ranges所代表区间
        for (int i = 0; i <= n; i++) {
            int r = ranges[i], left = 0;
            left = max(left, i - r);
            // left表示左端点 right_most[left]表示以当前left为左端点的最右端点
            right_most[left] = max(right_most[left], i + r);
        }
        int ans = 0;
        int cur_right = 0, next_right = 0;
        // 走到 n - 1时没有返回，那么必然可以走到 n
        for (int i = 0; i < n; i++) {
            next_right = max(next_right, right_most[i]);
            // 已走到最右端点 须建桥
            if (i == cur_right) {
                // 如果循环中发现也是下一段区间的最右端点 那么走不到对岸
                if (i == next_right) {
                    return -1;
                }
                cur_right = next_right;
                ans++;
            }
        }
        return ans;
    }
};
```
- **时间复杂度**：`O(n)`
- **空间复杂度**：`O(n)`。

> others' answer

使用动态规划。
定义 $dp[i]$ 表示**覆盖区间**`[0, i]`所需的**最少**区间数目。
```cpp
class Solution {
public:
    int minTaps(int n, vector<int>& ranges) {
        vector<PII> segs;
        for (int i = 0; i <= n; i++) {
            int st = 0, ed = 0;
            st = max(0, i - ranges[i]);
            ed = min(n, i + ranges[i]);
            segs.push_back({st, ed});
        }
        sort(segs.begin(), segs.end());
        vector<int> dp(n + 1, INT_MAX);
		// 覆盖下标0不需要区间
        dp[0] = 0;
        for (auto &[st, ed] : segs) {
            if (dp[st] == INT_MAX) {
                return -1;
            }
            for (int j = st; j <= ed; j++) {
                dp[j] = min(dp[j], dp[st] + 1);
            }
        }
        return dp[n];
    }
typedef pair<int, int> PII;
};
```
- **时间复杂度**：`O(n(logn + max(ranges)))`。$max(ranges)$ 表示`ranges`中的最大元素。
- **空间复杂度**：`O(n)`。

>✨ tips
- `dp[0] = 0`。
