> 🔗[198 - 打家劫舍](https://leetcode.cn/problems/house-robber/description/)

## 📌 题目描述
> （请在此处粘贴题目描述）

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组，计算你 **不触动警报装置的情况下** ，一夜之内能够偷窃到的最高金额。

**示例 1：**

**输入：**[1,2,3,1]
**输出：** 4
**解释：** 偷窃 1 号房屋 (金额 = 1) ，然后偷窃 3 号房屋 (金额 = 3)。
     偷窃到的最高金额 = 1 + 3 = 4 。

**示例 2：**

**输入：**[2,7,9,3,1]
**输出：** 12
**解释：** 偷窃 1 号房屋 (金额 = 2), 偷窃 3 号房屋 (金额 = 9)，接着偷窃 5 号房屋 (金额 = 1)。
     偷窃到的最高金额 = 2 + 9 + 1 = 12 。

**提示：**

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 400`

> my answer

回溯版本：
```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();

        auto dfs = [&](this auto&& dfs, int i) ->int {
            if (i < 0) {
                return 0; // 没有房子可选
            }
            // dfs(i-1)：不选第i个房子 dfs(i-2) + nums[i]：选第i个房子
            // int res = max(dfs(i - 1), dfs(i - 2) + nums[i]);
            return max(dfs(i - 1), dfs(i - 2) + nums[i]);
        };

        return dfs(n - 1); // 从第n-1个房子开始
    }
};
```
- **时间复杂度**：$O(2^n)$。
	- **数学推导**：
	    *   设 $T(n)$ 为计算 $n$ 个房子所需的时间。
	    *   递推公式：$T(n) = T(n-1) + T(n-2) + O(1)$。
	    *   这与斐波那契数列的递推公式一致。斐波那契数列的增长速度约为 $\phi^n$（其中 $\phi \approx 1.618$）。
	    *   因此，时间复杂度是指数级的，即 **$O(2^n)$**（更精确地说是 $O(\phi^n)$）。
- **空间复杂度**：$O(n)$。
	- **递归深度**：
	    *   递归从 `i = n-1` 开始，每次递减 1 或 2，直到 `i < 0`。
	    *   最长的递归路径是每次减 1（即 `dfs(n-1) -> dfs(n-2) -> ... -> dfs(0) -> dfs(-1)`）。
	    *   因此，递归栈的最大深度为 $n$。

> to optimize

改成记忆化搜索：
```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        int memo[n];
        memset(memo, -1, sizeof(memo)); // 初始化为-1 -1绝对不可能被搜索到

        auto dfs = [&](this auto&& dfs, int i) ->int {
            if (i < 0) {
                return 0; // 没有房子可选
            }
            if (memo[i] != -1) {
                return memo[i]; // 被搜索过
            }
            memo[i] = max(dfs(i - 1), dfs(i - 2) + nums[i]);
            return memo[i];
        };

        return dfs(n - 1); // 从第n-1个房子开始
    }
};
```
- **时间复杂度**：$O(n)$。`n`是`nums`长度，搜索树最多`n`个节点。
- **空间复杂度**：$O(n)$。递归深度还是`n`，再加上`memo`数组大小。

>✨ tips
- 使用`memo`数组保存搜索结果。

自顶向下算 = 记忆化搜索
自底向上算 = 递推

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        vector<int> f(n + 2, 0); // f[0] = f[1] = 0
        for (int i = 0; i < n; i++) {
            // dfs(i) = max(dfs(i - 1), dfs(i - 2) + nums[i])
            f[i + 2] = max(f[i + 1], f[i] + nums[i]);
        }
        return f[n + 1]; // dfs(n - 1)
    }
};
```
- **时间复杂度**：$O(n)$。$状态个数(O(n)) \times 单个状态所需要的时间(O(1))$。 
- **空间复杂度**：$O(n)$

如何将空间复杂度优化成 $O(1)$？由于计算`f[i]` 只使用了 `f[i - 1` 和 `f[i - 2`。所以可使用两个变量`f0`和`f1`分别表示上上一个和上一个计算结果。
$$
\begin{align}
newF &= max(f_1, f_0 + nums[i]) \\
f_0 &= f_1 \\
f_1 &= newF
\end{align}
$$
```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        int f0 = 0, f1 = 0;
        for (int i = 0; i < n; i++) {
            int newF = max(f1, f0 + nums[i]);
            f0 = f1;
            f1 = newF;
        }
        return f1; // dfs(n - 1)
    }
};
```
- **时间复杂度**：$O(n)$。$状态个数(O(n)) \times 单个状态所需要的时间(O(1))$。 
- **空间复杂度**：$O(1)$

>✨ tips
- 由于状态计算只使用到了前两个状态，可以使用两个变量
