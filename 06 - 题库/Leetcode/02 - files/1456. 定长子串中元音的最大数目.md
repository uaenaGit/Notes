> 🔗[1456 - 定长子串中元音的最大数目](https://leetcode.cn/problems/maximum-number-of-vowels-in-a-substring-of-given-length/description/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给你字符串 `s` 和整数 `k` 。

请返回字符串 `s` 中长度为 `k` 的单个子字符串中可能包含的最大元音字母数。

英文中的 **元音字母** 为（`a`, `e`, `i`, `o`, `u`）。

**示例 1：**

**输入：** s = "abciiidef", k = 3
**输出：** 3
**解释：** 子字符串 "iii" 包含 3 个元音字母。

**示例 2：**

**输入：** s = "aeiou", k = 2
**输出：** 2
**解释：** 任意长度为 2 的子字符串都包含 2 个元音字母。

**示例 3：**

**输入：** s = "leetcode", k = 3
**输出：** 2
**解释：**"lee"、"eet" 和 "ode" 都包含 2 个元音字母。

**示例 4：**

**输入：** s = "rhythms", k = 4
**输出：** 0
**解释：** 字符串 s 中不含任何元音字母。

**示例 5：**

**输入：** s = "tryhard", k = 4
**输出：** 1

**提示：**

- $1 <= s.length <= 10^5$
- `s` 由小写英文字母组成
- `1 <= k <= s.length`

## 💡 解题思路 
由于窗口值是定长的。每次移入最新元素`s[i]`进入窗口，判断`s[i]`是否是元音，是的话`cnt += 1`；当下标`i`移动到能容纳窗口`k`（`i >= k - 1`），则更新答案`ans`，同时移出当前窗口的左端点的元素值，并判断是否是元音，相应地对`cnt`进行更新。

## 💻 代码实现
> my answer
```cpp
class Solution {
public:
    bool check(char c) {
        bool res = (c == 'a') || (c == 'e') || (c == 'i') ||
                    (c == 'o') || (c == 'u');
        return res;
    }
    int maxVowels(string s, int k) {
        int n = s.size();
        int ans = 0;
        int left = 0, cnt = 0;
        for (int i = 0; i < n; i++) {
            cnt += check(s[i]); // 最新字符移入窗口
            // 满足窗口 k
            if (i >= k - 1) {
                ans = max(ans, cnt);
                // 由于窗口是定值， 每次新移入一个字符就要移出一个字符 更新cnt
                cnt -= check(s[left]);
                left++;
            }
        }
        return ans;
    }
};
```
- **时间复杂度**：`O(n)`
- **空间复杂度**：`O(1)`

窗口左端点在 `i` 时，由于窗口长度为`k`，所以窗口左端点为`i - k + 1`。
**入——更新——出：**
1. **入**：下标为 `i` 的元素进入窗口，更新相关统计量。如果左端点 `i - k + 1 < 0`，则尚未形成第一个窗口，重复第一步。
2. **更新**：更新答案。一般更新最大值/最小值。
3. **出**：下标为 `i - k + 1` 的元素离开窗口，更新相关统计量，为下一个循环。

```cpp
class Solution {
public:
    bool check(char c) {
        bool res = (c == 'a') || (c == 'e') || (c == 'i') ||
                    (c == 'o') || (c == 'u');
        return res;
    }
    int maxVowels(string s, int k) {
        int ans = 0, vowel = 0;
        for (int i = 0; i < s.size(); i++) {
            // 1. 右端点进入窗口
            vowel += check(s[i]);

            int left = i - k + 1; // 窗口左端点
            if (left < 0) { // 窗口大小不足 k 
                continue;
            }
            // 2. 更新答案
            ans = max(ans, vowel);

            // 3. 左端点离开窗口
            vowel -= check(s[left]); // 更新vowel 
        }
        return ans;
    }
};
```
- **时间复杂度**：`O(n)`
- **空间复杂度**：`O(1)`

>✨ tips
- 窗口为`k`时，窗口的左端点是`left = i - k + 1`。
