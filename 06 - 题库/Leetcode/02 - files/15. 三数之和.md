> 🔗[15 - 三数之和](https://leetcode.cn/problems/3sum/description/?envType=study-plan-v2&envId=top-interview-150)

## 📌 题目描述
> （请在此处粘贴题目描述）

给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 `0` 且不重复的三元组。

**注意：** 答案中不可以包含重复的三元组。

**示例 1：**

**输入：** nums = [-1,0,1,2,-1,-4]
**输出：**`[[-1,-1,2],[-1,0,1]]`
**解释：**
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0 。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0 。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0 。
不同的三元组是 [-1,0,1] 和 [-1,-1,2] 。
注意，输出的顺序和三元组的顺序并不重要。

**示例 2：**

**输入：** nums = [0,1,1]
**输出：**[]
**解释：** 唯一可能的三元组和不为 0 。

**示例 3：**

**输入：** nums = [0,0,0]
**输出：**`[[0,0,0]]`
**解释：** 唯一可能的三元组和为 0 。

**提示：**

- `3 <= nums.length <= 3000`
- $-10^5 <= nums[i] <= 10^5$

## 💡 解题思路 
每次固定一个指针`k`，初始化两个指针`i = k + 1, j = nums.size( - 1)`。如果三个数之和大于 $0$，将指针 `j--`；如果三个数之和小于$0$，将指针`i++`；如果三个数指针之和等于 $0$，则将当前的三个数加入答案数组，同时更新指针`i++, j--`，注意要跳过重复的数。
## 💻 代码实现
> my answer
```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        int n = nums.size();
        sort(nums.begin(), nums.end());
        vector<vector<int>> ans;
        for (int k = 0; k < n - 2; k++) {
            if (nums[k] > 0) break;
            // 注意 k > 0 否则会下标越界
            if (k > 0 && nums[k] == nums[k - 1]) continue; // 跳过重复数字
            int i = k + 1, j = n - 1;
            while (i < j) {
                int s = nums[k] + nums[i] + nums[j];
                if (s > 0) {
                    j--;
                } else if (s < 0) {
                    i++;
                } else {
                    ans.push_back({nums[k], nums[i], nums[j]});
                    i++;
                    while (i < j && (nums[i] == nums[i - 1])) i++;
                    j--;
                    while (i < j && (nums[j] == nums[j + 1])) j--;
                }
            }
        }
        return ans;
    }
};
```
- **时间复杂度**：$O(n^2)$
- **空间复杂度**：`O(1)`

还有些小优化，如：
- 当前最小的三个数之和大于`0`，直接`break`；
- 当前最大的三个数之和小于`0`，直接`continue`；
```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        int n = nums.size();
        sort(nums.begin(), nums.end());
        vector<vector<int>> ans;
        for (int k = 0; k < n - 2; k++) {
            if (nums[k] > 0) break;
            if (k > 0 && nums[k] == nums[k - 1]) continue; // 跳过重复数字
            if (nums[k] + nums[k + 1] + nums[k + 2] > 0) break; // 最小的三个数大于0
            if (nums[k] + nums[n - 2] + nums[n - 1] < 0) continue; // 最大的三个数之和小于0
            int i = k + 1, j = n - 1;
            while (i < j) {
                int s = nums[k] + nums[i] + nums[j];
                if (s > 0) {
                    j--;
                } else if (s < 0) {
                    i++;
                } else {
                    ans.push_back({nums[k], nums[i], nums[j]});
                    i++;
                    while (i < j && (nums[i] == nums[i - 1])) i++;
                    j--;
                    while (i < j && (nums[j] == nums[j + 1])) j--;
                }
            }
        }
        return ans;
    }
};
```
- **时间复杂度**：$O(n^2)$
- **空间复杂度**：`O(1)`
