> 🔗[50 - Pow(x, n)](https://leetcode.cn/problems/powx-n/description/?envType=study-plan-v2&envId=top-interview-150)

## 📌 题目描述
> （请在此处粘贴题目描述）

实现 [pow(_x_, _n_)](https://www.cplusplus.com/reference/valarray/pow/) ，即计算 `x` 的整数 `n` 次幂函数（即，`xn` ）。

**示例 1：**

**输入：** x = 2.00000, n = 10
**输出：** 1024.00000

**示例 2：**

**输入：** x = 2.10000, n = 3
**输出：** 9.26100

**示例 3：**

**输入：** x = 2.00000, n = -2
**输出：** 0.25000
**解释：** $2^{-2} = 1/2^2 = 1/4 = 0.25$

**提示：**

- `-100.0 < x < 100.0`
- $-2^{31} <= n <= 2^{31}-1$
- `n` 是一个整数
- 要么 `x` 不为零，要么 `n > 0` 。
- $-10^4 <= x^n <= 10^4$

## 💡 解题思路 
使用快速幂。
例如：计算 $3 ^ {13}$
由于 $(13)_2 = (1101)$。
$$
\begin{align}
3^{13} &= 3^{2^0} \times 3^{2^2} \times 3^{2^3} \\
&= 3^{2^0} \times (3^{2^1})^2 \times (3^{2^2})^2 
\end{align}
$$
如何实现$x ^ {-n}$ ？
$$
x ^{-n} = (\frac {1}{x}) ^ n
$$
## 💻 代码实现
> my answer
```cpp
class Solution {
public:
    double myPow(double x, int n) {
        double ans = 1;
        long long k = n; // 当 n = -2^31 时，-n = 2^31大于int可以表示的数所以用long long表示
        if (k < 0) {
            k = -k;
            x = 1 / x;
        }
        while (k) {
            if (k & 1) ans = ans * x;
            k >>= 1;
            x = x * x;
        }
        return ans;
    }
};
```
- **时间复杂度**：`O(logn)`
- **空间复杂度**：`O(1)`
