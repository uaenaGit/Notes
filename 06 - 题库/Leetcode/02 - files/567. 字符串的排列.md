> 🔗[567 - 字符串的排列](https://leetcode.cn/problems/permutation-in-string/description/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给你两个字符串 `s1` 和 `s2` ，写一个函数来判断 `s2` 是否包含 `s1` 的 排列。如果是，返回 `true` ；否则，返回 `false` 。

换句话说，`s1` 的排列之一是 `s2` 的 **子串** 。

**示例 1：**

**输入：** s1 = "ab" s2 = "eidbaooo"
**输出：** true
**解释：** s2 包含 s1 的排列之一 ("ba").

**示例 2：**

**输入：** s1= "ab" s2 = "eidboaoo"
**输出：** false

**提示：**

- $1 <= s1.length, s2.length <= 10^4$
- `s1` 和 `s2` 仅包含小写字母

## 💡 解题思路 
首先，不需要将`s1`的所有全排列求出。由于是考察`s2`是否包含`s1`的排列，即考察是否`s2`中存在某一子串`s`，`s`中的每个字符与`s1`中的每个字符**出现次数相等**（暗含长度得相同）。
初始化两个哈希表`cnt1`和`cnt2`，分别用于记录`s1`和`s2`中字符出现的次数，维护一个长为`len(s1)`的滑动窗口。每次移入`s2`中的新字符，同时`cnt2[s2[i]]++`，当`i >= les(s1) - 1`时，考察是否`cnts == cnt2`，若相等则返回`true`，循环结束后若没有返回`true`，则返回`false`。

## 💻 代码实现
> my answer
```cpp
class Solution {
public:
    bool checkInclusion(string s1, string s2) {
        int m = s1.size(), n = s2.size();
        if (m > n) return false;
        vector<int> cnt1(26, 0), cnt2(26, 0);
        for (auto &c : s1) {
            cnt1[c - 'a']++;
        }
        for (int i = 0; i < n; i++) {
            // 1. 划入窗口
            cnt2[s2[i] - 'a']++;

            int left = i - m + 1;
            if (left < 0) {
                continue; // 不足一个窗口
            }

            if (cnt1 == cnt2) {
                return true;
            }
            // 3. 划出窗口
            cnt2[s2[left] - 'a']--;
        }
        return false;
    }
};
```
- **时间复杂度**：$O(n * |\sum|)$。$|\sum| = 26$表示字符集合的大小， $n$ 是`s2`长度。
- **空间复杂度**：$O(|\sum|)$ 。

> to optimize

可以只使用一个`cnt`数组，将每次循环的`cnt1 == cnt2`从$O(|\sum|)$ 优化成 `O(1)`。用一个变量`less`维护`s2`的长为`len(s1)`某一子串中有`less`种字母出现次数小于`s1`种字母的出现次数。可见，只要在遍历中发现`less == 0`，即可返回`ture`。
```cpp
class Solution {
public:
    bool checkInclusion(string s1, string s2) {
        int m = s1.size(), n = s2.size();
        if (m > n) return false;
        vector<int> cnt(26, 0);
        int less = 0;
        for (auto &c : s1) {
            if (cnt[c - 'a'] == 0) {
                less++; // 维护s1中不同的字母个数
            }
            cnt[c - 'a']++;
        }
        for (int i = 0; i < n; i++) {
            // 1. 划入窗口
            cnt[s2[i] - 'a']--; 
            // 如果减为0 表示当前串中出现字母与s1中相同（个数也相同）则less--
            if (cnt[s2[i] - 'a'] == 0) {
                less--;
            }

            int left = i - m + 1;
            if (left < 0) {
                continue; // 不足一个窗口
            }

            if (less == 0) {
                return true;
            }
            // 3. 划出窗口
            if (cnt[s2[left] -'a'] == 0) { // 表明要划出的字母是在s1中出现过的 则less++
                less++;
            }
            cnt[s2[left] - 'a']++;
        }
        return false;
    }
};
```
- **时间复杂度**：`O(n)` 或 $O(n + |\sum|)$。`n` 是`s2`长度，$|\sum| = 26$ 是字符集大小。
- **空间复杂度**：$O(|\sum|)$。

>✨ tips
- 使用`less`维护与`s1`中字母相差异的种数。
