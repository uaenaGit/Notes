> 🔗[3 - 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长 子串** 的长度。

**示例 1:**

**输入:** s = "abcabcbb"
**输出:** 3 
**解释:** 因为无重复字符的最长子串是 `"abc"`，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。

**示例 2:**

**输入:** s = "bbbbb"
**输出:** 1
**解释:** 因为无重复字符的最长子串是 `"b"`，所以其长度为 1。

**示例 3:**

**输入:** s = "pwwkew"
**输出:** 3
**解释:** 因为无重复字符的最长子串是 `"wke"`，所以其长度为 3。
     请注意，你的答案必须是 **子串** 的长度，`"pwke"` 是一个_子序列，_不是子串。

**提示：**

- $0 <= s.length <= 5 * 10^4$
- `s` 由英文字母、数字、符号和空格组成

## 💡 解题思路 
初始化一个哈希表`cnt`，键为字符`c`，值为`c`出现的次数。枚举`s`的字符，每次`cnt[c]++`，如果`cnt[c] > 1`，那么一定是最近移入的字符造成了重复。则移动左指针`left`，每次都将`cnt[left]--`，直到`cnt[c]`小于等于`1`停止，更新`ans`。
## 💻 代码实现
> my answer
```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int ans = 0;
        int n = s.size(), left = 0;
        for (int right = 0; right < n; right++) {
            cnt[s[right]]++; // 移入新字符
            while (cnt[s[right]] > 1) {
                cnt[s[left]]--; // 移出旧字符
                left++;
            }
            // 这里left不可能大于right
            ans = max(ans, right - left + 1);
        }
        return ans;
    }
private:
    unordered_map<char, int> cnt;
};
```
- **时间复杂度**：`O(n)`。$n$ 是 `s` 长度。
- **空间复杂度**：$O(|\sum|)$。$|\sum|$ 表示`ASCII`字符集大小。
