> 🔗[1765 - 地图中的最高点](https://leetcode.cn/problems/map-of-highest-peak/description/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给你一个大小为 `m x n` 的整数矩阵 `isWater` ，它代表了一个由 **陆地** 和 **水域** 单元格组成的地图。

- 如果 `isWater[i][j] == 0` ，格子 `(i, j)` 是一个 **陆地** 格子。
- 如果 `isWater[i][j] == 1` ，格子 `(i, j)` 是一个 **水域** 格子。

你需要按照如下规则给每个单元格安排高度：

- 每个格子的高度都必须是非负的。
- 如果一个格子是 **水域** ，那么它的高度必须为 `0` 。
- 任意相邻的格子高度差 **至多** 为 `1` 。当两个格子在正东、南、西、北方向上相互紧挨着，就称它们为相邻的格子。（也就是说它们有一条公共边）

找到一种安排高度的方案，使得矩阵中的最高高度值 **最大** 。

请你返回一个大小为 `m x n` 的整数矩阵 `height` ，其中 `height[i][j]` 是格子 `(i, j)` 的高度。如果有多种解法，请返回 **任意一个** 。

**示例 1：**

**![](https://assets.leetcode.com/uploads/2021/01/10/screenshot-2021-01-11-at-82045-am.png)**

**输入：** isWater =`[[0,1],[0,0]]`
**输出：**`[[1,0],[2,1]]`
**解释：** 上图展示了给各个格子安排的高度。
蓝色格子是水域格，绿色格子是陆地格。

**示例 2：**

**![](https://assets.leetcode.com/uploads/2021/01/10/screenshot-2021-01-11-at-82050-am.png)**

**输入：** isWater = [[0,0,1],[1,0,0],[0,0,0]]
**输出：** `[[1,1,0],[0,1,1],[1,2,2]]`
**解释：** 所有安排方案中，最高可行高度为 2 。
任意安排方案中，只要最高高度为 2 且符合上述规则的，都为可行方案。

**提示：**

- `m == isWater.length`
- `n == isWater[i].length`
- `1 <= m, n <= 1000`
- `isWater[i][j]` 要么是 `0` ，要么是 `1` 。
- 至少有 **1** 个水域格子。

## 💡 解题思路 
本题是`多源bfs`问题。多个水域可以看成多个`起点`。所有水源同时开始“漫延”，谁先到达某个陆地格子，那个格子就记录谁的距离。这正是题目要求的“最近水域距离”。
而[[1926. 迷宫中离入口最近的出口]] 问题是`单源bfs`问题，即只有一个起点。
## 💻 代码实现
> my answer

使用`单源bfs`的模版，但是要注意，当有多个起点都可以到达某一点时，应更新成最短距离。
```cpp
class Solution {
    static constexpr int d[4][2] = {
        {0, 1}, {0, -1}, {1, 0}, {-1, 0}
    };
public:
    void bfs(queue<pair<int, int>>& q, vector<vector<int>>& height) {
        while (q.size()) {
            int size = q.size();
            for (int k = 0; k < size; k++) {
                auto [x, y] = q.front();
                q.pop();
                for (auto &[dx, dy] : d) {
                    int nx = x + dx, ny = y + dy;
                    // 1. 出界
                    if (nx < 0 || nx >= height.size() || ny < 0 || ny >= height[0].size()) {
                        continue;
                    }
                    // 2. 已经访问过
                    if (height[nx][ny] != INT_MAX) {
                        continue;
                    }
                    // 3. 推入队列并更新最短距离
                    height[nx][ny] = min(height[nx][ny], height[x][y] + 1);
                    q.push({nx, ny});
                }
            }
        }
    }
    vector<vector<int>> highestPeak(vector<vector<int>>& isWater) {
        int m = isWater.size(), n = isWater[0].size();
        vector<vector<int>> height(m, vector<int>(n, INT_MAX)); // height初始化为INT_MAX
        queue<pair<int, int>> q;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (isWater[i][j]) {
                    height[i][j] = 0;
                    q.push({i, j});
                }
            }
        }
        bfs(q, height);
        return height;
    }
};
```
- **时间复杂度**：`O(mn)`。
- **空间复杂度**：`O(mn)`。最坏情况下整个矩阵都是水域，我们需要将所有水域入队。

> to optimize

`单源bfs`中有`for (int k = 0; k < size; k++) `，它试图按层来处理，  但在多源 BFS 求最短距离的场景下，**并不需要严格分层处理**。
```cpp
class Solution {
    static constexpr int d[4][2] = {
        {0, 1}, {0, -1}, {1, 0}, {-1, 0}
    };
public:
    vector<vector<int>> highestPeak(vector<vector<int>>& isWater) {
        int m = isWater.size(), n = isWater[0].size();
        vector<vector<int>> height(m, vector<int>(n, -1)); // height初始化为-1
        queue<pair<int, int>> q;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (isWater[i][j]) {
                    height[i][j] = 0;
                    q.push({i, j}); // 将所有水域入队
                }
            }
        }
        
        // 多源bfs
        while (q.size()) {
            auto [x, y] = q.front();
            // 多源 bfs 直接出队，再更新到达该点的距离
            q.pop();
            for (auto &[dx, dy] : d) {
                int nx = x + dx, ny = y + dy;
                if (0 <= nx && nx < m && 0 <= ny && ny < n && height[nx][ny] == -1) {
                    height[nx][ny] = height[x][y] + 1;
                    q.push({nx, ny});
                }
            }
        }
        return height;
    }
};
```

- **时间复杂度**：`O(mn)`。
- **空间复杂度**：`O(mn)`。最坏情况下整个矩阵都是水域，我们需要将所有水域入队。

## 🔁 复盘与扩展
> 关键点：
- 单源`bfs`和多源`bfs`比较

| 特性     | (单源/多次单源)                                  |  (多源 BFS)                                   |
| :----- | :----------------------------------------- | :------------------------------------------ |
| 入队策略   | 每次只把一个起点放入队列。                              | 初始化时把所有符合条件的起点（如所有水域）一次性放入队列。               |
| BFS 次数 | 如果有 $ N $ 个起点，理论上要跑 $ N $ 次 BFS（或者在循环里调用）。 | 只跑 1 次 BFS，所有起点同时向外扩散。                      |
| 计算目标   | 计算 特定点 A 到地图上其他所有点的距离。                     | 计算 地图上任意点 到 最近的一个起点集合 的距离。                  |
| 终止条件   | 通常找到特定终点就 `return`；或者遍历完整个连通块。             | 通常必须遍历完整个地图（因为要更新所有格子），或者找到第一个满足条件的边界点。     |
| 典型应用   | 走迷宫：从入口走到出口。  <br>洪水填充：从点击处填充颜色。           | 地图最高点：每个格子离最近的水有多远。  <br>腐烂橘子：所有坏橘子同时感染好橘子。 |
