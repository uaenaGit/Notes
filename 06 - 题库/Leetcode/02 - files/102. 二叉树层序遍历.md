> 🔗[102 - 二叉树层序遍历](https://leetcode.cn/problems/binary-tree-level-order-traversal/description/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给你二叉树的根节点 `root` ，返回其节点值的 **层序遍历** 。 （即逐层地，从左到右访问所有节点）。

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/02/19/tree1.jpg)

**输入：** root = [3,9,20,null,null,15,7]
**输出：** `[[3],[9,20],[15,7]]`

**示例 2：**

**输入：** root = [1]
**输出：** `[[1]]`

**示例 3：**

**输入：** root = []
**输出：** []

**提示：**

- 树中节点数目在范围 `[0, 2000]` 内
- `-1000 <= Node.val <= 1000`

## 💡 解题思路 
二叉树层序遍历：
使用两个数组`cur`和`next`分别存储当前层的节点和下一层的节点。具体的来说，只要`cur`不空，就初始化`next`数组和`val`数组分别于用于存储下一层节点和当前层节点的节点值，遍历 `cur`数组中节点，将节点值保存在`val`数组中，然后判断是否有左右子树，有的话就将其加入到`next`中，遍历完`cur`数组中，将`next`数组赋值给`cur`数组，这样保证循环能进行下去，直到将所有节点遍历完。

## 💻 代码实现
> my answer
```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        vector<vector<int>> ans; // 初始为空
        if (root == nullptr) return ans;
        vector<TreeNode*> cur; // 存储当前遍历的节点
        cur.push_back(root); // 将根节点存入cur数组
        while (cur.size()) { // cur数组不空
            vector<TreeNode*> next;
            vector<int> vals; // 存储节点值
            for (auto &node : cur) {
                vals.push_back(node->val); // 将当前节点值加入val数组
                if (node->left) next.push_back(node->left);
                if (node->right) next.push_back(node->right);
            }
            cur = next;
            ans.push_back(vals);
        }
        return ans;
    }
};
```
- **时间复杂度**：`O(n)`。$n$ 为树的节点个数。
- **空间复杂度**：`O(n)`

>✨ tips
- `return {};` 使用了**列表初始化（List Initialization）** 语法。 `{}` 表示一个空的初始化列表。编译器会自动调用 `vector<vector<int>>` 的构造函数，创建一个**空的二维向量**（即 `size()` 为 0 的 vector）。它的效果完全等同于 `return vector<vector<int>>();` 或 `return {};` (C++11)。
- `move`：这两行代码涉及到了 C++11 引入的核心特性：**右值引用（Rvalue Reference）** 和**移动语义（Move Semantics）**，具体通过 `std::move` 函数来实现。

它们的核心目的是：**避免深拷贝（Deep Copy），直接“窃取”资源，从而大幅提升性能。**

下面逐句详细解释：

---

### 1. `cur = move(nxt);`

#### 背景
假设 `cur` 和 `nxt` 都是某种昂贵的对象（比如 `queue<TreeNode*>` 或大的 `vector`）。
*   **如果不加 `move`**：`cur = nxt;` 会调用**拷贝赋值运算符**。系统会分配新的内存，把 `nxt` 里的所有元素一个一个复制一份到 `cur` 中。如果队列里有 100 万个节点，这就要复制 100 万次，非常慢。
*   **加上 `move`**：`cur = std::move(nxt);` 会调用**移动赋值运算符**。

#### 执行过程
1.  `std::move(nxt)`：它本身不做任何数据移动，它只是将 `nxt` 强制转换为一个**右值引用（xvalue）**。这相当于告诉编译器：“`nxt` 这个变量我之后不再使用了（或者我不关心它的值了），你可以把它里面的资源‘搬走’。”
2.  `cur = ...`：编译器看到右边是右值，于是调用 `cur` 的**移动赋值运算符**。
3.  **资源转移**：`cur` 直接接管 `nxt` 内部持有的指针（比如指向堆内存的指针、文件句柄等）。
    *   `cur` 原来的资源会被释放。
    *   `nxt` 内部的指针被置为空（或变为有效但未定义状态）。
    *   **没有发生任何数据的复制**，只是指针的赋值，时间复杂度从 $O(N)$ 降为 $O(1)$。

#### 结果
*   `cur` 现在拥有了原来 `nxt` 的数据。
*   `nxt` 变成了空（对于容器来说，`nxt` 变为 `empty()` 状态）。

---

### 2. `ans.push_back(move(vals));`

#### 背景
`ans` 是一个 `vector<vector<int>>`，`vals` 是一个 `vector<int>`（存储当前层的节点值）。
*   **如果不加 `move`**：`ans.push_back(vals);` 会调用 `vector` 的**拷贝构造函数**。系统会在 `ans` 内部开辟新内存，把 `vals` 里的所有整数复制一遍存进去。
*   **加上 `move`**：`ans.push_back(std::move(vals));` 调用**移动构造函数**。

#### 执行过程
1.  `std::move(vals)`：将 `vals` 标记为右值，表示“可以随意拿走我的内部缓冲区”。
2.  `push_back`：检测到参数是右值，于是触发移动构造。
3.  **指针交换**：`ans` 新生成的那个子向量，直接“继承”了 `vals` 原本指向的那块内存地址。
    *   `vals` 不再拥有那块内存（它的 `data` 指针变空，`size` 变 0）。
    *   数据零拷贝地进入了 `ans`。

#### 为什么要这样做？
在层序遍历中，`vals` 是一个临时变量，每处理完一层，它的内容就被存入结果集 `ans`，之后 `vals` 就会被清空（`vals.clear()` 或重新赋值）以便处理下一层。
既然 `vals` 马上就没用了，**为什么还要费力把数据复制一份给 `ans` 呢？** 直接把 `vals` 的内存“送”给 `ans` 是最优解。

---

### 总结对比

| 操作 | 普通拷贝 (Copy) | 移动语义 (Move) |
| :--- | :--- | :--- |
| **代码** | `a = b;` 或 `vec.push_back(b);` | `a = std::move(b);` 或 `vec.push_back(std::move(b));` |
| **行为** | **复制**：分配新内存，逐个元素复制数据。 | **窃取**：直接转移内部指针，原变量变空。 |
| **耗时** | $O(N)$ (与数据量成正比) | $O(1)$ (常数时间，极快) |
| **原变量状态** | `b` 保持不变，仍拥有数据。 | `b` 被掏空，处于有效但未指定状态（通常为空）。 |
| **适用场景** | 还需要再次使用原变量 `b` 时。 | 原变量 `b` 即将销毁或不再需要其旧值时。 |

### 在你的算法语境中
这两句代码通常出现在 BFS（广度优先搜索）的层序遍历优化中：
1.  `cur = move(nxt);`：把“下一层的队列”直接变成“当前层的队列”，避免复制整个队列指针。
2.  `ans.push_back(move(vals));`：把“当前层的数值列表”直接塞进结果集，避免复制整层的数据。

这是 C++ 高性能编程的标准写法。

使用一个队列。
```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        vector<vector<int>> ans; // 初始为空
        if (root == nullptr) return {};
        queue<TreeNode*> q;
        q.push(root);
        while (q.size()) {
            vector<int> vals;
            
            /*
            1. 将当前层的节点遍历完
            2. 不能写成 for (int i = 0; i < q.size(); i++)
                因为后面会对q进行push操作，q.size()会改变
            */
            int size = q.size(); // 固定当前层的大小
            for (int i = 0; i < size; i++) {
               auto node = q.front();
               q.pop();
               vals.push_back(node->val);
               if (node->left) q.push(node->left);
               if (node->right) q.push(node->right); 
            }
            ans.push_back(move(vals));
        }
        return ans;
    }
};
```
- **时间复杂度**：`O(n)`
- **空间复杂度**：`O(n)`

>✨ tips
- 使用`size`变量先固定当前层的大小。
