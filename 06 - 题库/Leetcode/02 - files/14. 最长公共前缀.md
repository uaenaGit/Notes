> 🔗[14 - 最长公共前缀](https://leetcode.cn/problems/longest-common-prefix/description/?envType=study-plan-v2&envId=top-interview-150)

## 📌 题目描述
> （请在此处粘贴题目描述）

编写一个函数来查找字符串数组中的最长公共前缀。

如果不存在公共前缀，返回空字符串 `""`。

**示例 1：**

**输入：** strs = ["flower","flow","flight"]
**输出：**"fl"

**示例 2：**

**输入：** strs = ["dog","racecar","car"]
**输出：**""
**解释：** 输入不存在公共前缀。

**提示：**

- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- `strs[i]` 如果非空，则仅由小写英文字母组成

## 💡 解题思路 
直接使用`string`的`substr`方法，先将`strs`按照字符串长度从小到大排序，再从`j = 1` 到`j = strs[0].size()`依次枚举子串。判断最长公共子串。

## 💻 代码实现
> my answer
```cpp
class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        int n = strs.size();
        if (n == 1) return strs[0];
        sort(strs.begin(), strs.end(), [](const string a, const string b) {
            return a.length() < b.length();
        });
        int ans = 0, flag = false;
        for (int j = 1; j <= strs[0].size(); j++) {
            for (int i = 0; i + 1 < n; i++) {
                if (strs[i].substr(0, j) == strs[i + 1].substr(0, j)) {
                    if(i + 2 == n) { // 比较到了最后一个字符串
                        ans = j;
                    }
                } else { // 在尝试比较长度为 j 的子串时失败了 直接break
                    flag = true;
                    break;
                }
            }
            if (flag) {
                break;
            }
        }
        return strs[0].substr(0, ans);
    }
};
```
- **时间复杂度**：$O(nlogn + n * m)$。$n$ 是`strs`长度，$m$ 是 `min(strs[i])`，即`strs`中字符串的最小长度。
- **空间复杂度**：`O(logn)`。`n`为`sort`排序开销

> to optimize

不使用排序，增加`j` 与 `strs[i].size()`大小的判断。
```cpp
class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        int n = strs.size();
        if (n == 1) return strs[0];
        int ans = 0, flag = false;
        for (int j = 1; j <= strs[0].size(); j++) {
            for (int i = 0; i + 1 < n; i++) {
                if ((j <= strs[i].size()) && (strs[i].substr(0, j) == strs[i + 1].substr(0, j))) {
                    if(i + 2 == n) { // 比较到了最后一个字符串
                        ans = j;
                    }
                } else { // 在尝试比较长度为 j 的子串时失败了 直接break
                    flag = true;
                    break;
                }
            }
            if (flag) {
                break;
            }
        }
        return strs[0].substr(0, ans);
    }
};
```
- **时间复杂度**：`O(n * m)`。`m` 是 `min(strs[i])`。
- **空间复杂度**：`O(1)`

```cpp
class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        string s0 = strs[0];
        for (int j = 0; j < s0.size(); j++) {
            for (auto &str : strs) {
                if (j == str.size() || str[j] != s0[j]) {
                    return s0.substr(0, j);
                }
            }
        }
        return s0;
    }
};
```
- **时间复杂度**：`O(n * m)`。`n` 是 `strs`的长度，`m` 是`strs` 中最短字符串的长度。
- **空间复杂度**：`O(1)`
