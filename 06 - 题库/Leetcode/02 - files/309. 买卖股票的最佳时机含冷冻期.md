> 🔗[309 - 买卖股票的最佳时机含冷冻期](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-with-cooldown/description/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定一个整数数组`prices`，其中第  `prices[i]` 表示第 `_i_` 天的股票价格 。​

设计一个算法计算出最大利润。在满足以下约束条件下，你可以尽可能地完成更多的交易（多次买卖一支股票）:

- 卖出股票后，你无法在第二天买入股票 (即冷冻期为 1 天)。

**注意：**你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

**示例 1:**

**输入:** prices = [1,2,3,0,2]
**输出:** 3 
**解释:** 对应的交易状态为: [买入, 卖出, 冷冻期, 买入, 卖出]

**示例 2:**

**输入:** prices = [1]
**输出:** 0

**提示：**

- `1 <= prices.length <= 5000`
- `0 <= prices[i] <= 1000`

## 💡 解题思路 
思路参考 [[122. 买卖股票的最佳时机 Ⅱ]]
注意：
- 只有当持有股票的时候，如果是**买入股票**才更新当前状态为**持有**的话，会有冷冻期（*1天*），所以对应状态更新应为 $max(dfs(i - 1, 1), dfs(i - 2, 0) - prices[i])$。即这会导致边界条件多了一个 $dfs(−2,0)=0$，后面空间优化中的 `pre0​` 指的就是这个状态。
- 注意 `dfs(i−2,0)` 并不意味着第 `i−2` 天一定卖了股票，而是在没有股票下的最优状态。
## 💻 代码实现
> my answer
```cpp
class Solution {
public:
    int dfs(vector<int> &prices, int i, int hold, vector<vector<int>> &memo) {
        if (i < 0) {
            return hold ? INT_MIN / 2 : 0; // dfs(-1, 0) = 0, dfs(-1, 1) = INT_MIN / 2;
        }
        if (memo[i][hold] != INT_MIN) {
            return memo[i][hold];
        }
        int res;
        if (hold) {
            // 只有买入的时候才会考虑冷冻期 冷冻期为一天 所以如果是用买入更新的话应该为 i - 2更新过来
            res = max(dfs(prices, i - 1, 1, memo), dfs(prices, i - 2, 0, memo) - prices[i]);
        } else {
            res = max(dfs(prices, i - 1, 0, memo), dfs(prices, i - 1, 1, memo) + prices[i]);
        }
        return memo[i][hold] = res;
    }

    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        vector<vector<int>> memo(n, vector<int>(2, INT_MIN)); // 初始化二维vector为0
        return dfs(prices, n - 1, 0, memo);
    }
};
```


- **时间复杂度**：`O(n)`。$n$ 为`prices`数组大小。
- **空间复杂度**：`O(n)`。$n$ 为`memo`数组大小。

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        vector<vector<int>> f(n + 2, vector<int>(2, 0)); // 初始化二维vector为0
        // 由于状态转移涉及到 f[i - 1][0] 所以我们整体往后移1位
        f[1][1] = INT_MIN;
        for (int i = 0; i < n; i++) {
            f[i + 2][0] = max(f[i + 1][0], f[i + 1][1] + prices[i]);
            // 只有买入时才会涉及到冷冻期
            f[i + 2][1] = max(f[i + 1][1], f[i][0] - prices[i]);
        }
        return f[n + 1][0];
    }
};
```
- **时间复杂度**：`O(n)`。$n$ 是`prices`数组长度。
- **空间复杂度**：`O(n)`。$n$ 是`f`数组大小。

>✨ tips
- 由于会涉及到`f[i - 1][0]`，所以不能从`f[0][*]`开始初始化，否则会出现数组下标越界的问题，得从`f[1][*]` 开始初始化。
- 由于返回答案是`f[n + 1][0]` 所以初始化`f`数组至少行数为`n + 2`。

1. 解法一
使用**滚动数组**对空间进行优化。
```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        // prev_f0相当于dfs{i-2, 0}
        int prev_f0 = 0, f0 = 0, f1 = INT_MIN;
        for(auto &prcie : prices) {
            int new_f0 = max(f0, f1 + prcie);
            f1 = max(f1, prev_f0 - prcie);
            prev_f0 = f0;
            f0 = new_f0;
        }
        return f0;
    }
};
```
- **时间复杂度**：`O(n)`。
- **空间复杂度**：`O(1)`。

>✨ tips
- 使用`prev_f0`表示`dfs(i - 2, 0)`状态，用`new_f0`表示`max(f0, f1 + prices[i])`。

2. 解法
多使用一种状态表示**冷冻期获利**。
状态关系为：  
- 卖出获利 = max(前一天卖出获利， 前一天买入 + 今天卖出股票)  --- *不会有冷冻期*
- 买入获利 = 买入获利 = max(前一天买入获利，前一天冷冻获利 - 今天买入股票)  ---  *不能前一天卖出 + 今天买入*
- 冷冻期获利 = max(前一天冷冻期获利，前一天卖出获利)
```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        // 三个状态 f[*][0] 表示卖出; f[*][1] 表示买入; f[*][2] 表示冷冻
        vector<vector<int>> f(n + 1, vector<int>(3, 0));
        f[0][1] = INT_MIN, f[0][2] = 0; // 初始化冷冻期获利为0
        for (int i = 0; i < n; i++) {
            /*
            1. 卖出获利 = max(前一天卖出获利， 前一天买入 + 今天卖出) // 不会有冷冻期
            2. 买入获利 = max(前一天买入获利，前一天冷冻获利 - 今天买入)  // 不能前一天卖出 + 今天买入
            3. 冷冻期获利 = max(前一天冷冻期获利，前一天卖出获利)
            */
            f[i + 1][0] = max(f[i][0], f[i][1] + prices[i]);
            f[i + 1][1] = max(f[i][1], f[i][2] - prices[i]);
            f[i + 1][2] = max(f[i][2], f[i][0]);
        }
        return max(f[n][0], f[n][2]);
    }
};
```

- **时间复杂度**：`O(n)`。
- **空间复杂度**：`O(n)`。`f`状态数组的大小。
