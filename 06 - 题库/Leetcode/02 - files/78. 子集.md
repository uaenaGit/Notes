> 🔗[78 - 子集](https://leetcode.cn/problems/subsets/description/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给你一个整数数组 `nums` ，数组中的元素 **互不相同** 。返回该数组所有可能的子集（幂集）。

解集 **不能** 包含重复的子集。你可以按 **任意顺序** 返回解集。

**示例 1：**

**输入：** nums = [1,2,3]
**输出：**`[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]`

**示例 2：**

**输入：** nums = [0]
**输出：**`[[],[0]]`

**提示：**

- `1 <= nums.length <= 10`
- `-10 <= nums[i] <= 10`
- `nums` 中的所有元素 **互不相同**

## 💻 代码实现
> my answer
```cpp
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        int n = nums.size();
        vector<vector<int>> ans;
        vector<int> path;
        
        auto dfs = [&](this auto &&dfs, int i) {
            if (i == n) {
                // 0. 终止条件 子集构造完毕
                ans.push_back(path);
                return;
            }
            // 1. 不选nums[i] 直接递归下一层
            dfs(i+1); // 考虑下一个数nums[i+1]选或不选

            // 2. 选nums[i]
            path.push_back(nums[i]);
            // 递归下一层
            dfs(i+1); // 考虑下一个数nums[i+1]选或不选
            // 恢复现场
            path.pop_back();
        };

        dfs(0);
        return ans;
    }
};
```
- **时间复杂度**：$O(n*2^n)$。其中 `n` 是`nums`的长度，有 $2^n$ 个子集，所以搜索树有 $2 ^ n$ 个叶子，每个叶子复制`path`需要 $O(n)$ 的时间，一共 $O(n * 2 ^n)$。
- **空间复杂度**：`O(n)`

> to optimize

枚举选哪个。
枚举子集（答案）的第一个数选谁，第二个数选谁，第三个数选谁，依此类推。
`dfs` 中的 `i` 表示现在要枚举选 `nums[i]` 到 `nums[n−1]` 中的一个数，添加到 `path` 末尾。
如果选 `nums[j]` 添加到 `path` 末尾，那么下一个要添加到 `path` 末尾的数，就要在 `nums[j+1]` 到 `nums[n−1]` 中枚举了。
注意：不需要在回溯中判断 `i=n` 的边界情况，因为此时不会进入循环，`if i == n: return` 这句话写不写都一样。
```cpp
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        int n = nums.size();
        vector<vector<int>> ans;
        vector<int> path;
        
        auto dfs = [&](this auto &&dfs, int i) ->void {
            ans.push_back(path); // 不选把当前子集加入答案

            // 这个边界判断去掉也行 因为即使i=n，也不会进入for循环
            if (i == n) {
                return;
            }
            
            for (int j = i; j < n; j++) {
                path.push_back(nums[j]);
                dfs(j + 1); // 规定一个顺序 选nums[j]意味着i到j-1都不选，下一个数从j+1开始选
                path.pop_back(); // 恢复现场
            }
        };

        dfs(0);
        return ans;
    }
};
```

- **时间复杂度**：$O(n*2^n)$
- **空间复杂度**：`O(n)`

二进制枚举。
原序列中的每个数字 $a_i$ 的状态可能有两种，即「在子集中」和「不在子集中」。我们用 `1` 表示「在子集中」，`0` 表示不在子集中，那么每一个子集可以对应一个长度为 `n` 的 $0/1$ 序列，第 `i` 位表示 $a_i$ 是否在子集中。例如，$n=3$ ，$a={5,2,9}$ 时：

| $0/1序列$ | 子集        | $0/1$序列对应的二进制数 |
| ------- | --------- | -------------- |
| 000     | {}        | 0              |
| 001     | {9}       | 1              |
| 010     | {2}       | 2              |
| 011     | {2， 9}    | 3              |
| 100     | {5}       | 4              |
| 101     | {5，9}     | 5              |
| 110     | {2， 5}    | 6              |
| 111     | {2， 5， 9} | 7              |
可以发现 $0/1$ 序列对应的二进制数正好从 `0` 到 $2^n−1$。我们可以枚举 mask∈$[0,2^n−1]$，mask 的二进制表示是一个 $0/1$ 序列，我们可以按照这个 $0/1$ 序列在原集合当中取数。当我们枚举完所有 $2^n$ 个 mask，我们也就能构造出所有的子集。
```cpp
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        int n = nums.size();
        vector<vector<int>> ans;
        vector<int> path;
        
        for (int mask = 0; mask < (1 << n); mask++) {
            path.clear(); // 每个新的mask都要清空path
            for (int j = 0; j < n; j++) {
                if ((mask >> j) & 1) {
                    path.push_back(nums[j]);
                }
            }
            ans.push_back(path);
        }
        
        return ans;
    }
};
```
- **时间复杂度**：$O(n*2^n)$，一共 $2^n$ 个状态，每种状态需要 $O(n)$ 的时间来构造子集。
- **空间复杂度**：`O(n)`。构造子集临时数组`path`的大小。
