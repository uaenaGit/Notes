> 🔗[51 - N 皇后](https://leetcode.cn/problems/n-queens/)

## 📌 题目描述
> （请在此处粘贴题目描述）

按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。

**n 皇后问题** 研究的是如何将 `n` 个皇后放置在 `n×n` 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 `n` ，返回所有不同的 **n 皇后问题** 的解决方案。

每一种解法包含一个不同的 **n 皇后问题** 的棋子放置方案，该方案中 `'Q'` 和 `'.'` 分别代表了皇后和空位。

**示例 1：**
![](https://assets.leetcode.com/uploads/2020/11/13/queens.jpg)


**输入：** n = 4
**输出：**`[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]`
**解释：** 如上图所示，4 皇后问题存在两个不同的解法。

**示例 2：**

**输入：** n = 1
**输出：**`[["Q"]]`

**提示：**

- `1 <= n <= 9`

## 💡 解题思路 
由于每行恰好放一个皇后，记录每行的皇后放在哪一列，可以得到一个 $[0,n−1]$ 的排列 `queens`。示例 1 的两个图，分别对应排列 $[1,3,0,2]$ 和 $[2,0,3,1]$。所以我们本质上是在枚举列号的全排列。

## 💻 代码实现
> my answer
```cpp
class Solution {
public:
    vector<vector<string>> solveNQueens(int n) {
        vector<vector<string>> ans;
        vector<string> board(n, string(n, '.')); // 初始化棋盘全为 .
        // 初始化列、正对角线和反对角线全为 false
        vector<bool> col(n * 2, false), dg(n * 2, false), udg(n * 2, false);

        auto dfs = [&](this auto&& dfs, int i) {
            if (i == n) {
                ans.push_back(board);
                return;
            }

            // 枚举列
            for (int j = 0; j < n; j++) {
                // 查看列是否放皇后，还得检查对角线是否有皇后
                if (!col[j] && !dg[i + j] && !udg[j - i + n]) {
                    board[i][j] = 'Q';
                    col[j] = dg[i + j] = udg[j - i + n] = true;
                    dfs(i + 1);
                    col[j] = dg[i + j] = udg[j - i + n] = false; // 恢复现场
                    board[i][j] = '.';
                }
            }
        };

        dfs(0);
        return ans;
    }
};
```
- **时间复杂度**：$O(n^2⋅n!)$。O(n^2⋅n!)。搜索树中至多有 $O(n!)$ 个叶子，每个叶子生成答案每次需要 $O(n^2)$的时间，所以时间复杂度为 $O(n^2⋅n!)$。实际上搜索树中远没有这么多叶子，`n=9` 时只有 $352$ 种放置方案，远远小于 $9!=362880$。
- **空间复杂度**：$O(n)$。递归层数不会超过 $n$。
