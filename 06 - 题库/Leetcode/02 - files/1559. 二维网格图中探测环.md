> 🔗[1559 - 二维网格图中探测环](https://leetcode.cn/problems/detect-cycles-in-2d-grid/description/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给你一个二维字符网格数组 `grid` ，大小为 `m x n` ，你需要检查 `grid` 中是否存在 **相同值** 形成的环。

一个环是一条开始和结束于同一个格子的长度 **大于等于 4** 的路径。对于一个给定的格子，你可以移动到它上、下、左、右四个方向相邻的格子之一，可以移动的前提是这两个格子有 **相同的值** 。

同时，你也不能回到上一次移动时所在的格子。比方说，环  `(1, 1) -> (1, 2) -> (1, 1)` 是不合法的，因为从 `(1, 2)` 移动到 `(1, 1)` 回到了上一次移动时的格子。

如果 `grid` 中有相同值形成的环，请你返回 `true` ，否则返回 `false` 。

## 💡 解题思路 
两个难点：
- 如何判断环？
	- 可以维护一个`bool`数组，要是在某次搜索过程中发现`st[i][j] = true`，则说明走回了起点，形成环。
- 如何保证不走回头路？
	- 维护一个来时的方向`(px, py)`，在枚举新的方向时，如果发现新的方向与来时的方向相同则直接`continue`，枚举下一个方向。
注意：
- 是否需要判断长度`>= 4`？
	- 不用判断，因为只要形成环就一定有环的长度大于等于`4`，可以等价于判断是否形成环。
- 在枚举某一个方向时不能直接`return dfs(i, j, px, py);` 因为这只能代表这个方向是否能形成环，但是有可能这个方向不能形成环，其他方向却能形成环，所以得使用 `if (dfs (i, j, x, y))`判断。
## 💻 代码实现
> my answer
```cpp
class Solution {
    static constexpr int d[4][2] = {
        {-1, 0}, // 上
        {1, 0},  // 下
        {0, -1}, // 左
        {0, 1}   // 右
    };
public:
    bool containsCycle(vector<vector<char>>& grid) {
        int m = grid.size(), n = grid[0].size();
        vector<vector<bool>> st(m, vector<bool>(n, false)); // 标记数组

        // i, j: 当前坐标
        // px, py: 父节点坐标 (from where we came)
        auto dfs = [&](this auto&& dfs, int i, int j, int px, int py) -> bool {
            st[i][j] = true; // 标记当前点已访问

            for (auto &[dx, dy] : d) {
                int nx = i + dx;
                int ny = j + dy;

                // 1. 边界检查
                if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                
                // 2. 字符一致性检查
                if (grid[nx][ny] != grid[i][j]) continue;

                // 3. 不能走回父节点 (避免 immediate backtracking)
                if (nx == px && ny == py) continue;

                // 4. 核心判断：
                // 如果邻居已经访问过，且不是父节点 -> 发现环！
                if (st[nx][ny]) {
                    return true;
                }

                // 5. 继续深入搜索
                // 注意：这里不能直接 return dfs(...)，必须检查返回值
                if (dfs(nx, ny, i, j)) {
                    return true;
                }
            }

            // 所有方向都走不通，说明从当前点出发没找到环
            return false;
        };

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 如果未访问，则开始一次新的 DFS
                // 初始父节点设为 -1, -1
                if (!st[i][j] && dfs(i, j, -1, -1)) {
                    return true;
                }
            }
        }
        
        return false;
    }
};
```
- **时间复杂度**：`O(mn)`
- **空间复杂度**：`O(mn)`
