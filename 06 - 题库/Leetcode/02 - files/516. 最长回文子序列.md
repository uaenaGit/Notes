> 🔗[516 - 最长回文子序列](https://leetcode.cn/problems/longest-palindromic-subsequence/description/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给你一个字符串 `s` ，找出其中最长的回文子序列，并返回该序列的长度。

子序列定义为：不改变剩余字符顺序的情况下，删除某些字符或者不删除任何字符形成的一个序列。

**示例 1：**

**输入：** s = "bbbab"
**输出：** 4
**解释：** 一个可能的最长回文子序列为 "bbbb" 。

**示例 2：**

**输入：** s = "cbbd"
**输出：** 2
**解释：** 一个可能的最长回文子序列为 "bb" 。

**提示：**

- `1 <= s.length <= 1000`
- `s` 仅由小写英文字母组成

## 💻 代码实现
> my answer

记忆化搜索。
```cpp
class Solution {
public:
    int longestPalindromeSubseq(string s) {
        int n = s.size();
        vector<vector<int>> memo(n, vector<int>(n, 0));
        auto dfs = [&](this auto&& dfs, int i, int j) ->int {
            if (i == j) {
                return 1;
            }
            if (i > j) {
                return 0; // 空串
            }
            int &res = memo[i][j];
            if (res > 0) {
                return res; // 计算过
            }
            if (s[i] == s[j]) {
                return res = dfs(i + 1, j - 1) + 2;
            } else {
                return res = max(dfs(i + 1, j), dfs(i, j - 1));
            }
            return res;
        };

        // dfs(i, j) 表示从s[i]到s[j]的最长回文子序列长度
        return dfs(0, n - 1);
    }
};
```
- **时间复杂度**：$O(n^2)$。状态数为 $O(n^2)$，计算单个状态时间是 $O(1)$。
- **空间复杂度**：$O(n^2)$

> to optimize

$1 : 1$翻译成递推。
```cpp
class Solution {
public:
    int longestPalindromeSubseq(string s) {
        int n = s.size();
        vector<vector<int>> f(n, vector<int>(n, 0));
        for (int i = n - 1; i >= 0; i--) {
            f[i][i] = 1;
            for (int j = i + 1; j < n; j++) {
                if (s[i] == s[j]) {
                    f[i][j] = f[i + 1][j - 1] + 2;
                } else {
                    f[i][j] = max(f[i + 1][j], f[i][j - 1]);
                }
            }
        }
        return f[0][n - 1];
    }
};
```
- **时间复杂度**：$O(n^2)$
- **空间复杂度**：$O(n^2)$

>✨ tips
- 为什么 `j` 从 `i + 1`开始循环？
在记忆化搜索中，`i >= j` 是递归边界，直接返回。什么情况下会继续递归呢？就是 `i < j`，所以 $1 : 1$ 翻译成递推的时候也同样要满足 `i < j`，所以 `j` 要从 `i + 1`开始。（也可以这样理解，只有当 `i <= j`时才会存在回文串，但是 `i == j`时，`f[i][i] = 1`；所以 `j`从`i + 1`开始）
- `i` 和 `j` 的枚举顺序？
 由于 `f[i]` 从 `f[i + 1]`转移过来，所以 `i` 要倒序枚举。
 由于 `f[i][j]` 从 `f[i][j - 1]` 转移过来，所以 `j` 要正序枚举。

优化空间。
```cpp
class Solution {
public:
    int longestPalindromeSubseq(string s) {
        int n = s.size();
        vector<int> f(n, 0);
        for (int i = n - 1; i >= 0; i--) {
            f[i] = 1;
            int pre = 0; // 初始值为 f[i+1][i](j - 1 = i + 1 - 1 = i)
            for (int j = i + 1; j < n; j++) {
                int tmp = f[j]; // 实际上为 f[i + 1][j]
                if (s[i] == s[j]) {
                    f[j] = pre + 2;
                } else {
                    // max中：f[j] 实际是 f[i + 1][j]
                    // f[j - 1]实际是f[i][j - 1] 因为j是从小到大枚举的
                    f[j] = max(f[j], f[j - 1]);
                }
                pre = tmp;
            }
        }
        return f[n - 1];
    }
};
```
- **时间复杂度**：$O(n^2)$
- **空间复杂度**：$O(n)$
