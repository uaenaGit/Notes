> 🔗[56 - 合并区间](https://leetcode.cn/problems/merge-intervals/)

## 📌 题目描述
> （请在此处粘贴题目描述）



## 💡 解题思路 
先按照区间**左端点**进行排序，维护一个区间`[st, ed]`，枚举排序后区间`[l, r]`，若`l > ed`表明当前区间已经与维护的区间`[st, ed]` 脱离，将当前`[st, ed]`加入答案中，然后更新`st = l, ed = r`；
## 💻 代码实现
> my answer
```cpp
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        int n = intervals.size();
        vector<vector<int>> ans;
        // 默认按照左端点从小到大排序
        sort(intervals.begin(), intervals.end());
        int st = intervals[0][0], ed = intervals[0][1];
        for (int i = 1; i < n; i++) {
            int l = intervals[i][0], r = intervals[i][1];
            if (l > ed) {
                ans.push_back({st, ed});
                st = l, ed = r;
            } else {
                ed = max(ed, r);
            }
        }
        // 加上最后一个合法区间
        ans.push_back({st, ed});
        return ans;
    }
};
```

- **时间复杂度**：`O(nlogn)`。`sort`一般为 $O(nlogn)$。
- **空间复杂度**：`O(1)`

> to optimize

初始化`st = -1e9, ed = -1e9`来保证将所有考虑合法区间计入 `ans`。注意更新`ans`中区间的条件判断。
```cpp
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end()); // 默认按照[0]先排序 再比较[1]
        vector<vector<int>> ans;
        int st = -1e9, ed = -1e9;
        for (auto &interval : intervals) {
            int l = interval[0], r = interval[1];
            if (l > ed) {
                if (st != -1e9) ans.push_back({st, ed});
                st = l, ed = r; // 保证将第一个区间也考虑进去
            } else {
                // 可以进行区间合并 更新区间右端点
                ed = max(ed, r);
            }
        }
        if (st != -1e9) ans.push_back({st, ed}); // 保证不遗漏所有合法区间
        return ans;
    }
};
```

- **时间复杂度**：`O(nlogn)`
- **空间复杂度**：`O(1)`

>✨ tips
- 使用两个边界来平等处理所有区间，则少了特定区间的判断。
