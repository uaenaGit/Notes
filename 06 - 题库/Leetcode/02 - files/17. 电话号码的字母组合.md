> 🔗[17 - 电话号码的字母组合](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/description/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按 **任意顺序** 返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

![](https://pic.leetcode.cn/1752723054-mfIHZs-image.png)

**示例 1：**

**输入：** digits = "23"
**输出：**["ad","ae","af","bd","be","bf","cd","ce","cf"]

**示例 2：**

**输入：** digits = "2"
**输出：**["a","b","c"]

**提示：**

- `1 <= digits.length <= 4`
- `digits[i]` 是范围 `['2', '9']` 的一个数字。

## 💡 解题思路 
![image.png](https://cdn.jsdelivr.net/gh/uaenaGit/image-host@main/images20260313000200852.png)

回溯三问：
- 当前操作？
	- 枚举`path[i]`要填入的字母
- 子问题？
	- 构造字符串 $\geq i$ 的部分：`dfs(i)` 处理的是从下标 `i` 到末尾的所有字母组合。`dfs(i)` 不仅仅在枚举 `i`，还包含了 `dfs(i+1),dfs(i+2),…,dfs(n)` 这之后的所有递归调用。单纯说「枚举 `i`」是不准确的，因为除了枚举 `i`，还要递归处理剩余部分。正因为如此，我视频中讲的是 `≥i` 而不是等于 `i`。
- 下一个子问题？
	- 构造字符串 $\geq i + 1$ 的部分。`dfs(i) -> dfs(i + 1)`。


## 💻 代码实现
> my answer
```cpp
class Solution {
    // 报错 1
    // static constexpr vector<string> map = {
    //         "", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"
    //     };
public:
    vector<string> letterCombinations(string digits) {
        static const vector<string> map = {
            "", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"
        };
        vector<string> ans;
        int n = digits.size();
        if (n == 0) return {};
        // 报错 2
        // string path(n);
        string path(n, 0);
        auto dfs = [&](this auto&& dfs, int i) {
            if (i == n) {
                ans.push_back(path);
                return;
            }
            for (auto &c : map[digits[i] - '0']) {
                path[i] = c;
                dfs(i+1);
            }
            
        };

        dfs(0);
        return ans;
    }
};
```
- **时间复杂度**：$O(n * 4^n)$。`n` 为 `digits`的长度。最欢情况下，每次需要枚举 `4` 个字母，递归次数为一个满四叉树的节点数，一共会递归 $O(4^n)$ 次，再算上加上答案时复制`path`需要 $O(n)$ 时间，所以总共 $O(n * 4 ^ n)$。
- **空间复杂度**：`O(n)`。返回值的空间不计入，递归栈深度为 $O(n)$，临时字符串为 `path` 为 $O(n)$。
报错一：
这个报错的核心原因是：**C++ 标准不允许在类定义内部直接初始化非整型（non-integral）的 `static const` 成员变量**，除非该初始化是“常量表达式”（即加上 `constexpr`）。

 **🔍 详细解释**

1.  **规则限制**：
    *   在 C++ 中，只有**整型**（如 `int`, `char`, `long`）或**枚举类型**的 `static const` 成员可以在类内部直接赋值（例如 `static const int MAX = 10;` 是合法的）。
    *   对于复杂类型（如 `std::vector`, `std::string`, `std::map`），编译器无法在编译期仅仅通过类内部的代码完成内存分配和构造。因此，标准规定它们必须在**类外部**进行定义和初始化。

2.  **为什么报错建议加 `constexpr`？**
    *   报错信息提示你加 `constexpr`，是因为如果加上它，编译器会尝试在**编译期**构造这个 `vector`。
    *   **但是！** `std::vector` 的构造函数**不是** `constexpr` 的（直到 C++20 部分支持，但动态内存分配依然不能在纯 constexpr 上下文中随意进行，且你的初始化列表涉及动态字符串，通常无法通过 `constexpr` 检查）。
    *   所以，即使你加了 `constexpr`，大概率会报另一个错：`call to non-constexpr function...`。

**✅ 解决方案（二选一）**

*方案 A：拆分声明与定义（最标准、最兼容的做法）*

将**声明**留在类内，将**初始化**移到类外（通常在 `.cpp` 文件或类的实现末尾）。

**步骤 1：修改类内部（只声明，不赋值）**
```cpp
class Solution {
private:
    // 只声明，去掉 "= {...}"
    static const std::vector<std::string> map; 

public:
    // ... 其他函数 ...
};
```

**步骤 2：在类外部进行初始化**
在 `class Solution` 的大括号结束后，添加以下代码：

```cpp
// 格式：const 类型 类名::变量名 = { 初始化列表 };
const std::vector<std::string> Solution::map = {
    "", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"
};
```

> **注意**：如果你是在 LeetCode 等单文件环境中提交，直接把这段初始化代码写在 `class Solution` 定义的下方即可。

---

*方案 B：改为函数内的 `static` 变量（最简单，推荐用于刷题）*

如果你不想处理类外初始化的麻烦，可以直接把这个变量放到需要使用它的**函数内部**。利用 C++ 的“局部静态变量只初始化一次”的特性，效果完全一样，而且代码更紧凑。

```cpp
class Solution {
public:
    vector<string> letterCombinations(string digits) {
        // 【关键修改】把 map 移到这里，加上 static
        // 这样它只在第一次调用时初始化，之后一直复用
        static const vector<string> map = {
            "", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"
        };

        if (digits.empty()) return {};
        
        // ... 使用 map 进行后续逻辑 ...
        vector<string> ans;
        // ...
        return ans;
    }
};
```

**💡 总结建议**

*   **如果是正式项目开发**：请使用 **方案 A**（类内声明，类外定义），符合 C++ 规范，结构清晰。
*   **如果是 LeetCode/算法竞赛**：强烈推荐使用 **方案 B**（函数内 static），代码量少，不容易出错，且不需要担心链接错误或多文件编译问题。

**针对你现在的报错，最快修复方法就是采用方案 B，把 `map` 的定义剪切到 `letterCombinations` 函数的第一行。**

将`path`初始化为空字符串。
```cpp
class Solution {
    static constexpr string phoneMap[10] = {
        "", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"
    };
public:
    vector<string> letterCombinations(string digits) {
        vector<string> ans;
        size_t n = digits.size();
        if (n == 0) return {};
        string path;
        auto dfs = [&](this auto&& dfs, int i) {
            if (i == n) {
                ans.push_back(path);
                return;
            }
            for (auto &c : phoneMap[digits[i] - '0']) {
                path.push_back(c);
                dfs(i+1);
                path.pop_back(); // 回到上一层时得恢复环境
            }
            
        };

        dfs(0);
        return ans;
    }
};
```
- **时间复杂度**：$O(n * 4^n)$。
- **空间复杂度**：`O(n)`

>✨ tips
- 使用`push_back()`时，返回时应该恢复环境`pop_back()`。
