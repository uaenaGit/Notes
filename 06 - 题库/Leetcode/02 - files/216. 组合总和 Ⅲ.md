> 🔗[216 - 组合总和 Ⅲ](https://leetcode.cn/problems/combination-sum-iii/description/)

## 📌 题目描述
> （请在此处粘贴题目描述）

找出所有相加之和为 `n` 的 `k` 个数的组合，且满足下列条件：

- 只使用数字1到9
- 每个数字 **最多使用一次** 

返回 _所有可能的有效组合的列表_ 。该列表不能包含相同的组合两次，组合可以以任何顺序返回。

**示例 1:**

**输入:** _**k**_ = 3, _**n**_ = 7
**输出:**`[[1,2,4]]`
**解释:**
1 + 2 + 4 = 7
没有其他符合的组合了。

**示例 2:**

**输入:** _**k**_ = 3, _**n**_ = 9
**输出:** `[[1,2,6], [1,3,5], [2,3,4]]`
**解释:**
1 + 2 + 6 = 9
1 + 3 + 5 = 9
2 + 3 + 4 = 9
没有其他符合的组合了。

**示例 3:**

**输入:** k = 4, n = 1
**输出:**  []
**解释:** 不存在有效的组合。
在[1,9]范围内使用4个不同的数字，我们可以得到的最小和是1+2+3+4 = 10，因为10 > 1，没有有效的组合。

**提示:**

- `2 <= k <= 9`
- `1 <= n <= 60`

> my answer

以下是我的第一版代码。存在问题：
```cpp
class Solution {
public:
    vector<vector<int>> combinationSum3(int k, int n) {
        vector<vector<int>> ans;
        vector<int> path;

        auto dfs = [&](this auto &&dfs, int i, int s) ->void {
            int d = k - path.size();
            if (s < 0) {
                return;
            }

            if (d == 0 && s == 0) { // 注意：有可能 d = 0 但是 s != 0导致加了k+1个数
                ans.push_back(path);
                return;
            }
            for (int j = i; j >= d; j--) {
                path.push_back(j);
                dfs(j - 1, s - j);
                path.pop_back();
            }
        };

        dfs(9, n);
        return ans;
    }
};
```
在 `for` 循环内部，有可能 `s - j` 会发生溢出。由于只有在 `s < 0` 和 `d == 0 && s == 0`时，才做了 `return` 返回，但实际上，**如果递归没有及时在 `path.size() == k` 时停止，`path` 是完全可能超过 `k` 个元素的！** 
**场景重现：**
1. 你已经选了 `k` 个数 (`path.size() == k`, `d == 0`)。
2. 但是 `s` 还不等于 0 (比如还剩一些值没分完)。
3. 代码**没有 return**，而是继续执行下面的 `for` 循环。
4. 此时 `d = 0`。循环条件 `j >= 0`。
5. 你可能会再选一个数（比如 `j=0`），`path` 变成了 `k+1` 个元素。
6. 再次递归，`path.size()` 变成 `k+1`。
7. 此时 `d = k - (k+1) = -1`。 **`d` 变成负数了！**
一旦 `d` 变成负数：
- 循环条件 `j >= d` (例如 `j >= -1`) 变得非常宽松。
- 如果上一层传下来的 `i` 已经是 `0` 或负数，`j` 就会从 `0` 或负数开始递减。
- `j` 会迅速变成很大的负数（-1, -2, -3...）。
- 计算 `s - j` 时，`s - (-large_number)` = `s + large_number`，直接**溢出**！

所以可以加一个判断当`d < 0`时，直接 `return`；
```cpp
class Solution {
public:
    vector<vector<int>> combinationSum3(int k, int n) {
        vector<vector<int>> ans;
        vector<int> path;

        auto dfs = [&](this auto &&dfs, int i, int s) ->void {
            int d = k - path.size();
            if (s < 0 || d < 0) {
                return;
            }

            if (d == 0 && s == 0) {
                ans.push_back(path);
                return;
            }
            for (int j = i; j >= d; j--) {
                path.push_back(j); // 加入这个元素
                dfs(j - 1, s - j); // 则s - j
                path.pop_back(); // 恢复现场
            }
        };

        dfs(9, n); // 逆序枚举
        return ans;
    }
};
```
- **时间复杂度**：$O(k * C(9,k))$。**路径长度 × 搜索树的叶子数**。 
- **空间复杂度**：$O(k)$。

> to optimize

其实还隐藏着一个优化。
- 剩余数字即使全部选最大的，和也不够`s`，例如 `i = 5`，还需要选 `d = 3` 个数，那么如果 `s > 5 + 4 + 3`，可以直接返回 `s > i + ... + (i - d + 1) = (i + i - d + 1) * d / 2`。
```cpp
class Solution {
public:
    vector<vector<int>> combinationSum3(int k, int n) {
        vector<vector<int>> ans;
        vector<int> path;

        auto dfs = [&](this auto &&dfs, int i, int s) ->void {
            int d = k - path.size();
            if (s < 0 || s > (i * 2 + 1 - d) * d / 2) { // d = 0时 s < 0 || s > 0 返回
                return;
            }

            if (d == 0 ) { // 当d = 0 时，s 一定为 0
                ans.push_back(path);
                return;
            }
            for (int j = i; j >= d; j--) {
                path.push_back(j);
                dfs(j - 1, s - j);
                path.pop_back();
            }
        };

        dfs(9, n);
        return ans;
    }
};
```

- **时间复杂度**：$O(k * C(9,k))$。**路径长度 × 搜索树的叶子数**。 
- **空间复杂度**：$O(k)$

还可以枚举 选 或 不选。
```cpp
class Solution {
public:
    vector<vector<int>> combinationSum3(int k, int n) {
        vector<vector<int>> ans;
        vector<int> path;

        auto dfs = [&](this auto &&dfs, int i, int s) ->void {
            int d = k - path.size();
            if (s < 0 || s > (i * 2 + 1 - d) * d / 2) {
                return;
            }

            if (d == 0) {
                ans.push_back(path);
                return;
            }

            // 1. 不选
            if (i > d) {
                dfs(i - 1, s); // 没选值 s没变
            }
            // 2. 选
            path.push_back(i); // 选 i
            dfs(i - 1, s - i); // s -> s - i
            path.pop_back(); // 恢复现场
        };

        dfs(9, n);
        return ans;
    }
};
```

>✨ tips
- 你在写回溯（DFS）时，**基准情况（Base Case）的判断必须能够拦截所有“不需要继续递归”的状态**

二进制枚举。
```cpp
class Solution {
public:
    vector<vector<int>> combinationSum3(int k, int n) {
        vector<vector<int>> ans;
        vector<int> path;

        for (int mask = 1; mask < (1 << 9); mask++) {
            path.clear();
            int s = 0;
            for (int j = 0; j < 9; j++) {
                if ((mask >> j) & 1) {
                    s += j + 1; // mask第j位是1 实际上要加入集合的元素是j+1
                    path.push_back(j + 1);
                }
            }
            if (s == n && path.size() == k) {
                ans.push_back(path);
            }
        }
        return ans;
    }
};
```
- **时间复杂度**：$O(k * C(9,k))$
- **空间复杂度**：$O(k)$
