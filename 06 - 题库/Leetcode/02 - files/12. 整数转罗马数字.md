> 🔗[12 - 整数转罗马数字](https://leetcode.cn/studyplan/top-interview-150/)

## 📌 题目描述
> （请在此处粘贴题目描述）

七个不同的符号代表罗马数字，其值如下：

| 符号  |  值   |
| :-: | :--: |
|  I  |  1   |
|  V  |  5   |
|  X  |  10  |
|  L  |  50  |
|  C  | 100  |
|  D  | 500  |
|  M  | 1000 |

罗马数字是通过添加从最高到最低的小数位值的转换而形成的。将小数位值转换为罗马数字有以下规则：

- 如果该值不是以 4 或 9 开头，请选择可以从输入中减去的最大值的符号，将该符号附加到结果，减去其值，然后将其余部分转换为罗马数字。
- 如果该值以 4 或 9 开头，使用 **减法形式**，表示从以下符号中减去一个符号，例如 4 是 5 (`V`) 减 1 (`I`): `IV` ，9 是 10 (`X`) 减 1 (`I`)：`IX`。仅使用以下减法形式：4 (`IV`)，9 (`IX`)，40 (`XL`)，90 (`XC`)，400 (`CD`) 和 900 (`CM`)。
- 只有 10 的次方（`I`, `X`, `C`, `M`）最多可以连续附加 3 次以代表 10 的倍数。你不能多次附加 5 (`V`)，50 (`L`) 或 500 (`D`)。如果需要将符号附加4次，请使用 **减法形式**。

给定一个整数，将其转换为罗马数字。

**示例 1：**

**输入：** num = 3749

**输出：** "MMMDCCXLIX"

**解释：**
3000 = MMM 由于 1000 (M) + 1000 (M) + 1000 (M)
 700 = DCC 由于 500 (D) + 100 (C) + 100 (C)
  40 = XL 由于 50 (L) 减 10 (X)
   9 = IX 由于 10 (X) 减 1 (I)
注意：49 不是 50 (L) 减 1 (I) 因为转换是基于小数位

**示例 2：**

**输入：** num = 58

**输出：**"LVIII"

**解释：**
50 = L
 8 = VIII

**示例 3：**

**输入：** num = 1994

**输出：**"MCMXCIV"

**解释：**
1000 = M
 900 = CM
  90 = XC
   4 = IV

**提示：**

- `1 <= num <= 3999`

## 💡 解题思路 

初始化映射`value_symbol`（*pair<int, string>*），从大到小排列`1000->900->500->400>100->90->50->40->10->9->5->4->1`。
每次将`num - 最高位所代表的value_symbol值`，每减一次，`res += value_symbol值对应的字符串`，直到`num`为0即可。 

## 💻 代码实现
> my answer

注意，若将`value_symbol`声明在类内并使用`{}`初始化时，必须加上`static`，否则报错`error: array bound cannot be deduced from a default member initializer const pair<int, string> value_symbol[] = {`
因为**非静态数据成员**的数组大小不能通过其初始化列表自动推导。
```cpp
const pair<int, string> value_symbol[] = {
        {1000, "M"},
        {900, "CM"},
        {500, "D"},
        {400, "CD"},
        {100, "C"},
        {90, "XC"},
        {50, "L"},
        {40, "XL"},
        {10, "X"},
        {9, "IX"},
        {5, "V"},
        {4, "IV"},
        {1, "I"}
};
class Solution {
public:
    string intToRoman(int num) {
        string res;
        for (auto &[val, symbol] : value_symbol) {
            while (num >= val) {
                num -= val;
                res += symbol;
            }
            if (num == 0) {
                break;
            }
        }
        return res;
    }
};
```
- **时间复杂度**：`O(n)`
- **空间复杂度**：`O(1)`

> to optimize

直接硬编码。因为`num`在`[1, 3999]`。对于`个、十、百、千`直接映射。
```cpp
class Solution {
private:
    static constexpr string value_symbol[4][10] = {
        {"", "I", "II", "III", "IV", "V", "VI", "VII", "VIII", "IX"}, // 个位
        {"", "X", "XX", "XXX", "XL", "L", "LX", "LXX", "LXXX", "XC"}, // 十位
        {"", "C", "CC", "CCC", "CD", "D", "DC", "DCC", "DCCC", "CM"}, // 百位
        {"", "M", "MM", "MMM"}  // 千位
    };
public:
    string intToRoman(int num) {
        string res;
        res += value_symbol[3][num / 1000] + value_symbol[2][(num / 100) % 10]
             + value_symbol[1][(num / 10) % 10] + value_symbol[0][num % 10];
        return res;
    }
};
```
- **时间复杂度**：`O(1)`
- **空间复杂度**：`O(1)`
