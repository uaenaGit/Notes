> 🔗[274 - H指数](https://leetcode.cn/problems/h-index/description/?envType=study-plan-v2&envId=top-interview-150)

## 📌 题目描述
> （请在此处粘贴题目描述）

给你一个整数数组 `citations` ，其中 `citations[i]` 表示研究者的第 `i` 篇论文被引用的次数。计算并返回该研究者的 **`h` 指数**。

根据维基百科上 [h 指数的定义](https://baike.baidu.com/item/h-index/3991452?fr=aladdin)：`h` 代表“高引用次数” ，一名科研人员的 `h` **指数** 是指他（她）至少发表了 `h` 篇论文，并且 **至少** 有 `h` 篇论文被引用次数大于等于 `h` 。如果 `h` 有多种可能的值，**`h` 指数** 是其中最大的那个。

**示例 1：**

**输入：**`citations = [3,0,6,1,5]`
**输出：** 3 
**解释：** 给定数组表示研究者总共有 `5` 篇论文，每篇论文相应的被引用了 `3, 0, 6, 1, 5` 次。
     由于研究者有 `3` 篇论文每篇 **至少** 被引用了 `3` 次，其余两篇论文每篇被引用 **不多于** `3` 次，所以她的 _h_ 指数是 `3`。

**示例 2：**

**输入：** citations = [1,3,1]
**输出：** 1

**提示：**

- `n == citations.length`
- `1 <= n <= 5000`
- `0 <= citations[i] <= 1000`

## 💡 解题思路 
翻译题意：给一个数组，找出一个最大的 $h$ ，使得数组中至少有 $h$ 个数大于等于 $h$。
对数组进行排序，对于数组中每个非 $0$ 元素`val`，统计大于该元素值的个数`cnt`，如果`val >= cnt`则返回`cnt`即可。
## 💻 代码实现
> my answer
```cpp
class Solution {
public:
    int hIndex(vector<int>& citations) {
        int n = citations.size();
        sort(citations.begin(), citations.end()); // 排序
        int cnt = 0, ans = 0;
        for (int i = 0; i < n; i++) {
            // 遇到0 直接continue 非0时才计算h指数
            if (citations[i] == 0) continue;
            if (citations[i] > 0) {
                cnt = n - i;
            }
            if (citations[i] >= cnt) {
                ans = cnt;
                break;
            }
        }
        return ans;
    }
};
```

- **时间复杂度**：`O(nlogn)`。瓶颈在`sort`排序上。
- **空间复杂度**：`O(logn)`。瓶颈在`sort`排序上。

> to optimize

不用排序。创建一个计数数组`cnt[n + 1]`，统计给定数组中`min(citations[i], n)`的出现次数。注意，$h$ 指数最大不超过数组元素个数 $n$。逆序遍历给定数组，统计大于等于当前下标`i`的元素个数`s`，如果`s >= i`，则返回`i`即可。
```cpp
class Solution {
public:
    int hIndex(vector<int>& citations) {
        int n = citations.size();
        vector<int> cnt(n + 1);
        for (auto &c : citations) {
            cnt[min(c, n)]++;
        }
        int s = 0;
        // i = 0时，s >= i一定能够成立
        for (int i = n; ; i--) {
            s += cnt[i];
            if (s >= i) {
                return i;
            }
        }
    }
};
```
- **时间复杂度**：`O(n)`。
- **空间复杂度**：`O(n)`。$n$ 为数组大小。

>✨ tips
- 注意`for`循环中如果写了循环终止条件，力扣中会报错`error: non-void function does not return a value in all control paths`
```cpp
class Solution {
public:
    int hIndex(vector<int>& citations) {
        int n = citations.size();
        vector<int> cnt(n + 1);
        for (auto &c : citations) {
            cnt[min(c, n)]++;
        }
        int s = 0;
        // i = 0时，s >= i一定能够成立
        for (int i = n; i>= 0; i--) { // 写了终止条件反而会报错
            s += cnt[i];
            if (s >= i) {
                return i;
            }
        }
    }
};
```
根因：
- **代码 B** 是**良定义（Well-defined）** 的代码：循环一定会自然结束。编译器会认真检查循环结束后的情况，发现你漏了 `return`，于是报错。这是在帮你找逻辑漏洞。
- **代码 A** 包含了**未定义行为（UB）**：依赖 `int` 溢出或者依赖一个没有终点的循环。编译器 optimizations（优化）可能会基于“未定义行为不会发生”的假设，直接忽略循环自然流出的可能性，从而误以为你的代码是完美的。
