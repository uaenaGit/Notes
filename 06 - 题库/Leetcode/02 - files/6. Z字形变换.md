> 🔗[6 - Z 字形变换](https://leetcode.cn/problems/zigzag-conversion/description/?envType=study-plan-v2&envId=top-interview-150)

## 📌 题目描述
> （请在此处粘贴题目描述）

将一个给定字符串 `s` 根据给定的行数 `numRows` ，以从上往下、从左到右进行 Z 字形排列。

比如输入字符串为 `"PAYPALISHIRING"` 行数为 `3` 时，排列如下：

P      A      H     N
A  P  L  S   I   I  G
Y      I       R

之后，你的输出需要从左往右逐行读取，产生出一个新的字符串，比如：`"PAHNAPLSIIGYIR"`。

请你实现这个将字符串进行指定行数变换的函数：

string convert(string s, int numRows);

**示例 1：**

**输入：** s = "PAYPALISHIRING", numRows = 3
**输出：**"PAHNAPLSIIGYIR"

**示例 2：**

**输入：** s = "PAYPALISHIRING", numRows = 4
**输出：**"PINALSIGYAHRPI"
**解释：**

P        I        N
A     L S    I  G
Y  A   H  R
P        I

**示例 3：**

**输入：** s = "A", numRows = 1
**输出：**"A"

**提示：**

- `1 <= s.length <= 1000`
- `s` 由英文字母（小写和大写）、`','` 和 `'.'` 组成
- `1 <= numRows <= 1000`

## 💡 解题思路 
使用矩阵模拟。由于`Z`字形变换，以`t = r + r - 2 = 2 * r - 2`为周期，每个周期会占用矩阵的`1 + r - 2 = r - 1`列。所以共有 $\lceil \frac {n}{t} \rceil$  个周期（最后一个周期视为完整周期），乘以每个周期的列数，得到矩阵的列数 $c = \lceil \frac {n} {t} \rceil * (r - 1)$。
初始化一个`r`行`c`列的矩阵，初始`(x, y) = (0, 0)`，在矩阵左上角，若当前字符满足 `i mod t < r - 1`，则向下移动，否则向右上移动。
## 💻 代码实现
> my answer
```cpp
class Solution {
public:
    string convert(string s, int numRows) {
        int n = s.size(), r = numRows;
        if (r < 2 || r >= n) return s;
        int t = 2 * r - 2;
        int c = (n + t - 1) / t * (r - 1);
        vector<vector<char>> mat(r, vector<char>(c, ' '));
        for (int i = 0, x = 0, y = 0; i < n; i++) {
            mat[x][y] = s[i];
            if (i % t < r - 1) {
                x++; // 向下移动
            } else {
                x--; // 向右上移动
                y++;
            }
        }
        string res;
        for (int i = 0; i < r; i++) {
            for (int j = 0; j < c; j++) {
                if (mat[i][j] != ' ') res += mat[i][j];
            }
        }
        return res;
    }
};
```
- **时间复杂度**：`O(r*c)`。
- **空间复杂度**：`O(r*c)`。

> to optimize

使用`vector<string> mat`存储矩阵。
```cpp
class Solution {
public:
    string convert(string s, int numRows) {
        int n = s.size(), r = numRows;
        if (r < 2 || r >= n) return s;
        int t = 2 * r - 2;
        int c = (n + t - 1) / t * (r - 1);
        // 初始化：string(c, 0) 将字符串初始化为 c 个 空字符 ('\0')，其 ASCII 码值为 0。
        vector<string> mat(r, string(c, 0));
        for (int i = 0, x = 0, y = 0; i < n; i++) {
            mat[x][y] = s[i];
            if (i % t < r - 1) {
                x++; // 向下移动
            } else {
                x--; // 向右上移动
                y++;
            }
        }
        string res;
        for (auto &row : mat) {
            for (char ch : row) {
                if (ch != '\0') {
                    res += ch;
                }
            }
        }
        return res;
    }
};
```
- **时间复杂度**：`O(r * n)`。矩阵创建与遍历。
- **空间复杂度**：`O(r * n)`。占用 额外空间。

> others' answer

模拟行索引的变化，在遍历 `s`的同时把每个字符填充到`tmp[i]`，巧妙利用`flag`。
- 初始`flag = -1`；
- 当`i == 0 || i == numRows - 1`时，`flag = -flag`。
- `flag`可作为 `idx`的步长。
```cpp
class Solution {
public:
    string convert(string s, int numRows) {
        if (numRows < 2) return s;
        vector<string> tmp(numRows);
        int idx = 0, flag = -1;
        for (char &c : s) {
            tmp[idx].push_back(c);
            if ((idx == 0) || (idx == numRows - 1)) {
                flag = -flag;
            }
            idx += flag;
        }
        string res;
        for (auto &str : tmp) res += str;
        return res;
    }
};
```

- **时间复杂度**：`O(n)`
- **空间复杂度**：`O(n)`。占用额外空间。

>✨ tips
- 使用`flag`同时充当步长以及改变填充方向。
