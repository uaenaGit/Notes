> 🔗[713 - 乘积小于 K 的子数组](https://leetcode.cn/problems/subarray-product-less-than-k/description/)

## 📌 题目描述
> （请在此处粘贴题目描述）

给你一个整数数组 `nums` 和一个整数 `k` ，请你返回子数组内所有元素的乘积严格小于 `k` 的连续子数组的数目。

**示例 1：**

**输入：** nums = [10,5,2,6], k = 100
**输出：** 8
**解释：** 8 个乘积小于 100 的子数组分别为：[10]、[5]、[2]、[6]、[10,5]、[5,2]、[2,6]、[5,2,6]。
需要注意的是 [10,5,2] 并不是乘积小于 100 的子数组。

**示例 2：**

**输入：** nums = [1,2,3], k = 0
**输出：** 0

**提示:** 

- $1 <= nums.length <= 3 * 10^4$
- `1 <= nums[i] <= 1000`
- $0 <= k <= 10^6$

## 💡 解题思路 
思路与[[209. 长度最小的子数组]]类似。
注意：
- 计算满足要求的`[l, r]` 且以固定`r`为右端点的区间数目`cnt`。由于`[l, r]`，`[l + 1, r]`，...，`[r, r]`都满足要求，所以`cnt = r - l + 1`。
## 💻 代码实现
> my answer
```cpp
class Solution {
public:
    int numSubarrayProductLessThanK(vector<int>& nums, int k) {
        if (k <= 1) return 0; // nums[i] >= 1
        int n = nums.size();
        int ans = 0, left = 0;
        int prod = 1;
        for (int right = 0; right < n; right++) {
            prod *= nums[right];
            while (prod >= k) { 
                prod /= nums[left];
                left++;
            }
            // 注意 left 可能大于 right，但是至多 left = right + 1，此时 0 个区间满足
            ans += right - left + 1; // [l, r]满足要求 共有r - l + 1个区间
        }
        return ans;
    }
};
```
- **时间复杂度**：`O(n)`
- **空间复杂度**：`O(1)`
