> 🔗[134 - 加油站](https://leetcode.cn/problems/gas-station/description/?envType=study-plan-v2&envId=top-interview-150)

## 📌 题目描述
> （请在此处粘贴题目描述）

在一条环路上有 `n` 个加油站，其中第 `i` 个加油站有汽油 `gas[i]` 升。

你有一辆油箱容量无限的的汽车，从第 `i` 个加油站开往第 `i+1` 个加油站需要消耗汽油 `cost[i]` 升。你从其中的一个加油站出发，开始时油箱为空。

给定两个整数数组 `gas` 和 `cost` ，如果你可以按顺序绕环路行驶一周，则返回出发时加油站的编号，否则返回 `-1` 。如果存在解，则 **保证** 它是 **唯一** 的。

**示例 1:**

**输入:** gas = [1,2,3,4,5], cost = [3,4,5,1,2]
**输出:** 3
**解释:**
从 3 号加油站(索引为 3 处)出发，可获得 4 升汽油。此时油箱有 = 0 + 4 = 4 升汽油
开往 4 号加油站，此时油箱有 4 - 1 + 5 = 8 升汽油
开往 0 号加油站，此时油箱有 8 - 2 + 1 = 7 升汽油
开往 1 号加油站，此时油箱有 7 - 3 + 2 = 6 升汽油
开往 2 号加油站，此时油箱有 6 - 4 + 3 = 5 升汽油
开往 3 号加油站，你需要消耗 5 升汽油，正好足够你返回到 3 号加油站。
因此，3 可为起始索引。

**示例 2:**

**输入:** gas = [2,3,4], cost = [3,4,3]
**输出:** -1
**解释:**
你不能从 0 号或 1 号加油站出发，因为没有足够的汽油可以让你行驶到下一个加油站。
我们从 2 号加油站出发，可以获得 4 升汽油。 此时油箱有 = 0 + 4 = 4 升汽油
开往 0 号加油站，此时油箱有 4 - 3 + 2 = 3 升汽油
开往 1 号加油站，此时油箱有 3 - 3 + 3 = 3 升汽油
你无法返回 2 号加油站，因为返程需要消耗 4 升汽油，但是你的油箱只有 3 升汽油。
因此，无论怎样，你都不可能绕环路行驶一周。

**提示:**

- `n == gas.length == cost.length`
- $1 <= n <= 10^5$
- $0 <= gas[i], cost[i] <= 10^4$
- 输入保证答案唯一。

## 💡 解题思路 
![image.png](https://cdn.jsdelivr.net/gh/uaenaGit/image-host@main/images20260305094252186.png)

若有解，只要找出从 $0$ 开始的油量最低的加油站即可。
## 💻 代码实现
> my answer
```cpp
class Solution {
public:
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
        int n = gas.size();
        // min_s 不能初始化为 INT_MAX
        int s = 0, min_s = 0, ans = 0;
        for (int i = 0; i < n; i++) {
            s += gas[i] - cost[i];
            if (s < min_s) {
                min_s = s;
                ans = i + 1; // 消耗cost[i]从加油站 i 开到了 i + 1
            }
        }
        return s >= 0 ? ans : -1;
    }
};
```
- **时间复杂度**：`O(n)`
- **空间复杂度**：`O(1)`

> others' answer

假设从加油站 $x$ 出发，每经过一个加油站就加一次油（包括起始加油站），最后一个可以到达的加油站是 $y$（不妨设 $x<y$）。这就说明：
$$\sum_{i = x}^y gas[i] < \sum_{i = x}^y cost[i] ---(1) $$
$$\sum_{i = x}^j gas[i] \geq \sum_{i = x}^j cost[i](For all j \in [x, y) ---(2) $$
（1）表明无法达到加油站 $y$ 的下一个加油站，（2）表明可以达到 $y$ 以及 $y$ 之前的所有加油站。
现在考虑任意一个位于 $x, y$ 之间的加油站 $z$ (包括 $x$ 和 $y$)，我们现在考虑从该加油站出发，能否到达加油站 $y$ 的下一个加油站，即判断 $\sum_{i = z}^y gas[i]$ 与 $\sum_{i = z}^ycost[i]$ 之间的大小关系。
由上面式子：
$$\sum_{i = z}^y gas[i] = \sum_{i = x}^y gas[i] - \sum_{i = x}^{z - 1}gas[i] \\
< \sum_{i = x}^y cost[i] - \sum_{i = x}^{z - 1} gas[i]  < \sum_{i = x}^y cost[i] - \sum_{i = x}^{z - 1}cost[i]  = \sum_{i = z}^y cost[i] $$
从上面的推导中，能够得出结论：从 $x, y$ 之间的任何一个加油站出发，都无法达到加油站 $y$ 的下一个加油站。
所以首先检查第 $0$ 个加油站，试图判断能否环绕一周；如果不能， 就从第一个无法达到的加油站开始继续检查。
```cpp
class Solution {
public:
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
        int n = gas.size(), i = 0;
        while (i < n) {
            int sumGas = 0, sumCost = 0;
            int cnt = 0;
            while (cnt < n) {
                int j = (i + cnt) % n;
                sumGas += gas[j];
                sumCost += cost[j];
                if (sumGas < sumCost) {
                    break; // 从加油站 i 出发走不完有所加油站
                }
                cnt++;
            }
            if (cnt == n) {
                return i;
            } else {
                i = i + cnt + 1; // 从当前 i 到达不了的最后一个加油站出发
            }
        }
        return -1;
    }
};
```

- **时间复杂度**：`O(n)`
- **空间复杂度**：`O(1)`
