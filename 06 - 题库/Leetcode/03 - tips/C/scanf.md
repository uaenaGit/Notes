`scanf` 是 C 标准库 (`<cstdio>`) 中**格式化输入**的基石。尽管 C++ 提供了更安全的 `cin`，但 `scanf` 凭借其在**算法竞赛**中的极致速度、对**特定格式**的精准控制以及**轻量级**特性，依然是程序员必备的核心技能。

本指南不仅涵盖基础用法，更深入解析了**赋值抑制符 (`%*`)**、**扫描集 (`%[...]`)**（类正则功能）、**缓冲区陷阱**以及**高性能技巧**。

# 📚 C/C++ `scanf` 终极完全指南

### 📌 前置准备
```cpp
#include <cstdio>    // C++ 中推荐包含此头文件 (对应 C 的 <stdio.h>)
#include <iostream>
#include <vector>
#include <string>
#include <limits>    // 若混用 cin 需要

using namespace std;
```

> **核心特性速览**：
> 1. **格式化解析**：通过格式字符串精确匹配输入模式（数字、字符、特定集合）。
> 2. **指针传递**：除字符串数组外，所有参数必须传递**变量地址** (`&`)。
> 3. **返回值机制**：返回**成功匹配并赋值的变量个数**，是判断输入结束或错误的黄金标准。
> 4. **空白符智能跳过**：大多数格式符会自动跳过前导空白（空格、Tab、换行），但 `%c` 和 `%[...]` 除外。
> 5. **高性能**：默认情况下比 `cin` 快，是处理百万级数据输入的首选。

## 1️⃣ 函数原型与返回值深度解析

| 方法 | 参数详解 | 返回值 | 功能说明 |
| :--- | :--- | :--- | :--- |
| **`scanf(const char* format, ...)`** | `format`: 格式控制字符串`...`: 可变参数列表 (必须是**地址**) | `int` | 从 `stdin` 读取数据。**返回值 = 成功赋值的变量数量**。- 若遇到 EOF 且无赋值，返回 `EOF` (-1)。- 若中途类型不匹配，返回已成功的个数。 |

### 💡 返回值实战用法
利用返回值可以优雅地处理“读取直到文件尾”或“验证输入格式”。

```cpp
int main() {
    int a, b;
    // 循环读取，直到无法同时读入两个整数 (遇到 EOF 或格式错误)
    while (scanf("%d %d", &a, &b) == 2) {
        printf("Sum: %d\n", a + b);
    }
    
    if (feof(stdin)) {
        printf("到达文件尾，正常结束。\n");
    } else {
        printf("输入格式错误或中途停止。\n");
    }
    return 0;
}
```

## 2️⃣ 格式控制符大全 (Format Specifiers)

格式字符串由 **普通字符**（需严格匹配）和 **转换说明符**（以 `%` 开头）组成。

### 常用转换说明符表

| 格式符 | 对应 C++ 类型 | 说明 | 注意事项 |
| :--- | :--- | :--- | :--- |
| **`%d`** | `int` | 十进制整数 | 自动跳过前导空白。 |
| **`%ld`** | `long` | 长整型 | - |
| **`%lld`** | `long long` | 64位整数 | 竞赛常用，注意是 `lld`。 |
| **`%f`** | `float` | 单精度浮点 | - |
| **`%lf`** | `double` | 双精度浮点 | **⚠️ 重点**：`scanf` 中 `double` **必须**用 `%lf`，`printf` 中可用 `%f`。 |
| **`%c`** | `char` | 单个字符 | **⚠️ 陷阱**：**不**跳过前导空白（会读入空格/换行）。 |
| **`%s`** | `char[]` | 字符串 | 遇空白停止；数组名本身是地址，**不需加 `&`**。 |
| **`%x` / `%o`** | `int` | 十六进制 / 八进制 | 输入时可不带 `0x` 或 `0` 前缀。 |
| **`%p`** | `void*` | 指针地址 | 用于调试打印地址。 |
| **`%[...]`** | `char[]` | **扫描集** | 类似正则，读取指定字符集合（见第 5 节）。 |

> **❗ 铁律**：除了 `%s` 和 `%[...]`（目标为数组）外，**所有**基本类型变量前必须加 `&` 取地址！
> ```cpp
> int n; scanf("%d", &n); // ✅ 正确
> int n; scanf("%d", n);  // ❌ 崩溃 (未定义行为)
> ```

## 3️⃣ 进阶技巧：赋值抑制符 `%*` (Assignment Suppression)

在 `%` 和格式符之间加入 `*`，表示**读取该数据但不存储**（直接丢弃）。这是处理分隔符的神器。

### 💡 场景 A：吃掉数字后的单个分隔符
当你想读取一个数字，并确信后面紧跟一个分隔符（如空格、逗号或换行），且不想让它干扰后续读取时。

```cpp
int n;
char c;
// 输入: 100,
scanf("%d%*c", &n); // %d 读 100, %*c 读 ',' 并丢弃
scanf("%c", &c);    // 现在可以安全读取下一个字符了
```
> **对比**：如果不加 `%*c`，那个逗号会留在缓冲区，被下一个 `%c` 读走。

### 💡 场景 B：跳过不需要的数据
如果你只关心第 1 和第 3 个数据，想跳过中间的。
```cpp
int a, c;
// 输入: 10 20 30
// %d 读 10, %*d 读 20 并丢弃, %d 读 30
scanf("%d %*d %d", &a, &c); 
// 结果: a=10, c=30
```

## 4️⃣ ⚠️ 核心陷阱与解决方案

### 陷阱 1：`%c` 不跳过空白符
`%d`, `%s`, `%lf` 都会自动跳过前面的空格/换行，但 **`%c` 会读取下一个字符，哪怕是空格或换行**。

#### ❌ 错误示范
```cpp
int n; char c;
scanf("%d", &n); // 输入: 10 [回车] -> 缓冲区剩 '\n'
scanf("%c", &c); // ❌ c 读到了 '\n'，而不是用户想输入的下一个字符
```

#### ✅ 解决方案 1：在 `%c` 前加空格（推荐）
格式串中的**空格**代表“跳过任意数量的空白字符”。
```cpp
scanf("%d", &n);
scanf(" %c", &c); // ✅ 注意 %c 前的空格！它会跳过 '\n' 和任何多余空格
```

#### ✅ 解决方案 2：使用 `%*c` 吃掉换行
```cpp
scanf("%d%*c", &n); // 吃掉紧跟的一个字符（通常是换行）
scanf("%c", &c);
```
> **区别**：`" %c"` 更稳健，能跳过多个空白；`%*c` 只吃掉**一个**字符。如果用户输入 `10   ` (多个空格)，`%*c` 只能吃掉第一个空格，剩下的还会干扰。

### 陷阱 2：缓冲区溢出 (`%s`)
`scanf("%s", buf)` 不检查长度，极易导致溢出。

#### ✅ 解决方案：指定最大宽度
```cpp
char buf[20];
// 读取最多 19 个字符 (留 1 位给 '\0')
scanf("%19s", buf); 
```

### 陷阱 3：Double 必须用 `%lf`
```cpp
double d;
scanf("%lf", &d); // ✅ 正确
scanf("%f", &d);  // ❌ 错误！会导致数据读取异常
```

## 5️⃣ 类正则功能：扫描集 `%[...]` (Scan Sets)

这是 `scanf` 最强大的功能，允许定义字符集合进行匹配，行为类似正则表达式中的 `[...]`。

### 语法详解
| 写法 | 含义 | 正则类比 | 典型用途 |
| :--- | :--- | :--- | :--- |
| **`%[abc]`** | 只读取 'a', 'b', 'c' | `[abc]` | 提取特定字符序列 |
| **`%[^abc]`** | 读取**非** 'a', 'b', 'c' 的字符 | `[^abc]` | 遇到特定字符停止 |
| **`%[0-9]`** | 只读取数字 | `[0-9]` | 提取数字串（结果为字符串） |
| **`%[^\n]`** | 读取直到换行符 | `[^\n]` | **读取整行（含空格）** |
| **`%[^,]`** | 读取直到逗号 | `[^,]` | **CSV 解析** |

### 💻 代码示例 1：安全读取整行 (替代 `gets`)
```cpp
char line[100];
// 读取直到换行符，最多 99 个字符
// 注意：换行符 '\n' 会留在缓冲区，不会被消耗
if (scanf("%99[^\n]", line) == 1) {
    printf("整行内容: %s\n", line);
}
```

### 💻 代码示例 2：解析 CSV 数据
假设输入：`Alice,25,New York`
```cpp
char name[50], city[50];
int age;

// 1. %[^,] 读 "Alice" (遇逗号停)
// 2. , 匹配并跳过逗号
// 3. %d 读 25
// 4. , 匹配并跳过逗号
// 5. %[^\n] 读 "New York" (遇换行停)
scanf("%[^,],%d,%[^\n]", name, &age, city);

printf("Name: %s, Age: %d, City: %s\n", name, age, city);
```

## 6️⃣ 性能优化与混用警告

### ⚡ 为什么 `scanf` 快？
`scanf` 是 C 风格函数，没有 C++ 流的重载、类型检查和同步开销。在处理 **10^5 ~ 10^6** 级别的数据输入时，`scanf` 通常比默认 `cin` 快 2-3 倍。

### 🚫 混用 `cin` 和 `scanf` 的禁忌
默认情况下，C++ 为了兼容，会将 `cin` 和 `scanf` 同步。这意味着你可以混用，但**速度慢**。
如果你执行了以下优化代码：
```cpp
ios::sync_with_stdio(false); // 关闭同步，大幅提升 cin 速度
cin.tie(nullptr);
```
**⚠️ 警告**：一旦关闭同步，**严禁**再混用 `cin/cout` 和 `scanf/printf`！否则输入输出顺序会完全乱套，导致不可预知的错误。

**最佳策略**：
*   **方案 A (纯 C 风格)**：全篇使用 `scanf` + `printf`。适合算法竞赛，追求极致速度。
*   **方案 B (纯 C++ 风格)**：全篇使用 `cin` + `cout`，并关闭同步。适合现代 C++ 工程，类型安全且速度足够快。
*   **不要**：在同一个逻辑块中交替使用两者。

## 7️⃣ `scanf` vs `cin` 终极对比表

| 特性 | `scanf` / `printf` | `cin` / `cout` (关闭同步后) |
| :--- | :--- | :--- |
| **速度** | ⭐⭐⭐⭐⭐ (原生快) | ⭐⭐⭐⭐⭐ (关闭同步后相当) |
| **类型安全** | ❌ 低 (格式符错即崩) | ✅ 高 (编译器自动推导) |
| **语法简洁** | 紧凑，但需记忆格式符 | 直观，流式操作 `<<` `>>` |
| **字符串处理** | 需手动限宽，`%[^\n]` 较繁琐 | `getline` 方便，`string` 自动扩容 |
| **自定义类型** | ❌ 不支持 | ✅ 支持 (重载运算符) |
| **主要场景** | 算法竞赛、嵌入式、遗留代码 | 现代 C++ 开发、复杂业务逻辑 |

## 8️⃣ 总结与最佳实践口诀

### ✅ 最佳实践清单
1.  **地址符**：基本类型必加 `&`，数组名不用加。
2.  **Double**：`scanf` 中永远用 `%lf`。
3.  **字符读取**：`%c` 前务必加空格 `" %c"` 或使用 `%*c` 清理缓冲区。
4.  **防溢出**：`%s` 和 `%[...]` 必须指定宽度（如 `%19s`）。
5.  **返回值**：循环读取时，务必检查 `scanf` 返回值是否等于预期个数。
6.  **不混用**：选定一套 I/O 系统坚持到底，特别是关闭同步后。

### 🗣️ 终极口诀
> “格式化用 scanf，地址符号莫忘记；
> Double 必须 lf 配，字符前面加空格；
> **想吃分隔符，星号 `%*c` 来帮忙；**
> **整行读取难，`%[^\n]` 显神威；**
> 宽度限制防溢出，返回值查保平安；
> 竞赛刷题它最快，工程开发 cin 先。”
