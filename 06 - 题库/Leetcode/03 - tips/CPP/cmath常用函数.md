这些函数都定义在 C++ 的标准头文件 **`<cmath>`** (C 语言中是 `<math.h>`) 中。它们是处理浮点数运算的核心工具。

为了方便理解，我将它们分为 **取整类**、**基础运算类**、**三角/指数类** 和 **其他常用类** 进行详细解释，并附带了**负数行为对比**（这是最容易出错的地方）。

---

### 1. 取整类函数 (Rounding Functions)
这些函数接收 `double`，返回 `double`（即使结果是整数）。如果需要 `int`，通常需要强制转换 `(int)`。

| 函数             | 含义   | 规则 (方向)          | 正数示例 (`3.7`) | 负数示例 (`-3.7`) | 特殊点 (`.5`)      |
| :------------- | :--- | :--------------- | :----------- | :------------ | :-------------- |
| **`ceil(x)`**  | 向上取整 | 向 **正无穷** (`+∞`) | `4.0`        | `-3.0`        | `-3.5` → `-3.0` |
| **`floor(x)`** | 向下取整 | 向 **负无穷** (`-∞`) | `3.0`        | `-4.0`        | `-3.5` → `-4.0` |
| **`round(x)`** | 四舍五入 | 最近整数，**.5 远离零**  | `4.0`        | `-4.0`        | `-3.5` → `-4.0` |
| **`trunc(x)`** | 截断取整 | 向 **零** (`0`)    | `3.0`        | `-3.0`        | `-3.5` → `-3.0` |

*   **记忆口诀**：
    *   `ceil` (天花板)：永远往上顶。
    *   `floor` (地板)：永远往下掉。
    *   `trunc` (切断)：直接砍掉小数，只看整数部分。
    *   `round`：看缘分（≥0.5 进位），负数进位是变得更“小”（更负）。

> **注意**：C++ 中没有直接返回 `int` 的取整函数，返回值都是 `double`。
> 写法：`int n = (int)round(3.7);`

### 2. 基础运算类 (Basic Arithmetic)

| 函数                | 原型                                 | 功能                         | 示例                                       | 备注                                  |
| :---------------- | :--------------------------------- | :------------------------- | :--------------------------------------- | :---------------------------------- |
| **`fabs(x)`**     | `double fabs(double x)`            | **浮点绝对值**                  | `fabs(-5.5)` → `5.5`                     | 专用于浮点数。整数请用 `<cstdlib>` 中的 `abs()`。 |
| **`pow(x, y)`**   | `double pow(double x, double y)`   | **幂运算** ($x^y$)            | `pow(2, 3)` → `8.0``pow(9, 0.5)` → `3.0` | 计算 $x$ 的 $y$ 次方。效率低于连乘，但通用性强。       |
| **`sqrt(x)`**     | `double sqrt(double x)`            | **平方根** ($\sqrt{x}$)       | `sqrt(16.0)` → `4.0`                     | 若 $x < 0$，返回 `NaN` (非数字)。           |
| **`cbrt(x)`**     | `double cbrt(double x)`            | **立方根** ($\sqrt[3]{x}$)    | `cbrt(-27.0)` → `-3.0`                   | C++11 引入。支持负数开立方。                   |
| **`hypot(x, y)`** | `double hypot(double x, double y)` | **斜边长** ($\sqrt{x^2+y^2}$) | `hypot(3, 4)` → `5.0`                    | 比手动写 `sqrt(x*x + y*y)` 更安全，不易溢出。    |

### 3. 三角函数类 (Trigonometric Functions)
**重要前提**：所有三角函数的输入单位必须是 **弧度 (Radians)**，而不是角度 (Degrees)。
*   转换公式：`弧度 = 角度 * π / 180.0`
*   π 的获取：`const double PI = acos(-1.0);` 或 C++20 的 `std::numbers::pi`。

| 函数                | 功能         | 示例                                                                       |
| :---------------- | :--------- | :----------------------------------------------------------------------- |
| **`sin(x)`**      | 正弦         | `sin(PI / 2)` → `1.0`                                                    |
| **`cos(x)`**      | 余弦         | `cos(0)` → `1.0`                                                         |
| **`tan(x)`**      | 正切         | `tan(PI / 4)` → `1.0`                                                    |
| **`asin(x)`**     | 反正弦        | 返回弧度，范围 $[-\pi/2, \pi/2]$                                                |
| **`acos(x)`**     | 反余弦        | 返回弧度，范围 $[0, \pi]$                                                       |
| **`atan(x)`**     | 反正切        | 返回弧度，范围 $[-\pi/2, \pi/2]$                                                |
| **`atan2(y, x)`** | **四象限反正切** | `atan2(1, 1)` → $\pi/4$。**推荐用这个**代替 `atan(y/x)`，因为它能处理 $x=0$ 的情况并自动判断象限。 |

### 4. 指数与对数类 (Exponential & Logarithmic)

| 函数              | 功能    | 数学公式               | 示例                           |
| :-------------- | :---- | :----------------- | :--------------------------- |
| **`exp(x)`**    | 自然指数  | $e^x$              | `exp(1)` → `2.718...` ($e$)  |
| **`log(x)`**    | 自然对数  | $\ln(x)$ (底数为 $e$) | `log(exp(5))` → `5.0`        |
| **`log10(x)`**  | 常用对数  | $\log_{10}(x)$     | `log10(100)` → `2.0`         |
| **`log2(x)`**   | 二进制对数 | $\log_{2}(x)$      | `log2(8)` → `3.0`            |
| **`log(b, x)`** | 任意底对数 | $\log_{b}(x)$      | C++11 引入，`log(2, 8)` → `3.0` |

> **注意**：对数函数的参数 $x$ 必须 $>0$，否则返回 `NaN` 或报错。

### 5. 其他常用工具函数

| 函数                    | 功能       | 说明                                             |
| :-------------------- | :------- | :--------------------------------------------- |
| **`fmod(x, y)`**      | **浮点取模** | 计算 $x \div y$ 的余数。例如 `fmod(5.5, 2.0)` → `1.5`。 |
| **`remainder(x, y)`** | IEEE 余数  | 与 `fmod` 类似，但采用“最近整数”商来计算余数，结果可能为负。            |
| **`nan(str)`**        | 生成 NaN   | 生成一个 "Not a Number" 值。                         |
| **`isinf(x)`**        | 判断无穷     | 如果 $x$ 是 $+\infty$ 或 $-\infty$ 返回 `true`。      |
| **`isnan(x)`**        | 判断非数字    | 如果 $x$ 是 `NaN` 返回 `true`。                      |
| **`max(a, b)`**       | 最大值      | 需包含 `<algorithm>`。返回两者较大者。                     |
| **`min(a, b)`**       | 最小值      | 需包含 `<algorithm>`。返回两者较小者。                     |

### 6. 代码实战演示

```cpp
#include <iostream>
#include <cmath>        // 数学函数核心头文件
#include <algorithm>    // max, min
#include <iomanip>      // 控制输出精度

using namespace std;

int main() {
    double d = -3.7;
    const double PI = acos(-1.0); // 获取 PI

    cout << fixed << setprecision(2); // 设置输出保留2位小数

    cout << "--- 取整测试 (d = " << d << ") ---" << endl;
    cout << "ceil:     " << ceil(d) << endl;     // -3.00
    cout << "floor:    " << floor(d) << endl;    // -4.00
    cout << "round:    " << round(d) << endl;    // -4.00
    cout << "trunc:    " << trunc(d) << endl;    // -3.00
    cout << "fabs:     " << fabs(d) << endl;     // 3.70

    cout << "\n--- 幂与根 ---" << endl;
    cout << "pow(2, 10): " << pow(2, 10) << endl; // 1024.00
    cout << "sqrt(16):   " << sqrt(16) << endl;   // 4.00
    cout << "cbrt(-27):  " << cbrt(-27) << endl;  // -3.00

    cout << "\n--- 三角函数 (角度转弧度) ---" << endl;
    double angle_deg = 60.0;
    double angle_rad = angle_deg * PI / 180.0;
    cout << "sin(60°): " << sin(angle_rad) << endl; // 0.87

    cout << "\n--- 其他 ---" << endl;
    cout << "fmod(5.5, 2): " << fmod(5.5, 2.0) << endl; // 1.50
    cout << "max(3.0, 5.5): " << max(3.0, 5.5) << endl; // 5.50
    
    // 检查错误
    double invalid = sqrt(-1.0);
    if (isnan(invalid)) {
        cout << "sqrt(-1) 结果是 NaN (无效数字)" << endl;
    }

    return 0;
}
```

### 7. 常见坑点总结

1.  **整数除法陷阱**：
    在调用这些函数前，确保传入的是浮点数。
    *   错误：`sqrt(2/3)` → `2/3` 在 C++ 中是整数除法等于 `0`，结果是 `sqrt(0)=0`。
    *   正确：`sqrt(2.0/3.0)` 或 `sqrt((double)2/3)`。

2.  **`pow` 的性能**：
    如果是简单的平方或立方，直接写 `x*x` 或 `x*x*x` 比 `pow(x, 2)` 快得多。`pow` 适合指数是小数或变量的情况。

3.  **浮点数精度比较**：
    比较两个 `double` 是否相等（因为精度误差）。
    *   错误：`if (a == b)`
    *   正确：`if (fabs(a - b) < 1e-9)` (判断差值是否极小)。

4.  **角度与弧度**：
    再次强调，`sin`, `cos` 等函数**只认弧度**。如果你传入 `sin(90)`，它计算的是 90 弧度的正弦值（约等于 0.89），而不是 1。

掌握这些函数，你就拥有了 C++ 中进行科学计算和工程处理的基础能力。
