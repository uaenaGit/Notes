在 C++ 中，重载其他运算符的语法结构非常统一：
**`返回类型 operator 运算符符号 (参数列表) [const]`**

核心规则只有一条：**`operator` 关键字后面必须紧跟着你要重载的那个符号**（中间可以有空格，但逻辑上是一体的）。

以下是常用运算符的重载模板和示例：

---

### 1️⃣ 算术运算符 (`+`, `-`, `*`, `/`)
通常用于实现两个对象的加减乘除。
- **成员函数写法**：左操作数是 `this`，右操作数是参数。
- **非成员函数写法**（推荐）：左右操作数都是参数，方便支持 `int + Fruit` 这种混合运算。

```cpp
struct Fruit {
    int price;
    
    // 【成员函数】Fruit + Fruit
    // 用法：f1 + f2  ->  f1.operator+(f2)
    Fruit operator+(const Fruit& other) const {
        return Fruit(price + other.price);
    }

    // 【成员函数】Fruit += int
    // 用法：f1 += 10 -> f1.operator+=(10)
    Fruit& operator+=(int val) {
        price += val;
        return *this;
    }
};

// 【非成员函数】推荐写法：支持 int + Fruit
// 用法：10 + f1
Fruit operator+(int val, const Fruit& f) {
    return Fruit(f.price + val);
}
```

### 2️⃣ 比较运算符 ($==, !=, >, <=, >=$)
除了 `<` (你之前问的)，其他比较符写法类似。
*注意：C++20 引入了 `<=>` (太空船运算符)，可以自动生成所有比较符，但在 C++11/14/17 中需手动写。*

```cpp
struct Fruit {
    string name;
    int price;

    // 等于 ==
    bool operator==(const Fruit& other) const {
        return price == other.price && name == other.name;
    }

    // 不等于 != (通常利用 == 取反)
    bool operator!=(const Fruit& other) const {
        return !(*this == other);
    }

    // 大于 >
    bool operator>(const Fruit& other) const {
        return price > other.price;
    }
    
    // 小于等于 <=
    bool operator<=(const Fruit& other) const {
        return !(*this > other);
    }
};
```

### 3️⃣ 输入输出流运算符 (`<<`, `>>`)
**必须**写成**非成员函数**（通常是 `friend` 友元函数），因为左操作数是 `ostream` 或 `istream`，你无法修改标准库的类。

```cpp
#include <iostream>
using namespace std;

struct Fruit {
    string name;
    int price;
    
    // 声明友元，允许函数访问私有成员
    friend ostream& operator<<(ostream& os, const Fruit& f);
    friend istream& operator>>(istream& is, Fruit& f);
};

// 重载 << (输出)
// 用法：cout << f;
ostream& operator<<(ostream& os, const Fruit& f) {
    os << f.name << ":" << f.price;
    return os; // 必须返回流对象以支持链式调用 cout << f1 << f2;
}

// 重载 >> (输入)
// 用法：cin >> f;
istream& operator>>(istream& is, Fruit& f) {
    is >> f.name >> f.price;
    return is;
}
```

### 4️⃣ 下标运算符 (`[]`)
用于像数组一样访问对象，**必须**是成员函数。通常需要写两个版本：一个用于读取（const），一个用于修改（非 const）。

```cpp
struct MyArray {
    int data[10];

    // 非 const 版本：允许修改 data[i] = 5;
    int& operator[](int index) {
        return data[index];
    }

    // const 版本：只读访问，如 cout << arr[i];
    const int& operator[](int index) const {
        return data[index];
    }
};
```

---

### 5️⃣ 函数调用运算符 (`()`)
让对象像函数一样被调用（仿函数），常用于自定义排序规则或线程任务。

```cpp
struct Adder {
    int base;
    Adder(int b) : base(b) {}

    // 重载 ()
    // 用法：Adder add(10); int res = add(5); // 结果 15
    int operator()(int x) const {
        return base + x;
    }
};
```

### 6️⃣ 自增自减 (`++`, `--`)
需要区分**前置** (`++i`) 和**后置** (`i++`)。
- **前置**：没有额外参数。
- **后置**：有一个 dummy `int` 参数作为标记。

```cpp
struct Counter {
    int val;
    
    // 前置 ++ (先加后用)
    // 用法：++c
    Counter& operator++() {
        val++;
        return *this;
    }

    // 后置 ++ (先用后加)
    // 用法：c++
    // 注意那个多余的 int 参数，它只是为了区分前置后置，调用时不用传
    Counter operator++(int) {
        Counter temp = *this; // 保存旧值
        val++;                // 自增
        return temp;          // 返回旧值
    }
};
```

### ⚠️ 不能重载的运算符
以下运算符**禁止**重载：
- `::` (作用域解析)
- `.*` (成员指针访问)
- `.` (成员访问)
- `?:` (三元条件运算符)
- `sizeof`, `typeid`, `alignof` 等关键字

### 📝 总结速查表

| 运算符           | 写法示例              | 必须是成员函数？ | 备注                    |
| :------------ | :---------------- | :------- | :-------------------- |
| **算术** (`+`)  | `operator+`       | 否        | 推荐非成员以便混合运算           |
| **比较** ($==$) | `operator==`      | 否        | 常配合 `<` 使用            |
| **流** (`<<`)  | `operator<<`      | **否**    | 必须是友元或非成员             |
| **下标** (`[]`) | `operator[]`      | **是**    | 通常写 const 和非 const 两版 |
| **调用** (`()`) | `operator()`      | **是**    | 仿函数                   |
| **赋值** (`=`)  | `operator=`       | **是**    | 编译器默认生成浅拷贝，深拷贝需手写     |
| **前置++**      | `operator++`      | **是**    | 无参数                   |
| **后置++**      | `operator++(int)` | **是**    | 带 `int` 哑元参数          |

**口诀**：
> **Operator 后跟符号走，空格可有无强求。**
> **流运算符必友元，下标调用成员守。**
> **前后自增看参数，后置多把 int 留。**
> **点号作用域不可动，三元尺寸莫强扭。**
