`std::setw` 和 `std::setfill` 是 C++ 标准库 `<iomanip>` 头文件中提供的两个**流操纵符（Manipulators）**。它们主要用于控制输出流的格式，特别是在需要对齐文本或补零（如日期、时间、编号）时非常有用。

### 1. `std::setw(n)` (Set Width)
*   **含义**：设置**下一个**输出项的**最小字段宽度**。
*   **参数**：`n` 是一个整数，表示宽度。
*   **行为**：
    *   如果输出内容的长度 **小于** `n`：默认在左侧填充空格（除非配合 `std::left`），直到总长度达到 `n`。
    *   如果输出内容的长度 **大于或等于** `n`：**不会截断**，而是完整输出实际内容（宽度自动扩展）。
*   **重要特性**：**它只对紧接着的下一个输出项生效**。之后的输出项会恢复为默认宽度（即内容实际长度）。

### 2. `std::setfill(c)` (Set Fill Character)
*   **含义**：设置当输出内容宽度不足时，用于填充的**字符**。
*   **参数**：`c` 是一个字符（如 `'0'`, `'*'`, `' '` 等）。
*   **行为**：当配合 `setw` 使用且内容长度不足时，用 `c` 代替默认的空格进行填充。
*   **重要特性**：**它是持久的**。一旦设置，它会一直生效，直到你再次调用 `setfill` 修改它。

### 代码示例：日期格式化
这是最典型的应用场景：将 `2023-5-9` 格式化为 `2023-05-09`。

```cpp
#include <iostream>
#include <iomanip> // 必须包含此头文件

using namespace std;

int main() {
    int year = 2023;
    int month = 5;
    int day = 9;
    int hour = 8;
    int minute = 5;
    int second = 1;

    cout << "默认输出: " << year << "-" << month << "-" << day << " " 
         << hour << ":" << minute << ":" << second << endl;

    cout << "格式化输出: ";
    
    // 年：宽度4，不足补0 (虽然2023已经是4位，但为了通用性)
    cout << setw(4) << setfill('0') << year << "-";
    
    // 月：宽度2，不足补0 -> 输出 "05"
    cout << setw(2) << setfill('0') << month << "-";
    
    // 日：宽度2，不足补0 -> 输出 "09"
    // 注意：setfill('0') 是持久的，这里不需要再次写 setfill('0')，但写了也没错
    cout << setw(2) << setfill('0') << day << " ";
    
    // 时：宽度2 -> "08"
    cout << setw(2) << hour << ":";
    
    // 分：宽度2 -> "05"
    cout << setw(2) << minute << ":";
    
    // 秒：宽度2 -> "01"
    cout << setw(2) << second << endl;

    return 0;
}
```

**输出结果：**
```text
默认输出: 2023-5-9 8:5:1
格式化输出: 2023-05-09 08:05:01
```

### 关键细节与常见坑

#### 1. `setw` 的“一次性”特性
`setw` **只影响下一个变量**。如果你连续输出两个变量并希望都定宽，必须对每个变量都调用 `setw`。

```cpp
// 错误写法
cout << setw(2) << 5 << 6; 
// 输出: " 56" (只有5被格式化为" 5"，6紧挨着输出)

// 正确写法
cout << setw(2) << 5 << setw(2) << 6; 
// 输出: " 5 6"
```

#### 2. `setfill` 的“持久性”特性
`setfill` 设置后会一直保持，直到程序结束或再次修改。

```cpp
cout << setfill('*');
cout << setw(5) << 10 << endl; // 输出: "***10"
cout << setw(5) << 20 << endl; // 输出: "***20" (依然生效)
cout << setfill(' ');          // 手动改回空格
cout << setw(5) << 30 << endl; // 输出: "   30"
```

#### 3. 对齐方向
默认是**右对齐**（填充在左边）。你可以使用 `std::left` 改为左对齐（填充在右边）。

```cpp
cout << "|" << setw(5) << setfill('-') << 10 << "|" << endl; 
// 默认右对齐: "|---10|"

cout << "|" << left << setw(5) << setfill('-') << 10 << "|" << endl; 
// 左对齐:     "|10---|"
// 注意：left 也是持久的
```

### 总结表

| 操纵符 | 头文件 | 作用范围 | 默认行为 | 典型用途 |
| :--- | :--- | :--- | :--- | :--- |
| **`setw(n)`** | `<iomanip>` | **仅下一个**输出项 | 宽度为0 (按实际长度) | 固定列宽、表格对齐 |
| **`setfill(c)`** | `<iomanip>` | **持久** (直到下次修改) | 填充字符为空格 `' '` | 补零 (`0`)、制作分割线 (`-`) |

在处理 `YYYY-MM-DD HH:MM:SS` 这种格式时，通常的模式是：
`cout << setfill('0') << setw(2) << month;`
因为 `setfill('0')` 设一次就够了，后面每个需要补零的数字前只需加 `setw(2)`。
