## 📌 题目描述
> （请在此处粘贴题目描述）

### 题目描述
现有一个整数序列 $a_1, a_2, \dots, a_n$，求连续子序列 $a_i + \dots + a_j$ 的最大值。

### 输入描述
第一行一个正整数 $n$（$1 \le n \le 10^4$），表示序列长度；
第二行为用空格隔开的 $n$ 个整数 $a_i$（$-10^5 \le a_i \le 10^5$），表示序列元素。

### 输出描述
输出一个整数，表示最大连续子序列和。

### 样例1

**输入**
6
-2 11 -4 13 -5 -2
  
**输出**
20

**解释**
连续子序列和的最大值为：$11 + (-4) + 13 = 20$


## 💡 解题思路 
整体思路：动态规划的核心思想是将大问题分解为小问题来解决。对于本题，我们可以定义一个状态 $dp[i]$ 表示以第 $i$ 个元素结尾的最大连续子序列和。状态转移方程为：
$$
dp[i] = \max(a[i], dp[i-1] + a[i])
$$
这个方程的意思是，以第 $i$ 个元素结尾的最大连续子序列和要么是当前元素本身（$a[i]$），要么是前一个最大连续子序列和加上当前元素（$dp[i-1] + a[i]$）。

## 💻 代码实现
> my answer

记忆化搜索。
```cpp
#include <iostream>
#include <climits>
#include <vector>

using namespace std;
const int N = 10010;
int a[N];
vector<int> memo(N, INT_MIN);

int dfs(int i) {
    if (i == 0) {
        return a[i];
    }
    int &res = memo[i];
    if (res != INT_MIN) {
        return res;
    }
    return res = max(a[i], dfs(i - 1) + a[i]);
}

int main()
{
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    int ans = INT_MIN;
    for (int i = 0; i < n; i++) {
        ans = max(ans, dfs(i));
    }
    cout << ans << endl;

    return 0;
}
```
- **时间复杂度**：$O(n)$
- **空间复杂度**：$O(n)$

```cpp
#include <iostream>
#include <climits>
#include <vector>

using namespace std;
const int N = 10010;
int a[N];
vector<int> f(N, INT_MIN);

int main()
{
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    int ans = INT_MIN;
    f[0] = a[0];
    for (int i = 1; i < n; i++) {
        f[i] = max(a[i], f[i - 1] + a[i]);
    }
    for (int i = 0; i < n; i++) {
        ans = max(ans, f[i]);
    }
    cout << ans << endl;
    return 0;
}
```
- **时间复杂度**：$O(n)$
- **空间复杂度**：$O(n)$
