> 🔗[418 - 有向无环图固定终点的最长路](https://sunnywhy.com/camp/3415/model/3590?itemId=2997)

## 📌 题目描述
> （请在此处粘贴题目描述）

### 题目描述
现有一个共 $n$ 个顶点、$m$ 条边的有向无环图（假设顶点编号为从 $0$ 到 $n-1$），求到达指定终点 $T$ 的所有路径中边权之和的最大值（不固定起点）。

### 输入描述
- 第一行三个整数 $n、m、t$（$2 \le n \le 100, 1 \le m \le n(n-1), 0 \le t \le n-1$），分别表示顶点数、边数、终点编号；
- 接下来 $m$ 行，每行三个整数 $u、v、w$（$0 \le u \le n-1, 0 \le v \le n-1, u \neq v, 1 \le w \le 100$），表示一条边的起点和终点的编号及边权。数据保证不会有重边。

### 输出描述
输出一个整数，表示固定终点的路径上边权之和的最大值。

### 样例1
**输入**
6 7 5
0 1 1
0 2 2
1 3 3
1 4 4
2 4 2
3 5 2
4 5 3

**输出**
8

## 💡 解题思路 
思路参考[[416. 有向无环图的最长路]]。初始化 `dp[t] = 0`，即终点到自身的距离为0.
本题与[[416. 有向无环图的最长路]]的区别在于`dp`数组的初始化不同，对于本题，`dp` 数组初始化为`-INF`，
`dfs`内部，`dp[i] >= 0`时`return dp[i]`保证了一定会走到终点`t`。
## 💻 代码实现
> my answer
```cpp
#include <iostream>
#include <cstring>
#include <algorithm>

using namespace std;
int n, m, t;
const int N = 110, INF = 0x3f3f3f3f;
int g[N][N];
int dp[N];

int dfs(int i) {
    if (dp[i] >= 0) {
        return dp[i];
    }
    for (int j = 0; j < n; j++) {
        if (g[i][j] != INF) {
            dp[i] = max(dp[i], dfs(j) + g[i][j]);
        }
    }
    return dp[i];
}

int main()
{
    memset(g, 0x3f, sizeof(g));
    fill(dp, dp + N, -INF);
    cin >> n >> m >> t;
    for (int i = 0; i < m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        g[u][v] = w;
    }
    int ans = 0;
    dp[t] = 0; // 终点到自身的距离为0
    for (int i = 0; i < n; i++) {
        ans = max(ans, dfs(i));
    }
    cout << ans << endl;
    return 0;
}
```
- **时间复杂度**：$O(n + m)$
**最终结论**：$O(n + m)$（最坏情况下等价于 $O(n^2)$，因为有向无环图的边数最大为 $n(n-1)$）
**详细分析**：
- 该代码采用**记忆化DFS**（深度优先搜索）实现，核心逻辑是对每个节点只进行一次完整的递归计算：
  - 初始化阶段：`memset` 和 `fill` 操作是 $O(n^2) + O(n)$，但实际有效边只有 $m$ 条，可简化为 $O(n + m)$；
  - DFS递归：每个节点 $i$ 只会被访问一次（因为 `dp[i]` 记忆化后不会重复计算），每条边 $(i,j)$ 也只会被遍历一次；
  - 主循环：遍历 $n$ 个节点调用DFS，总递归次数等于节点数 $n$ + 边数 $m$，即 $O(n + m)$。
- 补充：由于题目中 $m \le n(n-1)$，因此最坏时间复杂度为 $O(n^2)$，但通常按稀疏图的 $O(n + m)$ 描述更准确。
- **空间复杂度**：$O(n ^ 2)$
**详细分析**：
- 邻接矩阵 `g[N][N]`：占用 $O(n^2)$ 空间（$N=110$ 是固定常量，但逻辑上按问题规模 $n$ 分析）；
- 记忆化数组 `dp[N]`：占用 $O(n)$ 空间；
- 递归调用栈：有向无环图的最大递归深度为节点数 $n$，占用 $O(n)$ 空间；
- 其他变量（`n/m/t/ans` 等）：$O(1)$ 常数空间。
- 核心占用：邻接矩阵是空间开销的主要来源，因此总空间复杂度为 $O(n^2)$。
