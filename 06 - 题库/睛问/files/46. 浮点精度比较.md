> 🔗[46 - 浮点精度比较](https://sunnywhy.com/camp/3415/model/3442?itemId=2769)

## 📌 题目描述
> （请在此处粘贴题目描述）

输入四个正整数`A`、`B`、`C`、`D`，输出以下两个公式的比较结果：
$$
\begin{align}
1. A * arcsin(\frac {\sqrt{B}} {2}) \\
2. C * arcsin(\frac {\sqrt{D}} {2})
\end{align}
$$
**输入描述：**
输入四个正整数`A`、`B`、`C`、`D`($1 \leq A, B, C, D \leq 20$)。

**输出描述：**
如果公式1较大，输出1；

如果公式2较大，输出2；

如果相等，输出0。

**样例：**

*输入*:
4 2 3 3

*输出*:
0

## 💡 解题思路 
本题考察 **浮点数的比较**。

由于浮点数的计算容易产生精度误差，因此对浮点数之间的比较需要特殊处理。

本题涉及大于和小于两种比较（大于等于和小于等于同理）：

- 当 $a - b$ 大于一个正的很小的数（例如 $10 ^ {-8}$）时，可以认为 $a > b$ 
- 当 $a - b$ 小于一个**负的绝对值**很小的数（例如 $-10^{-8}$）时，可以认为 $a < b$

## 💻 代码实现
> my answer
```cpp
#include <iostream>
#include <cmath>
using namespace std;

const double EPS = 1e-8;  // 定义比较精度

// 判断 a 是否明显大于 b
bool greater(double a, double b) {
    return a - b > EPS;
}

// 判断 a 是否明显小于 b
bool less(double a, double b) {
    return a - b < -EPS;
}

int main() {
    double a, b, c, d;
    // 从标准输入读取四个双精度数
    cin >> a >> b >> c >> d;
    // 计算两个结果：a * asin(sqrt(b)/2) 和 c * asin(sqrt(d)/2)
    double result1 = a * asin(sqrt(b) / 2);
    double result2 = c * asin(sqrt(d) / 2);
    // 根据比较结果输出相应标志
    if (greater(result1, result2)) {
        cout << "1";
    } else if (less(result1, result2)) {
        cout << "2";
    } else {
        cout << "0";
    }
    return 0;
}
```
