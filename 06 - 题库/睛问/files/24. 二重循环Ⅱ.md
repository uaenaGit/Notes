## 📌 题目描述
> （请在此处粘贴题目描述）

输入一个正整数，输出行，其中第`i`行为从`1`到`i` 的所有正整数。

输入描述:
一个正整数 `n(1 ≤ 10)`.

输出描述：
共`n`行，其中第`i`行为从`1`到`i`的所有正整数。整数间用一个空格隔开，行末不允许有多余的空格。

样例1
输入：
3
输出：
1
1 2
1 2 3
## 💡 解题思路 
模拟即可。

## 💻 代码实现
> my answer
```cpp
#include <cstdio>

int main() {
    int n;
    // 读取整数 n
    scanf("%d", &n);
    // 外层循环，控制行数，从 1 到 n
    for (int i = 1; i <= n; i++) {
        // 内层循环，打印当前行的 1 到 i
        for (int j = 1; j <= i; j++) {
            // 打印数字 j
            printf("%d", j);
            // 如果不是本行最后一个数字则打印空格，否则打印换行
            printf(j < i ? " " : "\n");
        }
    }
    return 0;
}
```
- **时间复杂度**：`O(1)`
- **空间复杂度**：`O(1)`
