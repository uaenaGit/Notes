## 💡 解题思路 
使用二分。首先明确二分边界，由于随着`h`增大，`s1 / s2` 增大，存在单调性，所以可以使用二分。显然`h`介于`[0, R]`之间。那么什么时候找到相应的`h`呢？可以自定义`eps = 1e-8`误差精度，当`r - l <= eps`时可以退出二分。

## 💻 代码实现
> my answer
```cpp
#include <iostream>
#include <cmath>

using namespace std;
const double PI = acos(-1.0); // cos(PI) = -1
const double eps = 1e-8;

double area(double R, double h){
    double alpha = acos((R - h) / R);
    double s2 = PI * R * R / 2;
    double L = sqrt(R * R - (R - h) * (R - h));
    double s1 = alpha * R * R - L * (R - h);
    return s1 / s2;
}

double binarySearch(double R, double ratio) {
    double l = 0, r = R;
    while (r - l > eps) {
        double mid = (l + r) / 2;
        if (area(R, mid) > ratio) {
            r = mid;
        } else {
            l = mid;
        }
    }
    return l;
}

int main()
{
    double R, r;
    scanf("%lf%lf", &R, &r);
    double h = binarySearch(R, r);

    printf("%.2f", h);
    return 0;
}
```
- **时间复杂度**：$O(\log (\frac {R} {eps}))$ 。取决于二分次数
- **空间复杂度**：`O(1)`
