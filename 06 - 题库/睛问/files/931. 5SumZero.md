## 💡 解题思路 
暴力`5`重循环会超时。使用哈希。
遍历数组`A`和`B`，将`A`、`B`中任意两个元素之和保存到一个哈希表`sum_AB`中，值为和出现的次数。
遍历数组`C`和`D`和`E`，设`target = C[i] + D[i] + E[i]`；在`sum_AB`中查找 `-target`，如果出现，则加上`sum_AB[-target]`。

## 💻 代码实现
> my answer
```cpp
#include <iostream>
#include <unordered_map>
#include <vector>

using namespace std;

int main()
{
    int a, b, c, d, e;
    cin >> a >> b >> c >> d >> e;
    vector<int> A(a), B(b), C(c), D(d), E(e);
    for (int i = 0; i < a; i++) cin >> A[i];
    for (int i = 0; i < b; i++) cin >> B[i];
    for (int i = 0; i < c; i++) cin >> C[i];
    for (int i = 0; i < d; i++) cin >> D[i];
    for (int i = 0; i < e; i++) cin >> E[i];

    unordered_map<int, int> sumAB;
    for (auto &x : A) {
        for (auto &y : B) {
            sumAB[x + y]++;
        }
    }
    int cnt = 0;
    for (auto &x : C) {
        for (auto &y : D) {
            for (auto &z : E) {
                int target = -(x + y + z);
                if (sumAB.find(target) != sumAB.end()) {
                    cnt += sumAB[target];
                }
            }
        }
    }
    cout << cnt << endl;
    return 0;
}
```
- **时间复杂度**：$O(N_a * N_b + N_c * N_d * N_e)$。
- **空间复杂度**：$O(N_a * N_b)$。
