### 题目描述
从整数 1 开始，每轮操作可以选择将上轮结果加 1 或乘 2。问至少需要多少轮操作才能达到指定整数 $n$。

### 输入描述
一个整数 $n$（$2 \le n \le 10^5$），表示需要达到的整数。

### 输出描述
输出一个整数，表示至少需要的操作轮数。

### 样例1
**输入**
7

**输出**
4

**解释**
第 1 轮: $1 + 1 = 2$
第 2 轮: $2 + 1 = 3$
第 3 轮: $3 * 2 = 6$
第 4 轮: $6 + 1 = 7$

因此至少需要操作 **4 轮**。


## 💡 解题思路 
广度优先搜索是一种图搜索算法，它从起点开始，逐层扩展搜索范围，直到找到目标节点。在这个问题中，我们可以将每一步操作看作是图中的一个节点，每一步操作的结果看作是节点的邻居。具体来说：

1.  **初始状态**：我们从整数 $1$ 开始。
2.  **每一步操作**：每一步可以选择将当前结果加 $1$ 或乘 $2$。
3.  **目标状态**：我们需要找到达到整数 $n$ 的最少操作轮数。

通过 BFS，我们可以逐层扩展，确保每一步都记录当前的操作轮数，直到找到目标整数 $n$。
注意：
使用数组`st`去重，保证每个数字只进入一次队列，否则可能会超时
## 💻 代码实现
> my answer
```cpp
#include <iostream>
#include <queue>

using namespace std;
const int N = 100010;
bool st[N];  // 记录是否已经加入队列

int main()
{
    int n;
    cin >> n;
    queue<int> q;
    q.push(1);
    st[1] = true;
    int steps = 0;
    bool first = false;
    while(q.size()) {
        int size = q.size();
        for (int i = 0; i < size; i++) {
            auto t = q.front();
            q.pop();
            if (t == n) {
                first = true;
                break;
            }
            int x = t + 1;
            if (x <= n && !st[x]) {
                q.push(x);
                st[x] = true;
            }
            x = t * 2;
            if (x <= n && !st[x]) {
                q.push(x);
                st[x] = true;
            }
        }
        if (first) {
            break;
        }
        steps++;
    }
    cout << steps << endl;

    return 0;
}

```
- **时间复杂度**：$O(n)$
- **空间复杂度**：$O(n)$
