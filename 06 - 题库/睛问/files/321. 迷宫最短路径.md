> 🔗[321 - 迷宫最短路径](https://sunnywhy.com/camp/3415/model/3590?itemId=2932)

## 📌 题目描述
> （请在此处粘贴题目描述）
### 题目描述
现有一个 $n \times m$ 大小的迷宫，其中 $1$ 表示不可通过的墙壁，$0$ 表示平地。每次移动只能向上下左右移动一格，且只能移动到平地上。假设左上角坐标是 $(1,1)$，行数增加的方向为 $x$ 增长的方向，列数增加的方向为 $y$ 增长的方向，求从迷宫左上角到右下角的最少步数的路径。

### 输入描述
第一行两个整数 $n、m$（$2 \le n \le 100, 2 \le m \le 100$），分别表示迷宫的行数和列数；
接下来 $n$ 行，每行 $m$ 个整数（值为 $0$ 或 $1$），表示迷宫。

### 输出描述
从左上角的坐标开始，输出若干行（每行两个整数，表示一个坐标），直到右下角的坐标。

数据保证最少步数的路径存在且唯一。
### 样例1

**输入**
3 3
0 1 0
0 0 0
0 1 0

**输出**
1 1
2 1
2 2
2 3
3 3

**解释**
假设左上角坐标是 $(1,1)$，行数增加的方向为 $x$ 增长的方向，列数增加的方向为 $y$ 增长的方向。

可以得到从左上角到右下角的最少步数的路径为：$(1,1) \Rightarrow (2,1) \Rightarrow (2,2) \Rightarrow (2,3) \Rightarrow (3,3)$。

## 💡 解题思路 
使用`bfs`。
使用 `pre` 记录新节点的前驱节点。
由于存的是坐标所以是 数组元素是 `pair`。
## 💻 代码实现
> my answer
```cpp
#include <iostream>
#include <queue>
#include <vector>


using namespace std;
const int N = 110;
int grid[N][N]; // 存迷宫
bool st[N][N];
const int d[4][2] = {
    {0, -1}, {0, 1}, {1, 0}, {-1, 0}
};
typedef pair<int, int> PII;
PII pre[N][N];

int main()
{
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            cin >> grid[i][j];
        }
    }
    queue<pair<int, int>> q;
    q.push({1, 1});
    st[0][0] = true;
    vector<pair<int, int>> ans;

    int steps = 0;
    bool reach = false;
    while (q.size()) {
        steps++;
        int size = q.size();
        for (int k = 0; k < size; k++) {
            auto [x, y] = q.front();
            q.pop();
            if (x == n && y == m) {
                reach = true;
                break;
            }
            for (auto &[dx, dy] : d) {
                int nx = x + dx, ny = y + dy;
                if (1 <= nx && nx <= n && 1 <= ny && ny <= m &&
                    !st[nx][ny] && grid[nx][ny] == 0) {
                    pre[nx][ny] = {x, y}; // 记录从哪个位置走过来
                    st[nx][ny] = true;
                    q.push({nx, ny});
                } 
            }
        }
        steps++;
        if (reach) {
            break;
        }
    }
    vector<PII> path;
    path.push_back({n, m});
    int x = n, y = m;
    // 写成 while (p[x][y] != make_pair(1, 1)) 也行
    // 只是path要手动push_back({1, 1})
    while(!(x == 1 && y == 1)) {
        auto t = pre[x][y];
        path.push_back({t.first, t.second});
        x = t.first, y = t.second;
    }

    for (int i = path.size() - 1; i >= 0; i--) {
        auto pos = path[i];
        cout << pos.first << ' ' << pos.second << endl;
    }

    return 0;
}
```
- **时间复杂度**：$O(n * m)$
- **空间复杂度**：$O(n * m)$
