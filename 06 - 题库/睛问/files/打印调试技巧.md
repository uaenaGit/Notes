## 1. 常见场景
1. **追踪变量取值**：在循环或函数调用的关键点打印关键变量。
2. **验证函数流程**：在函数入口、关键返回前、异常处理等位置打印信息判断流程走向。
3. **STL 容器调试**：检查容器内容，如 `vector`, `set`, `map` 等，打印其大小、元素顺序、键值对。
4. **边界条件检查**：处理边界或极端情况时，打印分支触发情况及相关值。

## 2. 基本用法
### 2.1 打印位置选择
- **函数入口或出口**：核对参数、返回值是否符合预期。
- **循环中**：查看迭代次数、循环变量、累加结果等。
- **分支判断**：确定是否进入特定分支；可在 `if-else`, `switch-case` 中打印。
- **异常处理**：在 `try-catch` 或 `throw` 前后添加打印，帮助定位异常原因。
### 2.2 宏与条件编译
```cpp
//#define DEBUG
#include <iostream>
#include <string>

// 技巧：利用 __FILE__, __LINE__, __func__ 自动定位代码位置
#ifdef DEBUG
    // 使用 do-while(0) 确保宏在任何上下文中都像一条完整语句
    // 允许传入多个流操作参数 (...)
    #define DBG(...) do { \
        std::cout << "[DEBUG] " << __FILE__ << ":" << __LINE__ \
                  << " (" << __func__ << ") " << __VA_ARGS__ << "\n"; \
    } while(0)
#else
    // 完美吃掉参数，且不产生任何代码
    #define DBG(...) do {} while(0)
#endif

int main() {
    int var = 42;
    std::string str = "Hello";

    // 用法 1: 简单打印
    DBG("var = " << var);

    // 用法 2: 复杂打印 (自动带上文件行号)
    DBG("str = " << str << ", var * 2 = " << (var * 2));

    // 用法 3: 在 if 中安全使用 (无需额外花括号)
    if (var > 0)
        DBG("Var is positive");
    else
        DBG("Var is negative"); // 不会报错，逻辑正确

    return 0;
}
```
> 记住`__LINE__`和`__func__`关键字

可以直接在代码中开启宏编译，`#define DEBUG`
也可以在控制台（`console`）下敲`g++`命令
```bash
# 重新编译
g++ -DDEBUG -std=c++11 debug.cpp -o test_debug.exe

# 运行
test_debug.exe
```

### 2.3 调试时间
#### 方案 A：直接优化版（适合单次使用）
```cpp
#include <iostream>
#include <chrono>
#include <string>

// 引入常用 chrono 类型，减少代码冗余
using namespace std::chrono;

void test_code() {
    // 1. 使用 steady_clock (强烈推荐用于耗时测量)
    auto start = steady_clock::now();

    // ... 要测试的代码 ...
    long long sum = 0;
    for (int i = 0; i < 1000000; ++i) {
        sum += i;
    }
    // .......................

    auto end = steady_clock::now();

    // 2. 智能单位显示：自动选择最合适的单位
    auto duration = end - start;
    
    // 将 duration 转换为不同单位进行判断
    auto ms = duration_cast<milliseconds>(duration).count();
    auto us = duration_cast<microseconds>(duration).count();
    auto ns = duration_cast<nanoseconds>(duration).count();

    std::cout << "[TIME] Elapsed: ";
    if (ms > 100) {
        // 超过100毫秒，显示毫秒
        std::cout << ms << " ms";
    } else if (us > 100) {
        // 超过100微秒，显示微秒
        std::cout << us << " us";
    } else {
        // 否则显示纳秒
        std::cout << ns << " ns";
    }
    std::cout << std::endl;
}

int main() {
    test_code();
    return 0;
}
```
#### 方案 B：宏封装版（完美契合你的 DBG 风格）

既然你已经在用 `DBG` 宏，我们可以创建一个 `DBG_TIME` 宏，利用 **RAII 技术**（对象生命周期自动管理）来自动记录时间，无需手动写 `end` 和计算逻辑。
```cpp
#include <iostream>
#include <chrono>
#include <string>

// ================= 配置区域 =================

#ifdef DEBUG
    // 之前的 DBG 宏 (保持原样)
    #define DBG(...) do { \
        std::cout << "[DEBUG] " << __FILE__ << ":" << __LINE__ \
                  << " (" << __func__ << ") " << __VA_ARGS__ << "\n"; \
    } while(0)

    // 【新增】自动计时宏
    // 用法：在代码块开始处放置 DBG_TIMER(name);
    // 当代码块结束（name 对象析构）时，自动打印耗时
    class DebugTimer {
        std::string name_;
        std::chrono::steady_clock::time_point start_;
    public:
        DebugTimer(const std::string& n) 
            : name_(n), start_(std::chrono::steady_clock::now()) {}
        
        ~DebugTimer() {
            auto end = std::chrono::steady_clock::now();
            auto duration = std::chrono::duration_cast<std::chrono::microseconds>(end - start_).count();
            
            std::cout << "[TIME] " << name_;
            if (duration > 1000) {
                std::cout << " took " << (duration / 1000.0) << " ms";
            } else {
                std::cout << " took " << duration << " us";
            }
            std::cout << std::endl;
        }
    };

    // 宏定义：利用变量名拼接行号，避免重名冲突
    #define DBG_TIMER(msg) DebugTimer _timer_##__LINE__(msg)

#else
    #define DBG(...) do {} while(0)
    #define DBG_TIMER(msg) do {} while(0) // 非 DEBUG 模式下完全消失
#endif

// ================= 使用示例 =================

void slow_function() {
    // 自动开始计时，名字为 "slow_function"
    DBG_TIMER("slow_function"); 
    
    long long sum = 0;
    for (int i = 0; i < 5000000; ++i) sum += i;
    
    // 函数结束时，_timer_XX 对象析构，自动打印耗时
}

void fast_function() {
    DBG_TIMER("fast_function");
    int a = 1 + 1;
}

int main() {
    DBG("Starting tests...");
    
    slow_function();
    fast_function();
    
    // 也可以手动控制作用域
    {
        DBG_TIMER("manual_block");
        // ... 一些代码 ...
    } // 这里自动打印耗时
    
    return 0;
}
```
