## 💡 解题思路 
使用`dfs`搜索。
注意：
- 置访问标记的位置。
## 💻 代码实现
> my answer
```cpp
#include <iostream>

using namespace std;
int n, m;
const int N = 10;
int a[N][N];
int dx[] = {-1, 1, 0, 0}, dy[] = {0, 0, -1, 1};
bool st[N][N];
int res;

void dfs(int i, int j) {
    if (i == n && j == m) {
        res++;
        return;
    }
    // 置访问标记
    st[i][j] = true;
    for (int k = 0; k < 4; k++) {
        int x = i + dx[k], y = j + dy[k];
        if (1 <= x && x <= n && 1 <= y && y <= m && 
            a[x][y] == 0 && !st[x][y])
        {
            /*
            不能在里面置访问标记，dfs之后再恢复
            st[x][y] = true;  这会导致(i, j)没被标记
            可能走回头路
            */
            dfs(x, y);
        }
    }
    // 恢复现场
    st[i][j] = false;
}

int main()
{
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            cin >> a[i][j];
        }
    }

    dfs(1, 1);
    cout << res << endl;

    return 0;
}
```
- **时间复杂度**：$O(m * n)$
- **空间复杂度**：$O(m * n)$
