> 🔗[553 - 认真吃菜](https://sunnywhy.com/problem/553)

## 📌 题目描述
> （请在此处粘贴题目描述）

### 题目描述
小晴最近找的工作很辛苦，但是干完之后，老板竟然打算请小晴吃饭！真是出乎小晴的意料！

为了让小晴吃饱，老板给小晴点了 $n$ 个菜。小晴粗略估计了一下吃每个菜各自需要的时间 $t$（每个菜可能不一样），觉得可能会吃很久，所以使出了一招“认真吃菜”，变了一个复制版的小晴出来，打算和复制版小晴一起把这些菜都吃了。假设复制版小晴的吃菜速度和原版小晴是一样的，并且两个小晴吃菜互相独立，但他们不会一起吃同一个菜，也不会在吃到一半的时候去吃另一个菜。

假设两个小晴同时开始吃，那么至少需要多久才可以把这些菜都吃完？


### 输入描述
- 第一行一个整数 $n$，表示菜的个数；
- 第二行为用空格隔开的 $n$ 个整数，表示完整吃完每个菜的时间。

**范围**：
- $1 \le n \le 100$
- $1 \le t[i] \le 1000$

### 输出描述
输出一个整数，表示吃完所有菜所需的最短时间。

### 样例 1
**输入**
6
1 -2 3 -1 2 1

**输出**
6

**解释**
可以选择第一段为第三个数字 $3$（和为 $3$），第二段为第五和第六个数字 $2$ 和 $1$（和为 $3$），中间隔了第四个数字 $-1$，因此两段不相邻，总和为 $3+3=6$。没有其他选择能得到更大的和，所以输出 $6$。

## 💡 解题思路 

为了更好利用两人同时吃的优势，应当尽可能将菜的时间平均分配，也就是说，如果所有菜的时间之和为 $sumT$，那么每个人各自吃的总时间越接近 $\frac{sumT}{2}$ 越好。显然，两个人各自的总时长是关于 $\frac{sumT}{2}$ 对称的，所以可以只考虑其中一个人。

于是问题可以转换为：
选择 $n$ 个菜中的哪些菜，可以使得这些菜的时间之和在不超过 $\frac{sumT}{2}$ 的前提下尽可能大，问最大可以是多少。

显然，我们只需要把背包容量设置为 $\frac{sumT}{2}$，菜的时间既是菜的重量，也是菜的价值，这样就可以转换成 **01背包** 问题的描述。接下来跑一遍 01背包 算法即可得到其中一个人的最大时间，用 $sumT$ 减去这个最大时间就能得到另一个人的对应时间，两者取较大值即为答案。
## 💻 代码实现
> my answer
```cpp
#include <bits/stdc++.h>

using namespace std;
const int N = 110, M = 50010; // 注意 体积最大不超过 100 * 1000 / 2
int a[N];
int memo[N][M];

// dfs(i, j) 选择i个菜中的某些菜，使得这些菜的时间之和在不超过 sumT/2的前提下最大
int dfs(int i, int v) {
    if (i < 0) {
        return 0;
    }
    int &res = memo[i][v];
    if (res != -1) {
        return res;
    }
    if (v < a[i]) {
        return res = dfs(i - 1, v); // 只能不选
    }
    return res = max(dfs(i - 1, v), dfs(i - 1, v - a[i]) + a[i]);
}

int main()
{
    int n;
    cin >> n;
    memset(memo, -1, sizeof(memo));
    int s = 0;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        s += a[i];
    }
    int v = s / 2;
    int t = dfs(n - 1, v);
    int ans = max(t, s - t);
    cout << ans << endl;
    return 0;
}
```
- **时间复杂度**：$O(NM)$
- **空间复杂度**：$O(NM)$
