## 💡 解题思路 
1. **链表反转**：
    - 初始化两个变量`current`和`last`，分别表示当前处理的结点和上一个处理的结点。初始时，`current`为链表的第一个结点编号，`last`为`-1`（表示链表的末尾）。
    - 使用一个循环遍历链表，直到`current`为`-1`（表示链表结束）：
        - 记录当前结点的下一个结点编号`next`。
        - 将当前结点的`next`指针指向`last`，即反转当前结点的指向。
        - 更新`last`为当前结点编号`current`。
        - 更新`current`为下一个结点编号`next`。
## 💻 代码实现
> my answer
```cpp
#include <iostream>

using namespace std;
const int N = 110;

struct Node {
    int data;
    int next;
} nodes[N];

int main()
{
    int n, first;
    cin >> n >> first;

    while (n--) {
        int id, data, next;
        cin >> id >> nodes[id].data >> nodes[id].next;
    }

    int current = first, last = -1;
    // 反转链表
    while (current != -1) {
        int next = nodes[current].next; // 记录下一个节点
        nodes[current].next = last; // 更改当前节点的next为上一个节点
        last = current; // 更显last节点
        current = next; // 最后更新current节点
    }
    // last指向反转前的最后一个节点也是反转后的第一个节点
    current = last;
    while (current != -1) {
        cout << current << ' ' << nodes[current].data
            << ' ' << nodes[current].next << endl;;
        current = nodes[current].next;
    }

    return 0;
}
```
- **时间复杂度**：`O(n)`
- **空间复杂度**：`O(1)`
