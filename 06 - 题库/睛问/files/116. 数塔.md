数塔就是由一堆数字组成的塔状结构，其中第一行1个数，第二行2个数，第三行3个数，依此类推。每个数都与下一层的左下与右下两个数相连接。这样从塔顶到塔底就可以有很多条路径可以走，现在需要求路径上的数字之和的最大值。

例如在上图中，5->8->12->10与5->3->16->11这两条路径上的数字之和都是35，是所有路径中的最大值。

## 💡 解题思路 
`dfs`搜索，可以看出，当`i == n` 时，触底返回。可将所有路径的数字之和记录到一个数组中，然后在数组中输出最大值即可。

## 💻 代码实现
> my answer
```cpp
#include <iostream>
#include <vector>
#include <climits>

using namespace std;
const int N = 25;
int a[N][N];
int n;

void dfs(int i, int j, int s, vector<int> &res) {
    s += a[i][j];
    if (i == n) { // 到达最后一层
        res.push_back(s);
        return;
    }
    
    if (i < n) { // 还有下一层
        dfs(i + 1, j, s, res);
        dfs(i + 1, j + 1, s, res);
    }
}

int main()
{
    cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            int x;
            cin >> x;
            a[i][j] = x;
        }
    }
    vector<int> res;
    dfs(1, 1, 0, res);
    int ans = INT_MIN;
    for (auto &num : res) {
        ans = max(ans, num);
    }
    cout << ans << endl;
    return 0;
}
```
- **时间复杂度**：$O(2 ^ n)$。
**推导过程：**
*   **递归树结构**：
    *   在第 1 层，调用 `getMax(1, 1)`，产生 2 个递归调用。
    *   在第 2 层，每个调用又产生 2 个调用，共 $2^1$ 个节点。
    *   在第 3 层，共 $2^2$ 个节点。
    *   ...
    *   在第 $k$ 层，大约有 $2^{k-1}$ 个节点。
    *   直到第 $n$ 层（底层），递归结束。
*   **总计算量**：
    整个递归过程形成了一棵高度为 $n$ 的二叉树。节点总数约为 $2^0 + 2^1 + \dots + 2^{n-1} = 2^n - 1$。
*   **重复计算**：
    这是最致命的问题。例如，计算 `getMax(3, 2)` 时，它可能被 `getMax(2, 1)` 调用，也可能被 `getMax(2, 2)` 调用。随着层数加深，同一个状态 `(i, j)` 会被重复计算指数级次数。
*   **结论**：
    当 $n=20$ 时，$2^{20} \approx 100$ 万次运算，计算机还能勉强接受；
    但当 $n=30$ 时，$2^{30} \approx 10$ 亿次运算，程序会运行好几秒；
    当 $n=50$ 时，$2^{50}$ 是一个天文数字，程序永远跑不完。
- **空间复杂度**：`O(n)`。主要指**递归调用栈**的深度，而不是数组占用的空间。

> to optimize

使用 `memo`数组，记忆化搜索。
```cpp
#include <iostream>
#include <cstring> // memset函数使用

using namespace std;
const int N = 25;
int a[N][N];
int memo[N][N];
int n;

int dfs(int i, int j) {
    if (i == n) {
        return a[i][j];
    }

    // 没被搜索过
    if (memo[i][j] != -1) {
        return memo[i][j];
    }

    memo[i][j] = max(dfs(i + 1, j), dfs(i + 1, j + 1)) + a[i][j];
    return memo[i][j];
}

int main()
{
    cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            cin >> a[i][j];
        } 
    }
    memset(memo, -1, sizeof(memo));

    cout << dfs(1, 1) << endl;
    return 0;
}
```
- **时间复杂度**：$O(n^2)$
- **空间复杂度**：$O(n^2)$

>✨ tips
- 使用`memo`数组优化时间复杂度。

```cpp
#include <iostream>

using namespace std;
const int N = 25;
int a[N][N];

int main()
{
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            cin >> a[i][j];
        }
    }
    // 直接使用 a 数组存储路径最大值
    // 由于a 数组最后一行就是元素值，所以直接从倒数第二行开始计算.
    for (int i = n - 1; i >= 1; i--) {
        for (int j = 1; j <= i; j++) {
            a[i][j] = max(a[i + 1][j], a[i + 1][j + 1]) + a[i][j];
        }
    }

    cout << a[1][1] << endl;
    return 0;
}
```
- **时间复杂度**：$O(n^2)$。
- **空间复杂度**：$O(n^2)$。额外空间为 $O(1)$。
