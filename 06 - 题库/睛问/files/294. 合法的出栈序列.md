## 💡 解题思路 
思路：模拟栈的操作过程
1. **初始化**：我们需要一个栈来模拟压入和弹出的操作，还需要一个变量`nowMax`来记录当前已经压入栈中的最大元素（`nowMax` 初始化为`0`）。
2. **遍历出栈序列**：对于出栈序列中的每一个元素，我们需要判断它是否可以按照我们模拟的栈操作顺序出栈。
3. **压入元素**：如果当前元素大于`nowMax`，我们需要从`nowMax + 1`到当前元素依次压入栈中，并更新`nowMax`。
4. **弹出元素**：如果栈顶元素等于当前元素，则弹出栈顶元素；如果不等于，则说明这个出栈序列不合法。
## 💻 代码实现
> my answer
```cpp
#include <iostream>
#include <stack>

using namespace std;

int main()
{
    int n;
    cin >> n;
    stack<int> s;
    int nowMax = 0; // 初始化为0
    bool isVld = true;
    while (n--) {
        int x;
        cin >> x;
        if (x > nowMax) {
            // 从nowMax+1到x依次压入栈中
            for (int i = nowMax + 1; i <= x; i++) {
                s.push(i);
            }
            nowMax = x; // 更新 nowMax = x
        }
        // 检查栈顶元素是否等于x
        // 由于是合法压入所以当栈顶元素不是x则一定出栈序列不合法
        if (x != s.top()) {
            isVld = false;
            break;
        } else {
            s.pop(); // 弹出栈顶元素
        }
    }
    if (isVld) puts("Yes");
    else puts("No");

    return 0;
}
```
- **时间复杂度**：`O(n)`
- **空间复杂度**：`O(n)`
