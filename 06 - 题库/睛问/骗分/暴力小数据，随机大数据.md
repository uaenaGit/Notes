在研究生入学考试中，上机考试往往采用 **case 打分** 的模式，也就是说，不要求程序在所有测试用例下都达到最优或者完全正确，只要能通过尽可能多的 case，就能获得更高的分数。本文介绍一种颇有成效的得分技巧——**“暴力小数据，随机大数据”**。这一策略结合了针对小规模数据使用暴力算法的精确性和针对大规模数据采用随机算法的高效性，能够在有限时间内尽可能多地通过测试用例，从而在分数上取得优势。

## 策略思想

- **暴力小数据**：  
    对于输入规模较小的测试用例，题目往往设计得较为精细，数据量有限，此时采用暴力搜索或枚举算法往往能在合理时间内获得最优解。暴力方法不依赖于精妙的剪枝或启发式规则，只需利用计算机强大的枚举能力便可确保所有可能性均被覆盖，从而取得正确答案。
    
- **随机大数据**：  
    当面对输入规模较大的测试用例时，暴力方法通常会因时间复杂度过高而超时。此时，可以采用随机或启发式算法，尝试生成一个近似解或者满足题目要求的解。随机算法不一定保证每次都能获得最优解，但通常能在时间限制内迅速得到一个较为合理的答案，从而争取部分或较高的分数。
    

## 具体实现与应用

在考试中，题目通常不会明确告知哪些测试用例属于“小数据”或“大数据”。因此，考生需要通过分析题目描述和对数据范围的估计来进行判断。例如：

- 若题目说明某个变量的范围在 100 或更低，通常可以认为适合暴力搜索；
- 若变量的规模达到  或更高，则应考虑采用随机或近似算法，比如课程里面提到的随机打乱或者模拟退火等技巧。

另外，可以在编写代码时设定一个“分界点”，在程序运行时动态判断输入规模，从而选择相应的策略。

在小数据情形下，可以使用递归、回溯、枚举等方法遍历所有可能的解。例如，在求解排列组合问题、子集问题或图的遍历问题时，若数据量不大，暴力枚举能够确保不漏解，从而拿到满分或高分 case。

#### 示例

假设题目要求在一组数中寻找某个特定的组合，其数据量仅有 10 个数字，直接暴力枚举所有组合（ 种可能）是可行的。只需写出完整的枚举逻辑，就可以确保覆盖所有情况。

对于大数据情况，暴力搜索不可行，此时可以考虑以下几种策略：

- **随机选取策略**：  
    在搜索空间内随机选取部分候选解，通过不断尝试和迭代来寻找满足条件的解。此方法虽不保证每次都能找到最优解，但通常能在考试环境下获得较高分数。
    
- **模拟退火、遗传算法等启发式算法**：  
    如果时间允许，可以实现一些简单的启发式算法，快速探索解空间，并逐步优化解的质量。
    
- **局部搜索和贪心算法结合随机扰动**：  
    在某些问题中，先采用贪心策略得到一个基本解后，再通过局部搜索和随机扰动改善结果，既保证了计算速度，又能争取部分高分 case。
    

#### 示例

若题目要求在大规模数据中寻找最优路径、最大匹配或最优排序，直接暴力搜索不仅超时，而且难以设计。此时，可以采用随机生成初始解，然后不断调整，利用分数反馈来改进解的质量。多次运行算法，在时间截止前尽可能多地找到符合要求的解，从而争取更多分数。

比如这题：[https://sunnywhy.com/problem/10024](https://sunnywhy.com/problem/10024)

#### 策略说明

- **小数据情况 (n < 20)：**  
    当 **n** 较小时，解空间（所有子集个数 (2^n)）较小，可以直接利用 DFS 或回溯进行暴力枚举，计算每个合法子集对应的子数字，并累加求和后取模 7。
    
- **大数据情况 (n ≥ 20)：**  
    当 **n** 较大时，直接枚举所有子集不可行。考虑到最终结果只需要 mod 7，而 7 只有 7 个可能的余数，可以通过随机算法、启发式搜索或者数学分析直接得到答案（甚至在考试中可以预处理或直接输出一个答案）。
    

下面给出一份 C++ 代码，展示如何实现上述策略。对于 **n < 20**，采用 DFS 暴力枚举；对于 **n ≥ 20**，这里仅作为示例输出一个占位答案（实际中需要设计更高效的算法）。

#### C++ 代码实现

```cpp
#include <iostream>
#include <string>
using namespace std;

string Y;
long long total = 0;

// DFS 枚举所有可能的删除集合
// current 为当前保留的数字（构成子数字的字符串）
void dfs(int idx, string current) {
    int n = Y.size();
    if (idx == n) {
        // 排除全集（current 长度为 n）和空集（current 为空）
        if (!current.empty() && current.size() < n) {
            // 将保留的数字转为整数
            long long num = stoll(current);
            total += num;
        }
        return;
    }
    // 选择保留当前数字
    dfs(idx + 1, current + Y[idx]);
    // 选择删除当前数字
    dfs(idx + 1, current);
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> Y;
    int n = Y.size();
    if(n < 20) {
        dfs(0, "");
        cout << (total % 7) << "\n";
    } else {
        // 当 n >= 20 时，直接枚举不可行，
        // 需要利用题目特点设计随机或数学算法，
        // 例如利用 mod 7 结果范围较小的性质预处理或直接输出答案。
        // 这里作为示例，直接输出一个占位答案。
        cout << 0 << "\n";
    }
    return 0;
}
```
