在考研上机考试中，时间紧、题目难是常态。遇到复杂的优化问题，比如背包、排列、子段选择等，暴力搜索可能超时，动态规划可能想不出。这时，**随机化算法**可以成为你的“救命稻草”，尤其是其中的**多次随机**技巧，能让你在有限时间内轻松拿到部分分数，甚至有时能撞出满分！

本文用三个由浅入深的例题，带你彻底掌握多次随机这一骗分神技。
## 什么是多次随机？

多次随机就是多次通过随机改变数据的顺序或者多次尝试不同的随机组合，从而逼近问题的解。

### 一个超级简单的例子

题目：有两个长度相同的数组  和 ，你可以任意打乱它们的顺序，然后按位置相乘并求和，问最大和是多少？

如果你学过排序不等式，就知道把大的和大的配在一起能得到最大和。但如果不知道这个规律，或者数据量稍大，我们完全可以用多次随机来“蒙”：

- 先随便打乱  和 ，算一次和。
- 再打乱，再算……反复很多次。
- 记录下所有尝试中的最大值。

因为每次都是随机排列，总有一次能接近最优解，甚至直接命中！这就是多次随机的核心思想：**用随机性覆盖搜索空间，用多次尝试逼近最优解**。

### 多次随机的原理与优势

- **原理**：通过随机数生成器打乱数据顺序，每次尝试一种新的排列；经过成千上万次尝试，找到的解会越来越接近最优。
- **优势**：
    - 代码极短，实现简单，考场上几分钟就能写出来。
    - 不依赖复杂的数学推导，适用面广（组合优化、搜索空间巨大的问题）。
    - 即使找不到最优，也能拿个不错的部分分。

## 实战一：纯多次随机——最大乘积和

**题目描述**  
有两个长度均为 10 的数字序列，每个数字在 1~5 之间。你可以任意调整每个序列中数字的顺序，然后按位置相乘并求和。求最大可能的总和。

链接：[https://sunnywhy.com/camp/3415/model/3591?itemId=4112](https://sunnywhy.com/camp/3415/model/3591?itemId=4112)

**分析**  
如果直接枚举所有排列，n的很大的情况（本题=10只是为了演示）根本跑不完。但用多次随机就简单了：每次多次随机两个数组，算一次乘积和，重复几十万次，最大值很可能就是最优解。

**代码实现**
```cpp
#include <bits/stdc++.h>

using namespace std;
int a[10], b[10];

double get_time()
{
    return 1.0 * clock() / CLOCKS_PER_SEC;
}

void shuffle_array(int c[])
{
    for (int i = 9; i > 0; i--) {
        int j = rand() % (i + 1);
        swap(c[i], c[j]);
    }
}

int main()
{
    srand(time(0));
    for (int i = 0; i < 10; i++) cin >> a[i];
    for (int i = 0; i < 10; i++) cin >> b[i];

    const int  ITER = 5e5;
    long long ans = 0;
    for (int i = 0; i < ITER; i++) {
        if (i > 0) { // 第一次不打乱
            shuffle_array(a);
            shuffle_array(b);
        }
        long long s = 0;
        for (int j = 0; j < 10; j++) {
            s += 1LL * a[j] * b[j];
        }
        ans = max(ans, s);
    }
    cout << ans;

    return 0;
}
```

**为什么这样能行？**  
因为两个数组长度只有 10，所有可能的排列总数是 (10!)² ≈ 1.3×10¹³，虽然巨大，但 50 万次随机已经足够覆盖很多“好”的排列。而且最优解往往不止一个，多次随机很容易撞到。实际运行中，这个代码几乎每次都能得到样例中的 114 和 110。

**新手提示**

- 如果时间允许，可以加大 `ITER`（比如 100 万次），提高撞到最优的概率。
- 注意用 `1LL *` 防止乘法溢出。


## 实战二：多次随机 + 贪心——不相邻取箱子
**题目描述**  
有 n 个箱子排成一排，每个箱子里有金币（可能为负数）。不能同时打开相邻的箱子。问最多能获得多少金币？

链接：[https://sunnywhy.com/camp/3415/model/3591?itemId=4113](https://sunnywhy.com/camp/3415/model/3591?itemId=4113)

**分析**  
这是一个经典的“不能取相邻”问题，通常用动态规划解决。但如果你不会 DP，或者 n 比较小（本题 n ≤ 60），可以用多次随机加贪心：

- 第一轮先排序获得贪心的保底最优值。
- 其他轮次先多次随机箱子的下标顺序（注意不是打乱金币值，而是打乱“考虑的顺序”）。
- 按照这个顺序依次处理：如果当前箱子没被禁止且金币为正，就取走，并禁止它相邻的箱子。
- 重复很多轮，取最大值。

**为什么这样能行？**  
虽然贪心不一定得到全局最优，但配合随机顺序，不同顺序会导致不同的选择，从而有机会跳出局部最优，逼近全局最优。

**代码实现**
正解：
```cpp
#include <bits/stdc++.h>

using namespace std;
typedef pair<int, int> PII;
const int N = 65;
int a[N];
int memo[N];

int dfs(int i)
{
    if (i < 0) {
        return 0;
    }
    int &res = memo[i];
    if (res != -1) {
        return res;
    }
    if (a[i] <= 0) { // 不取
        return res = dfs(i - 1);
    }
    return res = max(dfs(i - 1), dfs(i - 2) + a[i]);
}

int main()
{
    int n;
    cin >> n;
    memset(memo, -1, sizeof(memo));
    for (int i = 0; i < n; i++) cin >> a[i];
   
    cout << dfs(n - 1);

    return 0;
}
```

骗分：
```cpp
#include <bits/stdc++.h>

using namespace std;
const int N = 70;
int a[N];

double get_time()
{
    return 1.0 * clock() / CLOCKS_PER_SEC;
}

int main()
{
    // srand(time(0));
    mt19937 rng(time(0));
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];

    vector<int> order(n);
    // 存储下标顺序
    for (int i = 0; i < n; i++) order[i] = i;

    // 按金币数量从大到小对下标进行排序
    sort(order.begin(), order.end(), [](int i, int j) {
        return a[i] > a[j];
    });

    long long ans = 0;
    int ITER = 1000000;
    int t = 0;
    for (int t = 0; t < ITER; t++) {
        if (t > 0) {
            shuffle(order.begin(), order.end(), rng);
        }

        vector<int> banned(n);
        long long sum = 0;
        for (int k = 0; k < n; k++) {
            int p = order[k];
            if (banned[p]) continue;
            if (a[p] <= 0) continue; // 不选负数和0更优

            sum += a[p];
            banned[p] = 1;
            if (p + 1 < n) banned[p + 1] = 1;
            if (p - 1 >= 0) banned[p - 1] = 1;
        }
        ans = max(sum, ans);
    }
    cout << ans << endl;


    return 0;
}
```

## 实战三：多次随机 + 贪心 + 卡时——两段不相邻子段和
**题目描述**  
给定一个整数序列，选出两个不相邻的非空连续子段（两段之间至少隔一个数），使两段和最大。

链接：[https://sunnywhy.com/camp/3415/model/3591?itemId=4114](https://sunnywhy.com/camp/3415/model/3591?itemId=4114)
正解：
```cpp
#include <bits/stdc++.h>

using namespace std;
const int N = 60;
int a[N];

int main()
{
    int n;
    cin >> n;
    if (n < 3) {
        cout << 0 << endl;
        return 0; 
    }
    for (int i = 1; i <= n; i++) cin >> a[i];

    // left_max[i]表示在[1, i]范围内任意位置结尾的最大子段和
    vector<int> left_max(n + 1, INT_MIN);
    int current = INT_MIN;
    for (int i = 1; i <= n; i++) {
        if (current < 0) current = a[i];
        else current += a[i];
        left_max[i] = max(left_max[i-1], current);
    }

    // right_max[i]表示在[i, n]范围内以任意位置开始的最大子段和
    current = INT_MIN;
    vector<int> right_max(n + 2, INT_MIN);
    for (int i = n; i >= 1; i--) {
        if (current < 0) current = a[i];
        else current += a[i];
        right_max[i] = max(right_max[i+1], current);
    }

    int ans = INT_MIN;
    for (int i = 1; i <= n - 2; i++) {
        // 第一段在[1, i] 第二段在[i+2, n]
        ans = max(ans, left_max[i] + right_max[i + 2]);
    }
    cout << ans << endl;

    return 0;
}
```

**分析**  
n ≤ 50，直接枚举所有可能的两段组合复杂度大约 O(n⁴)，勉强能跑。但如果我们想练习随机化，或者想学习“卡时”技巧（在规定时间内尽可能多地尝试），可以用随机分割加贪心扩展：

1. 随机选择一个分割点 k，将序列分成左半 `[0..k]` 和右半 `[k+2..n-1]`（中间至少隔一个位置）。
2. 在左半随机选一个起点，然后尝试向左或向右扩展，只要扩展后子段和变大就接受，直到无法扩展。这样就得到左半的一个“好”子段。
3. 同样在右半随机选起点并贪心扩展，得到右半的子段。
4. 两段和作为一次尝试的结果。
5. 重复上述过程，直到时间快用尽（比如 450 毫秒），记录最大值。

**代码实现**
```cpp
#include <bits/stdc++.h>

using namespace std;
const int N = 60;
int a[N];

double get_time()
{
    return 1.0 * clock() / CLOCKS_PER_SEC;
}

int main()
{
    mt19937 rng(time(0)); // 随机数种子
    double st = get_time();

    int n;
    cin >> n;

    if (n < 3) {
        cout << 0 << endl;
        return 0;
    }

    for (int i = 0; i < n; i++) cin >> a[i];

    long long ans = INT_MIN;
    while (get_time() - st < 0.5) {
        // 随机分割点在[0, n-3] 
        int k = rng() % (n - 2);

        // 左半段 随机起点[0, k]
        long long s1 = 0;
        int l1 = rng() % (k + 1);
        s1 += a[l1];
        int r1 = l1;
        // 向两边扩展
        while (true)
        {
            bool moved = false;
            if (l1 - 1 >= 0) { // 不越界
                long long t = s1 + a[l1 - 1];
                // 更新最大值
                if (t > s1) {
                    l1--;
                    s1 = t;
                    moved = true;
                }
            }
            if (r1 + 1 <= k) {
                long long t = s1 + a[r1 + 1];
                if (t > s1) {
                    s1 = t;
                    r1++;
                    moved = true;
                }
            }
            if (!moved) {
                break; // 不能扩展下去
            }
        }

        // 右半边 [k + 2, n - 1]
        int l2 = k + 2;
        int r2 = l2;
        long long s2 = a[l2];
        while (true)
        {
            bool moved = false;
            if (l2 - 1 > k + 1) {
                long long t = s2 + a[l2 - 1];
                if (t > s2) {
                    s2 = t;
                    l2--;
                    moved = true;
                }
            }
            if (r2 + 1 < n) {
                long long t = s2 + a[r2 + 1];
                if (t > s2) {
                    s2 = t;
                    r2++;
                    moved = true;
                }
            }
            // 扩展不下去
            if (!moved) {
                break;
            }
        }

        if (s1 + s2 > ans) {
            ans = s1 + s2;
        }
    }
    cout << ans << endl;

    return 0;
}
```
通过率：96.7%
**新手提示**
- 这里用了“卡时”技巧：当接近时间限制时主动停止，这样能最大程度利用考试时间。
- 随机分割保证了两个子段不会相邻，而贪心扩展则让每个子段尽可能大（虽然不一定最优，但结合随机起点，能探索很多可能）。
- 这个代码在 n=50 时，450 毫秒内能跑几万到十几万轮，足够逼近最优解。

## 多次随机的注意事项
1. **迭代次数要合适**
    
    - 时间宽裕就多跑几次，时间紧就少跑。可以先用小规模测试一下速度。
    - 如果发现某次迭代得到了理论上界（比如题目要求最大值且你已经猜到了），可以提前跳出循环。
2. **随机种子要真随机**
    
    - 用 `chrono::steady_clock::now().time_since_epoch().count()` 作为种子，确保每次运行结果不同。记忆参考[[chrono]]
    - 尽量不要用 `rand()` 和 `srand(time(0))`，随机数质量低。
3. **结合问题特点改进**
    
    - 纯多次随机适用于排列类问题（例1）。
    - 随机顺序 + 贪心适用于有约束的选择问题（例2）。
    - 随机分割 + 局部贪心适用于子段类问题（例3）。
    - 多动脑筋，把随机性与问题结构结合起来，效果更好。
4. **骗分心态**
    
    - 随机算法不一定保证满分，但往往是“保底”的好方法。如果你实在想不出正解，写个多次随机，至少能拿部分分，甚至意外满分！

## 总结

多次随机是一种简单而强大的骗分技巧。通过多次随机尝试，我们可以在有限时间内逼近最优解。本文的三个例子展示了从纯随机到结合贪心再到卡时的逐步深入，希望能帮助你在考场上灵活运用，轻松拿分！
