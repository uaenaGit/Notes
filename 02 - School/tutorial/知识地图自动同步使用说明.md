# 知识地图自动同步与个人笔记

## 每天怎样使用

1. 在文件管理器中双击本目录的 **启动自动同步地图.cmd**。启动器会打开 `http://127.0.0.1:8765/`。
2. 在 Obsidian 中打开 [[大模型学习知识地图.canvas]]。
3. 修改 `知识节点` 文件夹中的笔记。Canvas 引用同一个文件；网页每 2 秒检查一次保存后的内容。
4. 用完可以双击 **停止自动同步地图.cmd**。关闭网页本身不会关闭后台服务。

服务只在本机运行，使用 Python 标准库，无需安装第三方包。重启电脑后需重新启动；重复启动会复用当前服务。若端口被其他程序占用，启动器报错并停止，不会结束其他进程。

## 先试一次：Python 与张量

打开 [[Python 与张量]]，在“我的理解”“代码与实验”“问题与排错”下面补内容。

例如先写自己的预测，再运行笔记里的代码，补实际输出以及广播和矩阵乘法的解释。内容可分多次完成。

在 Canvas 中，“Python 与张量”现在是文件卡片，不再是独立文字卡片。可以在 Obsidian 中直接搜索这篇笔记打开，也可以通过卡片菜单打开对应文件。若在卡片内编辑，改的就是同一篇 Markdown。

网页版点击节点 → **在 Obsidian 打开并编辑笔记**，也可以跳回这篇笔记。浏览器可能询问是否允许打开 Obsidian，允许后即可跳转。

## 内容从哪里来

```text
知识节点/*.md ──→ Canvas 文件卡片（Obsidian 原生引用）
       │
       └──────→ 网页节点详情、个人笔记、搜索和状态

Canvas 节点与连线 ──→ 网页节点与连线
笔记中的 [[已有地图笔记]] ──→ 网页增加“笔记链接”关系
```

Markdown 是个人笔记和状态的唯一内容源。网页是读取视图，不会把内容反向覆盖回笔记。

## 如何标记学习状态

在 Obsidian 的笔记属性中修改 `status`，例如：

```yaml
status: 学习中
```

可使用：`未开始`、`学习中`、`已实践待复习`、`已通过自测`。网页状态读取这个属性，不再另存一份浏览器状态。以前只保存在浏览器里的状态不会自动迁入笔记。

笔记属性中：`title` 控制网页名称，`kind` 使用“概念 / 资料 / 项目”。“学习范围”“验收标准”“资料”供网页摘要读取；个人内容可以自由写在后续章节。代码块、列表和公式在 Obsidian 正常编辑；网页个人笔记区以 Markdown 原文显示，保留内容，不执行其中的 HTML 或代码。

## 怎样增加个人知识笔记

### 只想补充某个节点

直接写到该节点对应的 Markdown 里，不需要修改脚本。

### 想拆成一篇新笔记

例如新建“张量广播规则.md”，在“Python 与张量”中写 `[[张量广播规则]]`。这样 Obsidian 全局关系图会产生联系。

如果也希望这篇新笔记出现在本学习地图里，将该笔记从 Obsidian 文件列表拖进 Canvas，使它成为文件卡片，再在 Canvas 中连线。网页会读取新增节点与连线。已有地图节点间的双向链接也会自动作为“笔记链接”展示；未加入 Canvas 的普通笔记不自动变成地图节点，避免图谱无限膨胀。

新笔记可以添加属性 `title`、`kind`、`status`。没有属性也能读取，默认按“概念 / 未开始”处理。自动布局会给新节点分配位置；较多新增节点时可能需要进一步整理网络布局。

## 同步边界

- **内容同步：** 保存后的笔记正文、标题、状态、学习范围、验收标准。
- **结构同步：** Canvas 的笔记节点、文字卡片和节点之间的连线；网页检测到结构变化会自动刷新。
- **位置：** Canvas 保留卡片布局，网页保留散点网络布局。移动卡片不会把网页变成卡片网格，两者位置不逐像素同步。
- **区域：** 当前网页保留四个视觉区域，Canvas 保留六个阶段分组；新增自定义区域暂不自动生成网页区域。
- **双向链接：** 读取已有地图节点之间的 `[[笔记名称]]`，添加网页关联线；不会反向修改 Canvas。
- **文件重命名：** 在 Obsidian 内重命名，让它更新引用；不要直接在文件管理器里改笔记名。

## 为什么直接打开 HTML 不是实时页面

浏览器直接打开 `file://` 文件时不能持续读取本地笔记，因此自动刷新需通过启动入口打开的本机地址。后台服务运行时也会更新同目录的 HTML 快照；直接打开快照需要手动刷新才能看到新版。

这是本机内容同步，不是电脑、手机之间的云同步。关闭同步服务后，Obsidian 笔记与 Canvas 仍可正常使用。

## 备份

迁移前的 Canvas、HTML 和说明保存在安装时建立的备份目录。迁移保留原卡片的 ID、位置、连线与卡片原文；原文在每篇笔记底部“迁移前卡片原文”中。新笔记的“我的理解”属于待填写内容，不代表已掌握。
