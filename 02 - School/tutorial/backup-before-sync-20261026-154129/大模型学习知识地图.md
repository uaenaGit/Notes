## 如何读图

- **概念**：需要理解和验证的问题。
- **资料**：提供解释和练习的入口，不要求全部学完。
- **项目**：把知识变成可检查的成果。
- **前置依赖**：箭头从前置指向后续；不表示两者是唯一依赖。
- **学习资料**：该资料可以帮助学习目标节点。
- **方向选修**：具备共同基础后，按兴趣和课题选择。
- **成果积累**：项目和记录可以支持科研或求职。

地图是为控制复杂度而做的简化，资料也可能覆盖多个区域；连线不是完整的课程先修规则。网页选中节点时会突出直接关联，Canvas 保留所有关系并可自由调整布局。

## 怎样把导航图长成自己的知识图谱

Canvas 当前的节点是可编辑文字卡片。等真正学到一个节点时，再创建对应的 Markdown 笔记，并在 Canvas 中加入该笔记文件卡片，或用它替换原文字卡片。

例如新建《为什么梯度默认会累加》：写自己的解释、一个最小验证、容易混淆的地方和资料来源；在分类项目记录中加入 `[[为什么梯度默认会累加]]`。

**Canvas 连线用于手工组织地图；Obsidian 全局关系图主要依赖 Markdown 笔记之间的双向链接。** 想让全局图也逐渐形成知识网络，应在实际笔记中建立有意义的 `[[链接]]`，而不是只增加 Canvas 连线。暂时不批量创建空白知识笔记。

每周新增或完善少量真正使用过的节点即可。知识地图的价值是能帮助定位问题、复现项目与规划下一步。
