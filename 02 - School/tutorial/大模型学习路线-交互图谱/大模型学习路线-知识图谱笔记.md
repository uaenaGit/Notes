  # 1. 引言
  机器学习（machine learning，ML）是一类强大的可以**从经验中学习**的技术
  ## 1.1 日常中的机器学习
  训练过程：
  1. 从一个随机初始化参数的模型开始，这个模型基本没有“智能”；
  2. 获取一些数据样本（例如，音频片段以及对应的是或否标签）；
  3. 调整参数，使模型在这些样本中表现得更好；
  4. 重复第（2）步和第（3）步，直到模型在任务中的表现令人满意。
  ![image-20261029115426410](https://cdn.jsdelivr.net/gh/uaenaGit/image-host@main/images20261029115426510.png)
  
  ## 1.2 机器学习中的关键组件
  每个数据集由一个个样本（example, sample）组成，大多时候，它们遵循**独立同分布(independently and identically distributed, i.i.d.)**。 样本有时也叫做数据点（data point）或者数据实例（data instance），通常每个样本由一组称为特征（features，或协变量（covariates））的属性组成。
  
  "学习"是指自主提高模型完成某些任务的效能，为了度量模型的优劣程度，我们通常定义一个目标函数或者叫做**损失函数**（loss funciton，或cosr function），我们希望它越低越好。当任务在试图预测数值时，最常见的损失函数是平方误差（squared error），即预测值和实际值之差的平方；当试图解决分类问题时，最常见的目标函数是是最小化错误率。
  通常，损失函数是根据**模型参数**定义的，并**取决于数据集**，在一个数据集上，我们通过最小化损失函数来学习模型的最佳值。
  
  获得了一些数据源及其表示、一个模型和一个合适的损失函数，接下来就需要**优化算法*，它能够搜索出
  最佳参数，以最小化损失函数，大多流行的优化算法基于梯度下降（gradient descent）。在每个步骤中，梯度下降法都会检查每个参数，看看如果**仅对该参数进行少量变动**，训练集损失会朝哪个方向移动，然后在减少损失的方向上优化参数。
  
  ## 1.3 各种机器学习问题
  ### 1.3.1 监督学习
  监督学习（supervisedlearning）擅长在**“给定输入特征”*的情况下预测标签。每个“特征‐标签”对都称为
  一个样本（example）
  ![image-20261102122402523](https://cdn.jsdelivr.net/gh/uaenaGit/image-host@main/images20261102122402891.png)
  
  #### 回归
  当标签取任意数值时，我们称之为回归问题，此时的目标是生成一个模型，使它的预测非常接近实际标签值。
  > 任何有关“有多少”的问题很可能就是回归问题
  
  #### 分类
  分类问题希望模型能够预测样本属于哪个类别（category，正式称为类（class））。分类问题的常见损失函数被称为**交叉熵（cross entropy）**。
  
  #### 标记
  学习预测不相互排斥的类别的问题称为多标签分类（multi‐labelclassification）
  
  #### 搜索
  有时，我们不仅仅希望输出一个类别或一个实值。在信息检索领域，我们希望对一组项目进行排序。
  
  #### 推荐系统
  它的目标是向特定用户进行“个性化”推荐。
  
  #### 序列学习
  序列学习需要摄取输入序列或预测输出序列，或两者兼而有之。
  - **标记和解析**。这涉及到用属性注释文本序列。
  - **自动语音识别**。
  - **文本到语音**
  - **机器翻译**
  
  ### 1.3.2 无监督学习
  数据中不含有“目标”的机器学习问题通常被称为无监督学习（unsupervised learning）。
  - 聚类问题（clustering）：没有标签的情况下给数据分类
  - 主成分分析问题（principal component analysis）
  - 因果关系（causality）和概率图模型（probabilisticgraphicalmodels）
  - 生成对抗性网络（generativeadversarialnetworks）：为我们提供一种合成数据的方法，甚至像图像和
  音频这样复杂的非结构化数据。

  ### 2.1.3 广播机制
  使用广播机制（broadcasting mechanism），通过适当复制元素来扩展一个或两个数组，使两个张量具有相同的形状，对生成的数组执行按元素操作。
  ```py
  a = torch.arange(3).reshape((3, 1))
  b = torch.arange(2).reshape((1, 2))
  a, b
  ```
  ```text
  (tensor([[0],
           [1],
           [2]]),
   tensor([[0, 1]]))
  ```
  ```py
  a + b # 广播机制
  ```
  ```text
  tensor([[0, 1],
          [1, 2],
          [2, 3]])
  ```
  广播机制是运算符自带的隐式行为，其核心规则如下：
  从**最右边的维度**开始对齐，逐维比较；两个维度的大小相同，或者**其中一个为 1**，就能匹配。缺少的维度按 1 处理。
  
  最容易弄错的是：`(3,)` 不等于 (3, 1)。 (3,) 是只有一个轴的**一维张量**，广播时会对齐最右侧的维度。
  如：
  ```py
  a = torch.zeros(3, 4)
  b = torch.tensor([10, 20, 30]))
  a + b # 会报错
  ```
  ```text
  Cell In[21], line 2
      b = torch.tensor([10, 20, 30]))
                                    ^
  SyntaxError: unmatched ')'
  ```
  正确用法：
  ```py
  a = torch.zeros(3, 4)
  b = torch.tensor([10, 20, 30]) # shape (3,)
  
  c = a + b.unsqueeze(1) # shape (3, 1)
  print(c)
  ```
  ```text
  tensor([[10., 10., 10., 10.],
          [20., 20., 20., 20.],
          [30., 30., 30., 30.]])
  ```
  `unsqueeze()` 的作用是：**在指定位置插入一个大小为 1 的新维度，元素的值和总数量不变。**
  
  | 写法 | 原形状 | 新形状 | 理解方式 |
  |---|---|---|---|
  | `b.unsqueeze(0)` | `(3,)` | `(1, 3)` | 在第 `0` 个位置插入 `1`，形成一行 |
  | `b.unsqueeze(1)` | `(3,)` | `(3, 1)` | 在第 `1` 个位置插入 `1`，形成一列 |
  
  **`dim` 表示插入位置，维度从 0 开始编号**。对形状为（2， 3）的张量，有三个可插入位置。
  ```text
  原形状：                (2, 3)
  
  unsqueeze(0) →       (1, 2, 3)
  unsqueeze(1) →       (2, 1, 3)
  unsqueeze(2) →       (2, 3, 1)
  ```
  也可以使用负数位置，**-1 表示在最后添加一个维度：**
  ```py
  x.unsqueeze(-1).shape
  # torch.Size([2, 3, 1])
  ```
  对于一个有 n 个维度的张量，`dim` 的合法范围是：
  ```text
  -(n + 1) ≤ dim ≤ n
  ```
  **普通的 unsqueeze() 不会改变原张量的形状**，需要**接收返回值**。
  如果想直接修改 b 自身的形状，可以使用带下划线的 `b.unsqueeze_(1)`。
  ```py
  a = torch.zeros(3, 4)
  b = torch.tensor([10, 20, 30]) # shape (3,)
  b.unsqueeze_(1)
  a + b
  ```
  ```text
  tensor([[10., 10., 10., 10.],
          [20., 20., 20., 20.],
          [30., 30., 30., 30.]])
  ```
  
  ### 2.1.4 索引和切片
  张量中的元素可以通过**索引**访问。与任何Python数组一样：第一个元素的索引是0，最后一个元素索引是‐1；可以指定范围以包含第一个元素和最后一个之前的元素。
  ```py
  X[-1], X[1:3] # 访问张量的最后一行和第 1 行到第 2 行（不包括第 3 行）
  ```
  ```text
  (tensor([ 8.,  9., 10., 11.]),
   tensor([[ 4.,  5.,  6.,  7.],
           [ 8.,  9., 10., 11.]]))
  ```
  通过**指定索引**来将元素写入矩阵。
  ```py
  X[1, 2] = 9
  X
  ```
  ```text
  tensor([[ 0.,  1.,  2.,  3.],
          [ 4.,  5.,  9.,  7.],
          [ 8.,  9., 10., 11.]])
  ```
  如果想为多个元素赋值相同的值，我们只需要索引所有元素，例如，`[0:2, :]`访问第1行和第2行，其中“:”代表沿轴1（列）的所有元素。
  ```py
  X[0:2, :] = 12 # 将 X 的前两行的所有元素设置为 12
  X
  ```
  ```text
  tensor([[12., 12., 12., 12.],
          [12., 12., 12., 12.],
          [ 8.,  9., 10., 11.]])
  ```
  
  ### 2.1.5 节省内存
  Python 的`id()`函数给我们提供了内存中引用对象的确切地址。
  ```py
  before = id(Y)
  print(before) # 打印 Y 的 id
  Y = Y + X
  id(Y) == before # False, 因为 Y 的 id 发生了变化
  ```
  ```text
  2284912379600
  False
  ```
  但是我们希望**原地更新**，避免不必要地分配内存。可以使用切片表示法将操作的结果分给先前分配的数组。例如：`Y[:] = <expression> `
  ```py
  Z = torch.zeros_like(Y) # 创建一个形状和 Y 一样的全零张量
  print('id(Z):', id(Z))
  Z[:] = X + Y # 切片表示法
  print('id(Z):', id(Z)) #  Z 的 id 没有发生变化
  ```
  ```text
  id(Z): 2284917653968
  id(Z): 2284917653968
  ```

  ### 2.3.9 矩阵乘法
  矩阵-矩阵乘法（matrix-matrix multiplication）：假设有两个矩阵$\mathbf{A}\in\mathbb{R}^{n\times k}$和$\mathbf{B}\in\mathbb{R}^{k\times m}$：
  $$
  \mathbf{A}=
  \begin{bmatrix}
  a_{11} & a_{12} & \dots & a_{1k} \\
  a_{21} & a_{22} & \dots & a_{2k} \\
  \vdots & \vdots & \ddots & \vdots \\
  a_{n1} & a_{n2} & \dots & a_{nk}
  \end{bmatrix},\quad
  \mathbf{B}=
  \begin{bmatrix}
  b_{11} & b_{12} & \dots & b_{1m} \\
  b_{21} & b_{22} & \dots & b_{2m} \\
  \vdots & \vdots & \ddots & \vdots \\
  b_{k1} & b_{k2} & \dots & b_{km}
  \end{bmatrix}.
  \tag{2.3.7}
  $$
  
  用行向量$\mathbf{a}_i^\top\in\mathbb{R}^k$表示矩阵$\mathbf{A}$的第$i$行，并列向量$\mathbf{b}_j\in\mathbb{R}^k$作为矩阵$\mathbf{B}$的第$j$列。要生成矩阵积$\mathbf{C}=\mathbf{AB}$，最简单的方法是考虑$\mathbf{A}$的行向量和$\mathbf{B}$的列向量：
  $$
  \mathbf{A}=
  \begin{bmatrix}
  \mathbf{a}_1^\top \\
  \mathbf{a}_2^\top \\
  \vdots \\
  \mathbf{a}_n^\top
  \end{bmatrix},\quad
  \mathbf{B}=
  \left[\mathbf{b}_1\ \mathbf{b}_2\ \dots\ \mathbf{b}_m\right].
  \tag{2.3.8}
  $$
  
  当我们简单地将每个元素$c_{ij}$计算为点积$\mathbf{a}_i^\top \mathbf{b}_j$：
  $$
  \mathbf{C}=\mathbf{AB}=
  \begin{bmatrix}
  \mathbf{a}_1^\top \\
  \mathbf{a}_2^\top \\
  \vdots \\
  \mathbf{a}_n^\top
  \end{bmatrix}
  \left[\mathbf{b}_1\ \mathbf{b}_2\ \dots\ \mathbf{b}_m\right]
  =
  \begin{bmatrix}
  \mathbf{a}_1^\top \mathbf{b}_1 & \mathbf{a}_1^\top \mathbf{b}_2 & \dots & \mathbf{a}_1^\top \mathbf{b}_m \\
  \mathbf{a}_2^\top \mathbf{b}_1 & \mathbf{a}_2^\top \mathbf{b}_2 & \dots & \mathbf{a}_2^\top \mathbf{b}_m \\
  \vdots & \vdots & \ddots & \vdots \\
  \mathbf{a}_n^\top \mathbf{b}_1 & \mathbf{a}_n^\top \mathbf{b}_2 & \dots & \mathbf{a}_n^\top \mathbf{b}_m
  \end{bmatrix}.
  \tag{2.3.9}
  $$
  使用 `mm` 来计算矩阵乘法。
  ```py
  B = torch.ones(4, 3)
  torch.mm(A, B)
  ```
  ```text
  tensor([[ 6.,  6.,  6.],
          [22., 22., 22.],
          [38., 38., 38.],
          [54., 54., 54.],
          [70., 70., 70.]])
  ```
  ### 2.3.10 范数
  
  **范数是一个函数，用来给向量/矩阵算出一个非负的数值，可以理解成「向量的长度、大小」，矩阵的范数可以理解成矩阵的“放大能力”。**
  
  **向量范数的定义（满足4条公理）**
  对向量 $\boldsymbol{x}\in\mathbb{R}^d$，范数 $\|\boldsymbol{x}\|$ 满足：
  1. **非负性**：$\|\boldsymbol{x}\| \ge 0$；只有零向量时 $\|\boldsymbol{x}\|=0$
  2. **齐次性**：$\|\alpha \boldsymbol{x}\| = |\alpha|\cdot\|\boldsymbol{x}\|$，$\alpha$ 是标量
  3. **三角不等式**：$\|\boldsymbol{x}+\boldsymbol{y}\| \le \|\boldsymbol{x}\|+\|\boldsymbol{y}\|$
  
  > 只要满足上面三条，就叫范数。
  
  **最常用：Lp 范数**
  $$
  \|\boldsymbol{x}\|_p = \left(\sum_{i=1}^d |x_i|^p\right)^{\frac1p}
  $$
  
  1. **$L_2$ 范数（欧几里得范数，最常用）**
  $$
  \|\boldsymbol{x}\|_2 = \sqrt{\sum_{i=1}^d x_i^2}
  $$
  ✅ 和点积关系：$\boldsymbol{x}^\top \boldsymbol{x} = \|\boldsymbol{x}\|_2^2$
  ✅ 就是我们几何里的直线距离。
  
  2. **$L_1$ 范数（曼哈顿范数）**
  $$
  \|\boldsymbol{x}\|_1 = \sum_{i=1}^d |x_i|
  $$
  每个元素绝对值相加，相当于沿着方格走的距离。
  
  3. **$L_\infty$ 范数（无穷范数）**
  $$
  \|\boldsymbol{x}\|_\infty = \max_{i}|x_i|
  $$
  取向量里绝对值最大的那个元素。
  
  **矩阵范数**
  矩阵也有范数，最常见的是**由向量范数诱导出来的算子范数**：
  $$
  \|\boldsymbol{A}\| = \max_{\boldsymbol{x}\neq \boldsymbol{0}} \frac{\|\boldsymbol{A}\boldsymbol{x}\|}{\|\boldsymbol{x}\|}
  $$
  含义：矩阵乘向量之后，向量最大能被放大多少倍。
  机器学习里最常用矩阵的 $L_2$ 诱导范数 = 矩阵最大奇异值。
  
  机器学习里的用途
  - $L_2$ 范数：L2正则（权重衰减），惩罚权重过大
  - $L_1$ 范数：L1正则，容易产生稀疏权重（很多参数变成0）
  
  配套代码（NumPy）
  ```python
  import numpy as np
  x = np.array([3,4])
  print(np.linalg.norm(x, ord=2)) # L2 范数，输出5
  print(np.linalg.norm(x, ord=1)) # L1 范数，输出7
  print(np.linalg.norm(x, ord=np.inf)) # L∞ 范数，输出4
  ```
  使用 `norm` 求范数
  ```py
  u = torch.tensor([3.0, -4.0])

  ```
  ```text

  ```
  类似于向量的$L_2$范数，矩阵$\mathbf{X} \in \mathbb{R}^{m\times n}$的Frobenius范数（Frobenius norm）是矩阵元素平方和的平方根：
  $$
  \|\mathbf{X}\|_F = \sqrt{\sum_{i=1}^{m}\sum_{j=1}^{n} x_{ij}^2}. \tag{2.3.17}
  $$
  Frobenius范数满足向量范数的所有性质，它就像是矩阵形向量的$L_2$范数。调用以下函数将计算矩阵的Frobenius范数。
  ```py

  ```
  ```text

  ```

  定义一个 plot 简单绘制多条曲线：
  ```py
  #@save
  def plot(X, Y=None, xlabel=None, ylabel=None, legend=None, xlim=None, ylim=None,
           xscale='linear', yscale='linear', fmts=('-', 'm--', 'g-', 'r:'), figsize=(3.5, 2.5), axes=None):
      """绘制数据点"""
      if legend is None:
          legend = []
  
      set_figsize(figsize)
      axes = axes if axes else d2l.plt.gca()
  
      # 如果有一个轴，输出 True
      def has_one_axis(X):
          return (hasattr(X, 'ndim') and X.ndim == 1 or isinstance(X, list)
                  and not hasattr(X[0], "__len__"))
  
      if has_one_axis(X):
          X = [X]
      if Y is None:
          X, Y = [[]] * len(X), X
      elif has_one_axis(Y):
          Y = [Y]
      if len(X) != len(Y):
          X = X * len(Y)
      axes.cla()
      for x, y, fmt in zip(X, Y, fmts):
          if len(x):

          else:
              axes.plot(y, fmt)
   ```

  理解它的关键是：**代码最终希望 `X` 和 `Y` 都是“装着多组数据的列表”，每组数据对应一条曲线。** 很多 `if` 判断都是为这个目标服务的。
  我们先假设有：
  ```python
  x = [0, 1, 2]
  y1 = [0, 1, 4]
  y2 = [0, 1, 8]
  ```
  
  作者希望这个函数支持下面几种用法：

  ```python
  plot(x, y1)                  # 指定横坐标和纵坐标，画一条线
  plot(y1)                     # 只给纵坐标，横坐标自动使用 0、1、2……
  plot(x, [y1, y2])            # 两条线共用一组横坐标
  plot([x, x], [y1, y2])       # 每条线分别提供横坐标和纵坐标
  ```

  **1. 函数参数：告诉函数“画什么、怎么画”**

  ```python

      legend = []
  ```
  没有提供图例，就使用空列表。
  这里使用 `legend=None`，然后在函数内部新建列表，是 Python 中常见的写法，可以避免把可变列表作为默认参数带来的共享问题。现阶段先记住这个惯用写法即可。
  
  ```python
  set_figsize(figsize)
  ```
  调用前面定义的辅助函数，设置图像大小。
  
  ```python
  axes = axes if axes else d2l.plt.gca()
  ```
  这是一个条件表达式，基本相当于：
  ```python
  if axes:
      axes = axes
  else:
      axes = d2l.plt.gca()
  ```
  
  意思是：
  > 如果调用者提供了坐标系，就使用它；否则，取得当前坐标系。
  `gca()` 是 *get current axes* 的缩写。
  
  这里的 `axes` 指的是**绘图区这个对象**，它可以负责画曲线、显示刻度和设置标签，不只是某一条横轴或纵轴。
  
  **3. `has_one_axis`：判断输入是不是一组一维数据**
  ```python
  def has_one_axis(X):
      return (hasattr(X, 'ndim') and X.ndim == 1 or isinstance(X, list)
              and not hasattr(X[0], "__len__"))
  ```
  
  这是定义在 `plot` 内部的小函数，外层函数用它来判断输入的数据形式。
  这里的“一个轴”指的是**数据只有一个维度**，例如：
  ```python
  [0, 1, 2]
  ```
  并不是说图里只有一个坐标轴。原注释容易让人混淆。
  把判断加上括号，会更容易看懂：
  ```python
  return (
      (hasattr(X, 'ndim') and X.ndim == 1)
      or
      (isinstance(X, list) and not hasattr(X[0], "__len__"))
  )
  ```
  
  它分两种情况。
  第一种，判断张量、NumPy 数组等具有 `ndim` 属性的对象：
  ```python
  hasattr(X, 'ndim') and X.ndim == 1
  ```
  - `hasattr(X, 'ndim')`：检查 `X` 有没有 `ndim` 属性。
  - `X.ndim == 1`：检查维度数是否等于 1。
  
  例如：
  ```python
  X = torch.tensor([0, 1, 2])
  
  X.ndim          # 1
  has_one_axis(X)  # True
  ```
  
  这里 `and` 有“短路”作用：如果前半部分是 `False`，就不会读取后面的 `X.ndim`，避免访问不存在的属性。
  
  第二种，判断普通 Python 列表：
  ```python
  isinstance(X, list) and not hasattr(X[0], "__len__")
  ```
  
  意思是：
  > `X` 是列表，而且它的第一个元素没有“长度”，就把它当作一组一维数据。
  对比两个例子：
  ```python
  X = [0, 1, 2]
  ```
  第一个元素是数字 `0`，没有长度，所以返回 `True`。
  
  ```python
  X = [[0, 1, 2], [3, 4, 5]]
  ```
  第一个元素是列表 `[0, 1, 2]`，有长度，所以返回 `False`。它被看作多组数据。
  `__len__` 是 Python 中支持 `len(...)` 的特殊方法。这里是在检查有没有这个方法。
  
  这个判断是给书中常用输入写的简化处理。例如，传入空列表 `[]` 时，访问 `X[0]` 会报错，因此它并不是适用于所有输入的通用检查。
  
  **4. 把一组横坐标包装成“包含一组数据的列表”**
  ```python
  if has_one_axis(X):
      X = [X]
  ```
  
  例如，原来是：
  ```python
  X = [0, 1, 2]
  ```
  
  处理后变成：
  ```python
  X = [[0, 1, 2]]
  ```
  
  **外层列表表示“有哪些曲线的数据”，内层列表表示“某一条曲线的数据点”。**
  为什么多加一层？因为后面要通过循环，每次取出一条曲线的数据。如果不加这一层，循环就会每次取出一个数字。
  
  **5. 根据有没有提供 `Y`，整理纵坐标**
  ```python
  if Y is None:
      X, Y = [[]] * len(X), X
  elif has_one_axis(Y):
      Y = [Y]
  ```
  
  这里分两种情况。
  
  如果只调用：
  ```python
  plot([0, 1, 4])
  ```
  
  这组数据最初被参数 `X` 接收，但用户实际想把它作为纵坐标。
  
  经过前面的包装：
  ```python
  X = [[0, 1, 4]]
  Y = None
  ```
  
  然后执行：
  ```python
  X, Y = [[]] * len(X), X
  ```
  
  结果变成：
  ```python
  X = [[]]
  Y = [[0, 1, 4]]
  ```
  
  这表示：
  - 有一条曲线。
  - 纵坐标是 `[0, 1, 4]`。
  - 横坐标没有指定，用空列表作为标记。
  
  **Python 会先计算赋值右侧的值，再赋给左侧变量，因此这里 `Y` 得到的是原来的 `X`。**
  
  其中：
  ```python
  [[]] * 3
  ```
  
  得到的形式是：
  ```python
  [[], [], []]
  ```
  
  严格说，这几个位置引用的是同一个空列表；这里后续只检查它们的长度、不修改内容，所以不影响此处的使用。
  如果提供了 `Y`，并且它是一组一维数据：
  
  ```python
  elif has_one_axis(Y):
      Y = [Y]
  ```
  
  就也加一层外部列表，例如：
  ```python
  Y = [0, 1, 4]
  ```
  
  变成：
  ```python
  Y = [[0, 1, 4]]
  ```
  
  这样 `X` 和 `Y` 的格式就统一了。
  
  **6. 多条曲线共用一组横坐标**
  ```python
  if len(X) != len(Y):
      X = X * len(Y)
  ```
  
  这里的 `len(X)` 和 `len(Y)` 数的是**数据组数**，也就是外层列表的长度。
  例如：
  ```python
  plot(x, [y1, y2])
  ```
  
  整理后：
  ```python
  X = [[0, 1, 2]]
  
  Y = [
      [0, 1, 4],
      [0, 1, 8]
  ]
  ```
  
  此时：
  ```python
  len(X)  # 1
  len(Y)  # 2
  ```
  
  所以执行：
  ```python
  X = X * 2
  ```
  
  得到：
  ```python
  X = [
      [0, 1, 2],
      [0, 1, 2]
  ]
  ```
  
  这样两组纵坐标都有对应的横坐标了。
  注意，**这里列表乘法表示重复列表中的元素，不是把坐标数值乘以 2**：
  ```python
  [0, 1, 2] * 2
  # [0, 1, 2, 0, 1, 2]
  ```
  
  这行代码主要照顾“一组横坐标对应多组纵坐标”的常见情况，没有完整检查其他数量不匹配的输入。
  
  **7. 清空坐标系，逐条画曲线**
  ```python
  axes.cla()
  ```
  
  `cla()` 表示清空当前这个坐标系里的已有内容，随后重新画图。
  
  接着是核心循环：
  ```python
  for x, y, fmt in zip(X, Y, fmts):
      if len(x):
          axes.plot(x, y, fmt)
      else:
          axes.plot(y, fmt)
  ```
  
  `zip` 把三个序列中对应位置的元素配成一组。
  例如：
  ```python
  X = [[0, 1, 2], [0, 1, 2]]
  Y = [[0, 1, 4], [0, 1, 8]]
  fmts = ('-', 'm--', 'g-', 'r:')
  ```
  
  循环过程是：
  | 循环 | `x` | `y` | `fmt` |
  |---|---|---|---|
  | 第一次 | `[0, 1, 2]` | `[0, 1, 4]` | `'-'` |
  | 第二次 | `[0, 1, 2]` | `[0, 1, 8]` | `'m--'` |
  
  这里大写 `X`、`Y` 保存所有曲线的数据；小写 `x`、`y` 是这次循环取出的一条曲线的数据。
  
  ```python
  if len(x):
  ```
  
  相当于：
  ```python
  if len(x) > 0:
  ```
  
  有横坐标时：
  ```python
  axes.plot(x, y, fmt)
  ```
  按指定的横纵坐标画图。
  
  没有提供横坐标时，`x` 是前面准备的空列表，就执行：
  ```python
  axes.plot(y, fmt)
  ```
  Matplotlib 自动用 `0, 1, 2, ...` 作为横坐标。
  
  另外，`zip` 会在最短的序列结束时停止。**默认 `fmts` 只有 4 项，所以这份函数一次最多画出 4 条曲线；要画更多，需要提供更多格式。**
  
  **8. 设置坐标轴和图例**
  ```python
  set_axes(axes, label, ylabel, xlim, ylim, xscale, yscale, legend)
  ```
  
  最后调用另一个辅助函数，统一设置：
  - 横、纵坐标的名称。
  - 横、纵坐标的范围。
  - 使用线性刻度还是对数刻度。
  - 图例等显示选项。
  
  `set_axes`、`set_figsize` 和 `d2l` 都需要提前定义或导入；这段函数依赖它们。
  
  把最常见的 `plot(x, [y1, y2])` 完整走一遍，你会看到它真正做的事情很直观：
  ```python
  # 用户传入
  X = [0, 1, 2]
  Y = [[0, 1, 4], [0, 1, 8]]
  
  # 包装 X
  X = [[0, 1, 2]]
  
  # Y 已经是多组数据，不需要包装
  
  # 重复 X，让两条线共用横坐标
  X = [[0, 1, 2], [0, 1, 2]]
  
  # 循环实际执行
  axes.plot([0, 1, 2], [0, 1, 4], '-')
  axes.plot([0, 1, 2], [0, 1, 8], 'm--')
  ```
  调用：
  ```py
  x = np.arange(0, 3, 0.1)
  plot(x, [f(x), 2 * x - 3], 'x', 'f(x)', legend=['f(x)', 'Tangent line (x=1)'])
  ```
  加上这两行，就能把前面定义的 `plot` 函数实际用起来：**在同一张图中，画出 `f(x)` 的曲线和直线 `y = 2x - 3`。**
  
  结合图例来看，作者想用这条直线表示 `f(x)` 在 `x = 1` 处的切线。它是否确实是切线，要看前面 `f` 的定义。
  
  我们先看第一行：
  
  ```python
  x = np.arange(0, 3, 0.1)
  ```
  
  `np` 通常来自：
  
  ```python
  import numpy as np
  ```
  
  `np.arange(起点, 终点, 步长)` 用来生成一组数，因此这里生成的是：
  
  ```python
  x = np.array([0.0, 0.1, 0.2, ..., 2.9])
  ```
  
  **包含起点 `0`，不包含终点 `3`**，总共 30 个数。它们作为画图时的横坐标，`x.shape` 为 `(30,)`。
  
  接下来：
  
  ```python
  plot(
      x,
      [f(x), 2 * x - 3],
      'x',
      'f(x)',
      legend=['f(x)', 'Tangent line (x=1)']
  )
  ```
  
  先把实参与前面函数的形参对应起来：
  
  | 传入的内容 | 对应形参 | 含义 |
  |---|---|---|
  | `x` | `X` | 两条曲线共用的横坐标 |
  | `[f(x), 2 * x - 3]` | `Y` | 两组纵坐标 |
  | `'x'` | `label` | 横坐标显示名称 |
  | `'f(x)'` | `ylabel` | 纵坐标显示名称 |
  | `legend=[...]` | `legend` | 两条曲线各自的名称 |
  
  注意，**`f(x)` 没有引号，是调用函数，计算纵坐标；`'f(x)'` 有引号，只是一段显示在图上的文字。**
  
  **`[f(x), 2 * x - 3]` 为什么表示两条线？**
  
  因为 `x` 是 NumPy 数组，运算会对数组中的每个元素进行。例如：
  
  ```python
  2 * x - 3
  ```
  
  会得到：
  
  ```python
  array([-3.0, -2.8, -2.6, ..., 2.8])
  ```
  
  它与 `x` 一一对应：
  
  | 横坐标 `x` | 直线的纵坐标 `2*x - 3` |
  |---|---|
  | 0.0 | -3.0 |
  | 0.1 | -2.8 |
  | 0.2 | -2.6 |
  | 1.0 | -1.0 |
  
  同样，如果 `f` 支持数组运算，`f(x)` 就会一次算出这 30 个横坐标对应的函数值。
  
  所以：
  
  ```python
  Y = [f(x), 2 * x - 3]
  ```
  
  是一个包含两个数组的列表：
  
  ```python
  Y = [
      第一条曲线的30个纵坐标,
      第二条曲线的30个纵坐标
  ]
  ```
  
  **把这些输入带进 `plot`，前面的判断就有具体意义了。**
  
  首先：
  
  ```python
  if has_one_axis(X):
      X = [X]
  ```
  
  传入的 `x` 是一维数组，所以变成：
  
  ```python
  X = [x]
  ```
  
  此时只有一组横坐标。
  
  接着：
  
  ```python
  if Y is None:
      ...
  elif has_one_axis(Y):
      Y = [Y]
  ```
  
  这里 `Y` 已经提供了，而且是包含两个数组的列表，表示两组数据，因此不需要再包装。
  
  现在：
  
  ```python
  len(X)  # 1：一组横坐标
  len(Y)  # 2：两组纵坐标
  ```
  
  于是：
  
  ```python
  if len(X) != len(Y):
      X = X * len(Y)
  ```
  
  执行后：
  
  ```python
  X = [x, x]
  ```
  
  **两条曲线共用同一个 `x`，现在就各自配上了一份横坐标。**
  
  然后：
  
  ```python
  for x, y, fmt in zip(X, Y, fmts):
  ```
  
  实际进行两次循环：
  
  | 循环 | 横坐标 | 纵坐标 | 格式 |
  |---|---|---|---|
  | 第一次 | 原来的 `x` 数组 | `f(x)` 的计算结果 | `'-'`，实线 |
  | 第二次 | 原来的 `x` 数组 | `2*x - 3` 的计算结果 | `'m--'`，品红色虚线 |
  
  相当于依次执行：
  
  ```python
  axes.plot(x, f(x), '-')
  axes.plot(x, 2 * x - 3, 'm--')
  ```
  
  最后，`set_axes(...)` 设置横坐标名称 `'x'`、纵坐标名称 `'f(x)'`，以及两条曲线的图例。
  
  **为什么图例写“在 `x=1` 处的切线”？**
  
  如果你前面使用的是书里这个函数：
  
  ```python
  def f(x):
      return 3 * x**2 - 4 * x
  ```
  
  那么：
  
  \[
  f(1)=3-4=-1
  \]
  
  它的导数是：
  
  \[
  f'(x)=6x-4,\qquad f'(1)=2
  \]
  
  所以在 `x=1` 处，切线经过点 `(1, -1)`，斜率为 `2`。代入直线的点斜式：
  
  \[
  y-f(1)=f'(1)(x-1)
  \]
  
  得到：
  
  \[
  y+1=2(x-1)
  \]
  
  也就是：
  
  \[
  \boxed{y=2x-3}
  \]
  
  因此，这两行代码把“函数曲线”和“它在某一点的切线”画在一起，帮助你观察导数所表示的切线斜率。**`plot` 本身只负责画图，切线公式 `2*x - 3` 是提前算好后传进去的。**

  ### 2.4.3 梯度
  我们可以连结一个多元函数对其所有变量的偏导数，以得到该函数的梯度（gradient）向量。具体而言，设函数$f:\mathbb R^n \to \mathbb R$的输入是一个$n$维向量$\mathbf x = [x_1,x_2,\dots,x_n]^\top$，并且输出是一个标量。函数$f(\mathbf x)$相对于$\mathbf x$的梯度是一个包含$n$个偏导数的向量：
  $$
  \nabla_{\mathbf x} f(\mathbf x) = \left[\frac{\partial f(\mathbf x)}{\partial x_1},\frac{\partial f(\mathbf x)}{\partial x_2},\dots,\frac{\partial f(\mathbf x)}{\partial x_n}\right]^\top, \tag{2.4.9}
  $$
  其中$\nabla_{\mathbf x} f(\mathbf x)$通常在没有歧义时被$\nabla f(\mathbf x)$取代。
  
  假设$\mathbf x$为$n$维向量，在微分多元函数时经常使用以下规则：
  - 对于所有$\mathbf A \in \mathbb R^{m\times n}$，都有$\nabla_{\mathbf x}\mathbf A\mathbf x = \mathbf A^\top$
  - 对于所有$\mathbf A \in \mathbb R^{n\times m}$，都有$\nabla_{\mathbf x}\mathbf x^\top \mathbf A = \mathbf A$
  - 对于所有$\mathbf A \in \mathbb R^{n\times n}$，都有$\nabla_{\mathbf x}\mathbf x^\top \mathbf A\mathbf x = (\mathbf A + \mathbf A^\top)\mathbf x$
  - $\nabla_{\mathbf x}\|\mathbf x\|^2 = \nabla_{\mathbf x}\mathbf x^\top \mathbf x = 2\mathbf x$
  
  同样，对于任何矩阵$\mathbf X$，都有$\nabla_{\mathbf X}\|\mathbf X\|_F^2 = 2\mathbf X$。正如我们之后将看到的，梯度对于设计深度学习中的优化算法有很大用处。
