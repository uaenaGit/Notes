## 打开

双击 `大模型学习路线-交互图谱.html`，推荐 Chrome / Edge。

不需要联网，不需要安装任何东西。窗口宽度建议 ≥ 1280px。

## 笔记：支持 Markdown、代码和公式

节点详情里的「我的笔记」有 **编辑 / 预览** 两个页签：编辑时写 Markdown 原文，切到预览看排版。

### 支持的写法

| 要写的东西 | 这样写 | 说明 |
| --- | --- | --- |
| 标题 | `## 标题`、`### 小标题` | `#`～`######` 都行，面板里自动降一级显示 |
| 粗体 | `**重点**` 或 `__重点__` | 全角 `＊＊重点＊＊` 也识别 |
| 斜体 | `*强调*` | 不建议用 `_强调_`；全角 `＊强调＊` 也识别 |
| 删除线 | `~~作废~~` | 全角 `～～作废～～`、`〜〜作废〜〜` 也识别（中文输入法容易打出全角） |
| 行内代码 | `` `scores.masked_fill(...)` `` | 反引号包住 |
| 代码块 | 三个反引号开头，可写语言名 | 见下面示例，支持自动换行 |
| 无序列表 | `- 条目` 或 `* 条目` | 支持一层，暂不做嵌套 |
| 有序列表 | `1. 条目`、`2. 条目` | |
| 勾选清单 | `- [ ] 未完成`、`- [x] 已完成` | 预览里显示成复选框 |
| 引用 | `> 一句话` | |
| 链接 | `[文字](https://example.com)` | 只允许 http(s)、mailto、站内锚点 |
| 图片 | `![说明](图片地址)` | 网络图片，或相对于 HTML 文件的路径 |
| 表格 | 见下面示例 | 支持 `:---` 左对齐、`:--:` 居中、`---:` 右对齐 |
| 分隔线 | `---` | |
| 行内公式 | `$QK^T/\sqrt{d_k}$` 或 `\(...\)` | |
| 块级公式 | `$$\mathrm{softmax}(QK^\top/\sqrt{d_k})V$$` 或 `\[...\]` | 单独一行，居中显示 |
| 换行 | 直接回车 | 同一段里回车会换行；空一行分新段 |

表格和代码块示例：

````markdown
| 方法 | 显存 | 备注 |
| --- | :--: | ---: |
| LoRA | 低 | **推荐** |
| 全参 | 高 | `A100 80G` |

```python
scores = q @ k.T / math.sqrt(d_k)
scores = scores.masked_fill(mask == 0, -1e9)
```
````

公式由本地的 `mathjax-tex-svg.js` 渲染成 SVG，离线可用。

### 暂不支持

- 列表嵌套（缩进子列表会当普通段落）
- 脚注、目录、HTML 标签、Obsidian 的 `[[双链]]` 和 `![[图片]]` 语法
- 任务清单只读，预览里不能直接勾选（回编辑里改 `[x]`）

导出时保留的是你写的 Markdown / LaTeX 原文，所以导进 Obsidian 后能继续正常渲染。

## 笔记存在哪里

笔记和学习状态保存在浏览器本地（localStorage），只在这台电脑、这个浏览器里有效。

- **导出笔记**：生成一份 Markdown，带 frontmatter、`[[wikilink]]` 和 `- [x]` 勾选框，可以直接放进 Obsidian 继续写。
- **备份 / 导入**：把全部笔记和进度导出成 JSON，在新设备上导入即可完整恢复（连状态和原文一起搬）。
- **重置**：清空全部状态和笔记（会二次确认）。

换电脑、换浏览器、清理浏览器数据都会丢失本地记录，重要内容记得定期「备份」或「导出笔记」。

## 换电脑 / 多设备

- 文件本身随便拷：整个文件夹（HTML + `mathjax-tex-svg.js` + 图片）复制到 Mac 或另一台电脑即可，双击就能用。
- 如果文件夹在 Obsidian 库里，iCloud / Obsidian Sync 会自动同步到 Mac，路径变了也不影响。
- Mac 上用 Safari 或 Chrome 打开都可以；如果 Safari 有样式异常，换 Chrome。
- **笔记不跟着文件走**：它存在浏览器里。换设备前先点「备份」导出 JSON，到新设备打开页面点「导入」恢复；只想要文字就「导出笔记」。
- 手机浏览器也能用：左上角 ☰ 打开图层和区域，双指缩放，点节点看笔记。

## 放到网上，随时打开

这个页面是纯静态的，任何静态托管都能用（唯一依赖是同目录的 `mathjax-tex-svg.js`，记得一起上传）。

**最简单的办法：Netlify Drop（不用注册也能先试）**

1. 新建一个文件夹，把 HTML 复制进去并改名为 `大模型学习路线-交互图谱.html`，再把 `mathjax-tex-svg.js` 放进去；
2. 打开 <https://app.netlify.com/drop>，把整个文件夹拖进去；
3. 几秒后得到 `https://xxxx.netlify.app` 链接，手机、Mac、实验室电脑都能打开。

**GitHub Pages**

1. 新建一个仓库，上传 `大模型学习路线-交互图谱.html` 和 `mathjax-tex-svg.js`；
2. Settings → Pages → Source 选 `main` 分支根目录，保存；
3. 等一分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

**要知道的两件事**

- 放到网上只解决“打开”，不解决“同步笔记”：笔记仍存在各自浏览器里，换设备用「备份 / 导入」搬。
- 公开链接谁都能看到图谱本身（内容都在 HTML 里）；笔记不在 HTML 里，只在你自己的浏览器。

更新版本时重新上传覆盖即可；域名不变的话，之前的本地笔记还在。

## 改内容

所有内容都在 `大模型学习路线-交互图谱.html` 里的三个数组中，改完刷新即可：

- `REGIONS`：区域框（位置、大小、强调色）
- `NODES`：节点（`id / label / type / region / desc / tips / links / tags`）
- `EDGES`：关系（`[起点 id, 终点 id, kind]`，kind 取 `prereq` / `source` / `related` / `produce`）

节点位置由脚本按标签宽度自动排布，不需要手动摆；新增节点后刷新页面会重新布局。
