### 9 运算符
#### 9.1 算术运算符
算术运算符是用于执行基本的数学运算的符号，作用于一个或多个操作数上，并产生一个计算结果。

| 运算符  | 描述    | 举例说明                        |
| ---- | ----- | --------------------------- |
| `+`  | 加法    | 1 + 5 ：1加上5                 |
| `-`  | 减法    | 8 - 3 ：8减3                  |
| `*`  | 乘法    | 3 * 8 ：3乘以8                 |
| `/`  | 除法    | 10 / 5 ：10除以5，除法结果是小数       |
| `//` | 整除    | 10 // 3 ：10整除3，整除结果为整数      |
| `%`  | 取余/求模 | 10 % 3 ：10模于3，结果为1（10除3取余数） |
| `**` | 幂指数   | 10 ** 3 ：10的3次方             |
课程代码：

#### 9.2 赋值运算符
赋值运算符作用：将右侧数值/表达式结果保存到左侧变量，核心规则：**右边计算，赋值给左边变量**

| 运算符   | 名称       | 等价写法                      | 示例说明                           |
| ----- | -------- | ------------------------- | ------------------------------ |
| `=`   | 赋值运算符    | 直接赋值                      | `num = 1+2` → num 结果为3         |
| `+=`  | 加法赋值运算符  | `a += b` 等价 `a = a + b`   | `num += 2` = `num = num + 2`   |
| `-=`  | 减法赋值运算符  | `a -= b` 等价 `a = a - b`   | `num -= 2` = `num = num - 2`   |
| `*=`  | 乘法赋值运算符  | `a *= b` 等价 `a = a * b`   | `num *= 2` = `num = num * 2`   |
| `/=`  | 除法赋值运算符  | `a /= b` 等价 `a = a / b`   | `num /= 2` = `num = num / 2`   |
| `%=`  | 取模赋值运算符  | `a %= b` 等价 `a = a % b`   | `num %= 2` = `num = num % 2`   |
| `//=` | 取整除赋值运算符 | `a //= b` 等价 `a = a // b` | `num //= 2` = `num = num // 2` |
| `**=` | 幂赋值运算符   | `a **= b` 等价 `a = a ** b` | `num **= 2` = `num = num ** 2` |

#### 9.3 比较运算符
比较运算符又叫关系运算符，用来对比两个数值的大小/相等关系；运算后只会返回**布尔值**：
- `True`：对比关系成立
- `False`：对比关系不成立

| 运算符  | 描述   | 实例       | 作用说明         |
| ---- | ---- | -------- | ------------ |
| ==   | 等于   | `a == b` | 判断a和b的值是否相等  |
| `!=` | 不等于  | `a != b` | 判断a和b的值是否不相等 |
| `>`  | 大于   | `a > b`  | 判断a是否大于b     |
| `>=` | 大于等于 | `a >= b` | 判断a是否大于或等于b  |
| `<`  | 小于   | `a < b`  | 判断a是否小于b     |
| `<=` | 小于等于 | `a <= b` | 判断a是否小于或等于b  |
#### 9.4 逻辑运算符
##### 一、and 逻辑与：多条件**同时满足**才通过
核心：所有条件全部成立，整体结果才为True
###### 场景1：表单/用户信息校验（最常用）
需求：用户注册，必须同时满足「用户名长度≥3」+「密码长度≥6」才能提交
```python
username = "xiaoming"
password = "123456"
# 两个条件同时成立才允许注册
can_register = len(username) >= 3 and len(password) >= 6
print(can_register) # True
```

###### 场景2：数值区间判断（数字同时大于下限、小于上限）
需求：判断分数是否为合格区间 [60, 100]
```python
score = 78
is_pass = score >= 60 and score <= 100
print(is_pass) # True
```

###### 场景3：权限双重校验
需求：只有「登录状态为True」**并且**「管理员身份」才能访问后台
```python
is_login = True
is_admin = True
can_manage = is_login and is_admin
```

##### 二、or 逻辑或：满足**任意一个**条件即可通过
核心：只要有一条条件成立，整体结果直接True
###### 场景1：多身份放行
需求：游客、会员、管理员任意一种身份，都能进入场馆
```python
identity = "member"
can_enter = identity == "visitor" or identity == "member" or identity == "admin"
```

###### 场景2：容错判断（满足其一就不用报错）
需求：文件后缀是jpg / png / gif，都判定为图片
```python
file_suffix = "png"
is_img = file_suffix == "jpg" or file_suffix == "png" or file_suffix == "gif"
```

###### 场景3：默认值兜底（or经典用法）
空字符串/0/None会被判定为假，`or` 自动取后面默认值
```python
name = ""
real_name = name or "匿名用户"
print(real_name) # 匿名用户
```

##### 三、not 逻辑非：条件取反，反向判断
核心：把True变False，False变True，用来写「不满足XX」的逻辑
###### 场景1：排除条件（禁止、不允许）
需求：未登录用户禁止访问页面
```python
is_login = False

需求：判断列表/字符串是否为空

data = []

```

###### 场景3：反向权限拦截
需求：不是管理员，就不能删除数据
```python
is_admin = False

##### 四、三者混合综合场景（真实业务逻辑）
###### 场景：游戏活动参与判定
规则：
1. 等级≥20 **并且** 背包有活动道具；
2. 或者 VIP玩家（不管等级）；
3. 但**不能**处于封禁状态

level = 25

final_result = can_join and not is_ban

```

### 11 模式匹配（match ... case ）
#### 1. 基础语法模板
```python
match 表达式:
    case 值1:
        操作1
    case 值2 if 条件表达式:
        # 同时满足：匹配值2 + 条件表达式成立
        操作2
    case 值3 | 值4:
        # 匹配值3 或者 值4 任意一个
        操作4
    case _:
        # 兜底分支，匹配所有其他情况（相当于else）
        默认操作
```
##### 语法分项说明
1. `case 值`：精准匹配表达式等于该固定值
2. `case 值 if 条件`：守卫模式，既要匹配固定值，还要满足附加条件才进入分支
3. `case a | b`：多值或匹配，多个值共用同一套执行逻辑
4. `case _`：通配兜底分支，匹配所有未命中的场景，必须写在所有case最后

#### 2. 适用场景区分
##### match...case 适用场景
适合**单个变量、多组固定值**的分支判断，代码结构比多层if-elif更整洁清晰。
例：运算符判断、菜单选项、固定状态码匹配。

##### if / elif 适用场景
适合包含**范围比较、多变量复杂组合逻辑**的判断。
例：分数区间划分、多条件且/或组合、数值大小对比。

#### 3. 核心注意要点
1. 版本要求：仅 Python 3.10 及以上版本支持 match-case 语法
2. 匹配顺序：从上至下依次匹配，命中第一条符合条件的case后直接结束匹配，不再向下执行
3. 守卫if：仅对当前case生效，不会干扰其他分支判断
4. 兜底分支：`case _` 可选，建议添加，防止未匹配场景无处理逻辑

#### 4. 实战示例（简易计算器）
```python
num1 = float(input("请输入第一个运算数："))
num2 = float(input("请输入第二个运算数："))
op = input("请输入运算符('+','-','*','/')：")
res = 0
op_flag = True

match op:
    case '+':
        res = num1 + num2
    case '-':
        res = num1 - num2
    case '*':
        res = num1 * num2
    case '/' if num2 != 0:
        res = num1 / num2
    case '/':
        print("除法运算，除数不能为0！")
        op_flag = False
    case _:
        print("无效运算符")
        op_flag = False

if op_flag:
    print(f"{num1} {op} {num2} = {res:.4f}")
```

### 12 while 循环
#### 一、两种语法结构
##### 基础版（无 else）
```python
# while语法结构
while 条件表达式:
    循环体语句1
    循环体语句2
    ...
```

##### 完整版（带 else）
```python
# while语法结构
while 条件表达式:
    循环体语句1
    循环体语句2
    ...
else:
    # 仅当条件为False、循环正常结束时执行
    收尾语句
```

#### 二、执行流程（流程图文字版）
1. 开始
2. 判断【条件表达式】
   - 结果为 `True`：执行循环体语句 → 回到第2步重新判断条件
   - 结果为 `False`：直接结束循环；若写了 `else`，会先执行 else 内代码再结束

#### 三、核心注意点
- while 循环依靠**条件表达式**控制是否继续下一轮循环；
- `else` 块触发规则：只有循环正常走完、条件变成False才会执行；
- 若循环内使用 `break` 强制跳出循环，`else` 代码**不会执行**。

#### 四、示例代码（方便理解else）
```python
i = 1
while i <= 3:
    print(f"循环第{i}次")
    i += 1
else:
    print("循环正常结束，执行else")
```
输出：
```
循环第1次
循环第2次
循环第3次
循环正常结束，执行else
```

##### 带 break 对比（else不触发）
```python
i = 1
while i <= 3:
    print(f"循环第{i}次")
    if i == 2:
        break
    i += 1
else:
    print("循环正常结束，执行else")
```
输出：
```
循环第1次
循环第2次
```

> 说明：break强制终止循环，else 不会运行。

### 13 for循环结构
#### 语法格式
```python
# for循环结构
for 元素 in 待处理数据集:
    循环体代码(对元素进行处理)
else:
    # 循环正常结束时，执行的代码（可选分支）
```

#### 细节说明
1. **核心循环逻辑**：会依次从`待处理数据集`里取出每一个`元素`，重复执行循环体代码，完成对每个元素的处理。
2. **else分支特性**：`else`是可选内容，**只有循环正常遍历完所有元素、没有被`break`强制中断**时，才会执行`else`内的代码；如果循环被`break`提前跳出，`else`部分不会运行。

#### 示例演示
```python
# 正常遍历，会触发else
for num in [1,2,3]:
    print(num)
else:
    print("循环正常遍历完毕")
```
输出：
```
1
2
3
循环正常遍历完毕
```

```python
# 被break中断，不会触发else
for num in [1,2,3]:
    if num == 2:
        break
    print(num)
else:
    print("循环正常遍历完毕")
```
输出：
```
1
```

#### 执行流程补充
1. 从待处理数据集取出第一个元素，执行循环体；
2. 依次后续取出元素重复循环体，直到数据集全部遍历完成；
3. 遍历无中断则执行`else`代码块，若中途触发`break`则直接终止、跳过`else`。
