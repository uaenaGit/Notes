## 3、文本使用
```text
- No need to be polite with LLM so there is no need to add phrases like “please”, “if you don’t mind”, “thank you”, “I would like to”, etc.,
- 和大语言模型交互不必讲客套话，无需使用“请”、“如果你不介意”、“谢谢”、“我想要”这类表达。

- Employ affirmative directives such as ‘do,’ while steering clear of negative language like ‘don’t’.
- 使用肯定式指令，例如“做某事”，避免使用“不要”这类否定表述。

- Add “I’m going to tip $xxx for a better solution!”4
- 加入句子：“我会给xxx美元小费，换取更好的回答！”

- Incorporate the following phrases: “You will be penalized”
- 加入这句话：“你将会受到惩罚”

- Add to your prompt the following phrase “Ensure that your answer is unbiased and avoids relying on stereotypes.”
- 在提示词中加入：“确保你的回答不带偏见，不要依赖刻板印象。”

- ……

```
✅ 适合：简单任务的**风格微调**，部分旧版开源模型效果明显。

❌ 不适合：不能提升底层推理能力，不能修复模型事实错误，对现在主流闭源大模型（豆包、GPT-4o 等）增益很小，部分句子甚至起反作用。

> 现在公认更靠谱的提示词思路：清晰任务定义 + 给出示例（Few-shot） + 分步思考（Chain-of-thought），远比小费、惩罚话术稳定。

**例子：**
❌ 按这套套路写：

> Write a summary of this article. I’m going to tip $200 for a better solution! You will be penalized. Ensure that your answer is unbiased and avoids relying on stereotypes.

✅ 现代更推荐的写法：

> Summarize the article in 3 concise paragraphs. Keep neutral, avoid stereotypes. Separate facts from opinions.
