# 李宏毅2024生成式AI作业写在哪里（自学版，不用提交台大）
> 原版作业是 **Google Colab（Jupyter Notebook `.ipynb` 文件）**，国内打不开，优先用【社区中文镜像仓库】，已经把API、交互全部适配国内环境。

仓库地址：`https://github.com/Hoper‑J/LLM‑Guide‑and‑Demos‑zh_CN`

有3种写作业的方案，按推荐优先级排序：

## 方案1：本地电脑写作业（最推荐，你有PyCharm）✅
把全部作业下载到自己电脑，本地运行，不需要翻墙。
1. 克隆仓库到本地
```bash
git clone https://github.com/Hoper-J/LLM-Guide-and-Demos-zh_CN.git
cd LLM‑Guide‑and‑Demos‑zh_CN
```
2. 创建conda虚拟环境，安装依赖
```bash
conda create -n genai‑hw python=3.11
conda activate genai‑hw
pip install -r requirements.txt
```
3. 两种打开notebook方式：
    - 方式A：命令行启动jupyter
    ```bash
    jupyter notebook
    ```
    浏览器弹出网页，直接点开`HW01/HW01.ipynb`，就可以写、修改、运行作业。
    - 方式B：**PyCharm专业版直接打开`.ipynb`文件**，直接在pycharm里面编辑、运行每一格代码，和你平时写代码体验一致。

> 💡注意：作业里面有`TODO`注释的地方，就是留给你填写修改的位置，替换成你自己的大模型API key（火山Ark / DeepSeek / GLM都可以）。

## 方案2：Kaggle云端在线跑（不想本地装环境）🌐
Kaggle国内可以直连，免费提供GPU，不用装Python环境。
1. 镜像仓库每个作业都提供Kaggle链接；
2. 点开链接，复制到自己Kaggle的笔记本，直接网页写代码运行；
> 适合HW5/HW10这种需要GPU的任务，缺点是每周GPU时长有限，超时会断开。

## 方案3：原版Google Colab（不推荐国内自学）❌
台大学生原版方案，需要特殊网络，默认调用OpenAI接口，国内直接跑会报错。

# 自学完整操作流程（照着做）
1. B站看完一节课视频；
2. 本地打开对应HW的`.ipynb`；
3. 找到文件内`TODO`，填入你的大模型API‑key；
4. 逐单元格运行代码，修改作业需要你完成的部分；
5. 运行看输出结果，**不需要上交任何人，自己看懂实验即可**。

### 关键提醒
1. 作业文件后缀是 `.ipynb`，不是普通py脚本，是Jupyter交互式笔记本，一格一格执行代码。
2. HW01‑HW04几乎**不需要GPU，只调用API**，你的本地电脑完全可以跑通。
3. HW5、HW10微调任务吃显卡，本地没有GPU就不要硬跑，看懂代码逻辑即可。

### 常见踩坑
> 报错：API调用失败
- 镜像作业已经把原版OpenAI调用改成兼容格式，你只需要填入国内大模型的`base_url`和`api_key`。
