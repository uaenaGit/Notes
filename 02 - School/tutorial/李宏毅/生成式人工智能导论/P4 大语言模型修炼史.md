# 模型训练
## 1、超参数（Hyperparameter）

### 定义

**超参数**是在模型训练开始前，由人工或调参程序设置的参数，用于控制：

- 模型的结构
- 模型的训练方式
- 模型的复杂度

> [!summary]  
> **模型参数是模型从数据中学到的结果；超参数是规定模型如何学习的设置。**

### 参数与超参数的区别

|对比项|模型参数（Parameter）|超参数（Hyperparameter）|
|---|---|---|
|设置方式|训练过程中自动学习|训练前人工设置或自动搜索|
|是否由优化器直接更新|是|通常不是|
|主要作用|表达模型学到的规律|控制模型结构和训练过程|
|常见例子|权重、偏置|学习率、批次大小、网络层数|

### 常见超参数

#### 学习率（Learning Rate）

控制每次更新模型参数时的步长。

- 学习率过大：训练可能不稳定，甚至无法收敛
- 学习率过小：训练速度慢，可能停留在较差的结果

```
learning_rate = 0.001
```

#### 批次大小（Batch Size）

控制每次参数更新使用的训练样本数量。

- 批次较大：计算更稳定，但占用更多显存
- 批次较小：更新噪声更大，但有时泛化能力更好

```
batch_size = 32
```

#### 训练轮数（Epoch）

一个 Epoch 表示模型完整学习一次训练集。

- 轮数过少：可能导致欠拟合
- 轮数过多：可能导致过拟合

```
epochs = 20
```

#### 模型结构

常见的结构超参数包括：

- 网络层数
- 每层神经元数量
- 隐藏层维度
- 注意力头数量
- 卷积核大小

#### 正则化参数

用于限制模型复杂度、减少过拟合。

```
weight_decay = 0.01
dropout = 0.2
```

#### 不同算法中的超参数

|算法|常见超参数|
|---|---|
|决策树|最大深度 `max_depth`|
|随机森林|决策树数量 `n_estimators`|
|KNN|邻居数量 `k`|
|SVM|惩罚系数 `C`、核函数参数|
|神经网络|学习率、层数、隐藏层维度、Dropout|
|大语言模型|层数、隐藏维度、注意力头数、上下文长度|

### 为什么叫“超”参数

这里的“超”不是“超级”的意思，而是表示它位于普通模型参数的上一层：

- **模型参数**决定模型如何根据输入产生输出
- **超参数**决定模型采用什么结构，以及参数如何被学习

### 数学表示

在给定超参数 $\lambda$ 后，通过训练得到模型参数：

$$\theta^*(\lambda) = \arg\min_\theta L_{\text{train}}(\theta;\lambda) $$

其中：

- $\theta$：模型参数
- $\lambda$：超参数
- $L_{\text{train}}$：训练集损失函数

再通过验证集选择效果最好的超参数：

$$\lambda^* = \arg\min_\lambda L_{\text{validation}}(\theta^*(\lambda)) $$

因此，模型训练可以理解为两层优化：

1. 固定超参数，训练模型参数
2. 比较不同超参数，选择验证集表现最好的配置

### 超参数的选择方法

- **人工调参**：根据经验逐步尝试
- **网格搜索（Grid Search）**：穷举预先设定的参数组合
- **随机搜索（Random Search）**：从指定范围内随机抽取组合
- **贝叶斯优化（Bayesian Optimization）**：根据已有结果选择下一组参数
- **Hyperband / Successive Halving**：提前停止效果较差的实验，将资源分配给更有潜力的配置

### 数据集的作用

```
训练集 → 学习模型参数
验证集 → 选择超参数
测试集 → 最终评估模型
```

> [!warning]  
> 不应根据测试集结果反复调整超参数，否则会造成测试集信息泄漏，使最终评估结果不再可靠。

### 示例

```
learning_rate = 0.001
batch_size = 64
epochs = 30
hidden_size = 256
dropout = 0.2
```

以上都是超参数。训练过程中由优化器自动更新的权重和偏置，则属于模型参数。

### 注意事项

某个量是否属于超参数，取决于它的确定方式：

- 如果由训练算法直接学习，它是**模型参数**
- 如果由人工或外层搜索程序指定，它是**超参数**

### 核心总结

> [!tip]  
> **参数是模型学到了什么，超参数是模型应该怎么学。**

## Saliency Map（显著性图）
> 笔记用途：深度学习 / 计算机视觉，模型可解释性
> 核心一句话：**显著性图用来可视化图像中哪些像素对模型最终预测结果贡献最大**。简单说就是找出图片里模型“重点关注”的区域。

### 1. 基本概念
- Saliency：显著性，代表像素的重要程度。
- Saliency Map：一张和输入图像尺寸相同的灰度/热力图。
  - 亮（红）色区域：**该像素变化会显著影响模型输出**，是模型判断类别时最关心的地方。
  - 暗（蓝）色区域：像素改动几乎不影响预测，模型不关注。

> ⚠️ 区分两个容易混淆的概念
> - **Saliency Map（基于梯度）**：对输入图像求梯度，看输出对输入像素的敏感度。属于**模型可解释性方法**。
> - **传统显著性检测（Saliency Detection）**：计算机视觉任务，直接从图片本身找人眼感兴趣区域，不需要神经网络。

### 2. 原理（最原始 Vanilla Saliency）
出自论文：*Deep Inside Convolutional Networks: Visualising Image Classification Models and Saliency Maps*（2013）

设：
- $x$：输入图像
- $y_c$：模型对类别 $c$ 的输出得分（logit，softmax前的值）

显著性值 = 损失/类别得分对输入图像像素的梯度：
$$
S(x) = \frac{\partial y_c}{\partial x}
$$

理解：
1. 输入一张图片，前向传播得到类别分数。
2. 反向传播，**不对权重求导，而是对输入图像像素求导**。
3. 取梯度绝对值，reshape成原图大小，就是显著性图。
4. 梯度绝对值越大，代表改动这个像素，类别得分变化越大 → 像素越重要。

### 3. 常见变种（拓展）
1. **Vanilla Saliency（原始梯度）**
    直接 $\partial y_c/\partial x$。缺点：梯度容易饱和、有噪声，会出现梯度消失/爆炸，有时不可靠。
2. **SmoothGrad**
    多次给原图加微小高斯噪声，多次计算显著性图，最后取平均。**降噪，可视化效果更干净**，工程最常用。
3. **Guided Backpropagation**
    修改反向传播时ReLU的梯度，只保留正向激活的梯度，可视化边缘细节更强。
4. **Grad-CAM**
    不是对输入求梯度，是对**最后一层卷积特征图**求梯度，得到类激活热力图。
> 对比：Saliency是像素级细粒度；Grad-CAM是区域级粗粒度。

### 4. 能做什么 & 局限性
✅ 用途
- 模型可解释性：查看CNN是不是真的学到目标物体，而不是依赖背景噪声。
- 调试模型：检查模型是否存在shortcut（走捷径，靠无关背景判断）。
- 论文可视化，展示模型注意力。

❌ 缺点
1. **梯度欺骗问题**：梯度显著性图不一定总是可靠，模型可以产生虚假显著性。
2. 高度依赖模型本身，同一张图换模型，显著性图差异很大。
3. 只反映**敏感度**，不等于模型“学到的语义”。
> 重点：**敏感度 ≠ 因果重要性**。

### 5. 极简伪代码（PyTorch）
```python
# Vanilla Saliency 核心逻辑
model.eval()
x.requires_grad = True # 输入图像开启梯度
logits = model(x)
score = logits[0, target_class] # 目标类得分

score.backward() # 反向传播，对输入x求导
saliency = x.grad.abs().max(dim=1)[0] # 取梯度绝对值，RGB三通道取最大值
```

### 6. 对比小结（方便记忆）
|方法|对象|粒度|特点|
|---|---|---|---|
|Vanilla Saliency|输入图像|像素级|原始梯度，噪声大|
|SmoothGrad|输入图像|像素级|多次加噪平均，效果稳定|
|Grad-CAM|最后卷积特征|区域级|物体轮廓清晰，最常用|
