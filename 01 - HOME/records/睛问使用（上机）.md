总体原则：
- 训练营整体使用：**语言入门精选** + **模版原型精选** + **重点难点特训**。
- 模拟赛都要参加。
- 一眼就会的题，直接看题解思路，思路相同则可以跳过。

level1 : 语言相关
level2 : 模拟、数组、算法、搜索、dp、树图（概率低）、链表（概率最低）
level3 : 在level2的基础上强化了

tips:
- `cin/cout` 和 `scanf/printf`函数不要混用，推荐`scanf/printf`
- 关注数据范围：
1. $N$ 较小（$N ≤ 20$）
	- 使用回溯（`Backtracking`）、暴力搜索等时间复杂度相对较高（比如$2^N$ 或 $N!$）的算法
	- 侧重考察对搜索剪枝、记忆化搜索等技巧的掌握。
2. $N$ 中等（如几十到几百）
	- 关注算法能否在$O(N^3)$、$O(N^2 logN)$ 或更优的复杂度运行。
	- 常见算法包括`Floyd`、`DP`、一些基于矩阵的算法等。$N$ 如果大约在$100\sim300$的量级，`Floyd`($O(N^3)$)，$O(N^2logN)$ 以及一般的二重循环甚至三重循环都有可能在可接受的时间内完成。
> 当 `N ≤ 20` 暴力还有`next_permutation`函数，用于`O(n!)`暴力

3. $N$ 较大
	- 关注是否在$O(NlogN)$ 或更优下完成
	- 排序、二分、树状数组（`Fenwick Tree`）、各类图算法（如`Dijkstra`的堆优化版）等都是典型的$O(NlogN)$ 或 $O((N + M)logN)$。
	- 如果数据范围更大（达到百万量级），往往需要$O(N)$ 或近似$O(N)$的算法，比如单词扫描、双指针、栈相关算法的部分操作等。
- **不要忽略内存限制**
    - 当 $N$ 和 $M$ 都很大时，存储一个邻接矩阵需要  空间，如果 $N=10^5$ 就肯定不行。要用邻接表等更节省空间的方式。
    - 同时，注意大数组或递归深度可能导致**内存不足或栈溢出**，必要时需要将递归改为迭代实现。
