### 🚀 1. 最核心的“救命”快捷键 (必背)
| 功能         | Windows / Linux        | Mac                      | 说明                                           |
| :--------- | :--------------------- | :----------------------- | :------------------------------------------- |
| **命令面板**   | `Ctrl` + `Shift` + `P` | `Cmd` + `Shift` + `P`    | 万能键。找不到功能时按它，输入关键词（如 "Format", "Theme"）即可执行。 |
| **快速打开文件** | `Ctrl` + `P`           | `Cmd` + `P`              | 模糊搜索文件名，快速跳转。                                |

### ✍️ 2. 编辑与多光标神技 (提升手速)
这是 VS Code 最强大的地方，学会多光标编辑，效率翻倍。

| 功能           | Windows / Linux         | Mac                        | 说明                                          |
| :----------- | :---------------------- | :------------------------- | :------------------------------------------ |
| **向上/下复制行**  | `Shift` + `Alt` + `↓/↑` | `Shift` + `Option` + `↓/↑` | 快速复制当前行到下方或上方。                              |
| **向上/下移动行**  | `Alt` + `↓/↑`           | `Option` + `↓/↑`           | 不复制，直接交换当前行位置。                              |
| **删除当前行**    | `Ctrl` + `Shift` + `K`  | `Cmd` + `Shift` + `K`      | 直接删掉整行，无需选中。                                |
| **添加下一个匹配项** | `Ctrl` + `D`            | `Cmd` + `D`                | **神器**。选中一个词，再按一次会选中下一个相同的词，可连续按，实现多光标同时编辑。 |

| 多光标点击        | `Alt` + `Click`         | `Option` + `Click`         | 鼠标按住 Alt 点击多处，生成多个光标。                       |
| 列选择模式        | `Shift` + `Alt` + `拖拽`  | `Shift` + `Option` + `拖拽`  | 垂直框选一块区域进行编辑。                               |
| 行尾插入光标       | `Shift` + `Alt` + `I`   | `Shift` + `Option` + `I`   | 选中多行后按此键，会在每一行的末尾都加上一个光标（适合批量加分号或逗号）。       |
| 切换代码自动换行     | `Alt + Z`               | `Option + Z`               | 临时开启/关闭长行视觉自动换行，仅当前文件生效                     |

## Mac 补充：终端、Python 与 Notebook

Mac 键名：`Cmd` = Command ⌘，`Ctrl` = Control ⌃，`Option` = ⌥，`Shift` = ⇧。以下使用默认键位；安装键位映射扩展或自定义后，以键盘快捷方式页面为准。

| 功能 | Windows | Mac |
| --- | --- | --- |
| 运行生成任务（不是直接运行 Python） | Ctrl + Shift + B | Cmd + Shift + B |
| 跳转到指定行 | Ctrl + G | Ctrl + G |
| 显示／隐藏终端 | Ctrl + 反引号 | Ctrl + 反引号 |
| 新建终端 | Ctrl + Shift + 反引号 | Ctrl + Shift + 反引号 |
| 显示／隐藏底部面板 | Ctrl + J | Cmd + J |
| 打开扩展面板 | Ctrl + Shift + X | Cmd + Shift + X |
| 打开设置 | Ctrl + , | Cmd + , |
| 打开键盘快捷方式 | 先 Ctrl + K，再 Ctrl + S | 先 Cmd + K，再 Cmd + S |
| 保存文件 | Ctrl + S | Cmd + S |
| Notebook 运行单元并移到下一格 | Shift + Enter | Shift + Enter |
| Notebook 运行单元并停在当前格 | Ctrl + Enter | Ctrl + Enter |
| 终端中中断当前程序 | Ctrl + C | Ctrl + C |

反引号是 `` ` ``，不是单引号 `'`，在常见键盘上与 `~` 共用一个键。终端里的 `Ctrl + C` 用于中断程序；Mac 复制文本用 `Cmd + C`。

### 当前 D2L 项目的环境选择

- `.ipynb`：点击编辑区域右上角“选择内核”，选 `Python (d2l)`。用单元左侧 ▶ 或 `Shift + Enter` 运行。
- `.py`：按 `Cmd + Shift + P`，执行 `Python: Select Interpreter`，选择 `/Users/yangyu/miniconda3/envs/d2l/bin/python`；在编辑区右键选择“在终端中运行 Python 文件”。
- 已经打开的终端需要时手动执行 `conda activate d2l`。Notebook 内核、编辑器解释器和终端激活环境是不同设置，分别检查。
- `Run Code` 属于 Code Runner 扩展，可能使用自己的执行器配置；它不等同于 Python 扩展的“在终端中运行 Python 文件”。
- 核对实际运行环境：`import sys; print(sys.executable)`。

功能键 F1–F12 如果触发亮度、音量等系统功能，需要配合 `Fn`，或在系统设置中调整功能键行为。`Ctrl + Space` 可能与输入法切换冲突，可在 VS Code 键盘快捷方式或 macOS 输入法快捷键中调整。
