## Mac 快捷键对照

使用 Obsidian 桌面版默认键位；插件命令和自定义键位请在“设置 → 快捷键”中核对。

| 功能            | Windows          | Mac                |
| ------------- | ---------------- | ------------------ |
| 切换编辑视图／阅读视图   | Ctrl + E         | Cmd + E            |
| 打开开发者工具       | Ctrl + Shift + I | Cmd + Option + I   |
| 粘贴纯文本         | Ctrl + Shift + V | Cmd + Shift + V    |
| 打开命令面板        | Ctrl + P         | Cmd + P            |
| 快速切换笔记        | Ctrl + O         | Cmd + O            |
| 新建笔记          | Ctrl + N         | Cmd + N            |
| 查找当前笔记        | Ctrl + F         | Cmd + F            |
| 搜索整个仓库        | Ctrl + Shift + F | Cmd + Shift + F    |
| 打开设置          | Ctrl + ,         | Cmd + ,            |
| 加粗            | Ctrl + B         | Cmd + B            |
| 斜体            | Ctrl + I         | Cmd + I            |
| 插入链接          | Ctrl + K         | Cmd + K            |
| 撤销            | Ctrl + Z         | Cmd + Z            |
| 关闭当前标签页       | Ctrl + W         | Cmd + W            |
| 打开系统 Emoji 面板 | Win + .          | Ctrl + Cmd + Space |

`Cmd + E` 切换编辑和阅读视图；编辑视图内部的“实时预览／源码模式”是另一项设置，可通过命令面板搜索“源码模式”相关命令，或在“设置 → 编辑器”中调整。原笔记里的“源代码模式和阅读模式”应按这个区别理解。
