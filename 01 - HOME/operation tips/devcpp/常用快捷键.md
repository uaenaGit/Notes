## Mac 使用说明与替代操作

常见的 Dev-C++ 发行版面向 Windows，没有对应的官方原生 macOS 默认键位。原有记录保留用于 Windows；Mac 可以使用 VS Code 编写 C/C++，下表仅表示编辑动作的替代键位。

| 操作 | 原 Dev-C++ Windows 记录 | VS Code（Mac 默认） |
| --- | --- | --- |
| 复制当前行到相邻行 | Ctrl + E | Shift + Option + ↓ / ↑ |
| 删除当前行 | Ctrl + D | Cmd + Shift + K |
| 格式化文档 | Ctrl + Shift + A | Shift + Option + F |

VS Code 的 C/C++ 格式化需要相应扩展／格式化器；编译运行还需要另外配置编译器和任务。以上编辑快捷键不代表已经配置好编译环境。
