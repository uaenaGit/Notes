```
Ctrl + Shift + ESC : 打开任务管理器
```

## 对应的 Mac 操作

| 目的 | Windows | Mac |
| --- | --- | --- |
| 结束无响应的应用 | Ctrl + Shift + Esc 打开任务管理器 | Cmd + Option + Esc 打开“强制退出应用程序” |
| 查看 CPU、内存、进程占用 | 任务管理器 | Cmd + Space 搜索“活动监视器”并回车 |

“强制退出”与完整的任务管理器功能不同；查看资源占用应使用“活动监视器”。更多操作见 [[macOS/常用快捷键]]。
