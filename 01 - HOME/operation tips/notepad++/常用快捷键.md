## Mac 使用说明与替代操作

Notepad++ 没有官方原生 macOS 版，因此没有可直接套用的 Mac 默认快捷键。下面记录的是 Mac 上 **VS Code** 的替代操作；通过兼容层运行 Windows 版时，键位取决于兼容层映射。

| 操作           | Notepad++（Windows 默认）            | VS Code（Mac 默认）              |
| ------------ | -------------------------------- | ---------------------------- |
| 从光标选中到文档开头   | Ctrl + Shift + Home              | Cmd + Shift + ↑              |
| 删除光标到文档开头的文本 | Ctrl + Shift + Home，再按 Backspace | Cmd + Shift + ↑，再按 Delete    |
| 删除当前行        | Ctrl + Shift + L                 | Cmd + Shift + K              |
| 剪切当前行        | Ctrl + L                         | 未选中文本时 Cmd + X（默认启用空选区复制／剪切） |
|              |                                  |                              |

纠正原记录：`Ctrl + Shift + Home` 只负责选中，不直接删除；Notepad++ 的 `Ctrl + L` 是剪切当前行，会改写剪贴板。
