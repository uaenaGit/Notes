# macOS 常用快捷键

键名：`Cmd` = Command ⌘；`Ctrl` = Control ⌃；`Option` = Alt ⌥；`Shift` = ⇧。不能把所有 Windows 的 Ctrl 都替换成 Cmd，例如终端中断程序和 VS Code 显示终端仍使用 Ctrl。

以下按 macOS 默认键位；应用、自定义设置和键盘布局可能覆盖快捷键。功能键触发亮度、音量时，可配合 Fn 使用。

## 常用操作

| 操作         | Windows                    | Mac                    |
| ---------- | -------------------------- | ---------------------- |
| 复制／剪切／粘贴文本 | Ctrl + C / X / V           | Cmd + C / X / V        |
| 全选         | Ctrl + A                   | Cmd + A                |
| 撤销         | Ctrl + Z                   | Cmd + Z                |
| 重做         | 常见为 Ctrl + Y               | 常见为 Cmd + Shift + Z    |
| 保存         | Ctrl + S                   | Cmd + S                |
| 当前内容查找     | Ctrl + F                   | Cmd + F                |
| 切换应用       | Alt + Tab                  | Cmd + Tab              |
| 同一应用的窗口间切换 | 因应用而异                      | Cmd + 反引号              |
| 关闭当前窗口／标签  | Alt + F4（窗口）/ Ctrl + W（标签） | Cmd + W                |
| 退出整个应用     | 常用 Alt + F4 关闭窗口           | Cmd + Q                |
| 隐藏当前应用     | 因应用而异                      | Cmd + H                |
| 最小化当前窗口    | Win + ↓（取决于窗口状态）           | Cmd + M                |
| 搜索应用／文件    | Win 键后输入搜索                 | Cmd + Space（Spotlight） |
| 强制退出无响应应用  | 通过任务管理器                    | Cmd + Option + Esc     |
| 锁屏         | Win + L                    | Ctrl + Cmd + Q         |
| Emoji／字符面板 | Win + .                    | Ctrl + Cmd + Space     |

关闭 Mac 应用窗口不一定退出应用；退出整个应用使用 Cmd + Q。

## 截图与 Finder

| 操作 | Mac |
| --- | --- |
| 截取整个屏幕 | Cmd + Shift + 3 |
| 截取选定区域 | Cmd + Shift + 4 |
| 截取窗口 | Cmd + Shift + 4，再按 Space，再点击窗口 |
| 打开截图／录屏工具栏 | Cmd + Shift + 5 |
| 截图直接复制到剪贴板 | 在 Cmd + Shift + 3 / 4 基础上加 Ctrl |
| Finder 前往指定文件夹 | Cmd + Shift + G |
| Finder 显示／隐藏隐藏文件 | Cmd + Shift + . |
| Finder 新建文件夹 | Cmd + Shift + N |
| Finder 重命名选中项 | Return（回车） |
| Finder 快速预览选中文件 | Space |
| Finder 打开选中文件 | Cmd + O |
| Finder 移到废纸篓 | Cmd + Delete |
| Finder 复制文件 | Cmd + C，然后 Cmd + V |
| Finder 移动文件 | Cmd + C，然后 Cmd + Option + V |

Finder 移动文件使用“复制后移动”，不是对文件按 Cmd + X。

## 文本与终端

| 操作 | Mac |
| --- | --- |
| 到行首／行尾（常见文本编辑器） | Cmd + ← / → |
| 到文档开头／结尾（常见文本编辑器） | Cmd + ↑ / ↓ |
| 按词移动 | Option + ← / → |
| 扩展选区 | 在相应移动组合键上加 Shift |
| 向前删除一个字符 | Fn + Delete |
| 终端中断当前程序 | Ctrl + C |
| 终端清屏（常见 shell） | Ctrl + L |
| 查看历史命令 | ↑ / ↓ |
| VS Code 显示／隐藏终端 | Ctrl + 反引号 |
| VS Code 新建终端 | Ctrl + Shift + 反引号 |

macOS 的 Terminal 应用没有通用默认的“全局打开终端”快捷键。可以按 Cmd + Space 搜索“终端”，再按回车；上表的终端显示快捷键仅适用于 VS Code。
