# 一、完善你的三大物料板块+新增正规粉丝群必备模块
你原有：影视作品集、综艺采访合集、写真图片集，我帮你细分优化，再加4个刚需板块，群整体专业规整，适合佛系正规同担群「珮瑶小筑」

1. 电视剧合集
按上映年份排序：剧名+播出平台+饰演角色+角色简介+经典片段/出圈台词、追剧看点
细分：已播完结剧、正在热播剧、待拍/待官宣剧集
2. 电影/短片/微电影
院线电影、文艺短片、公益短片，标注上映时间、人物、剧情亮点
3. 角色台词合集
整理张海琪等高人气角色走心台词、采访里她聊演戏的感悟
4. 追剧讨论索引
每部剧单独标注，方便大家分话题聊，避免刷屏混乱

## 板块2：综艺&线下活动合集

2. 活动高清图：红毯、路演精修图、官方出图站姐合规产出

✅ 只用**简短文本+在线文档/网盘链接**，不放大段文字、压缩包、图片

⚠️ 禁止事项：私生、引战、广告、商用物料传播
新人先点开链接看完基础内容再发言~

### 为什么不直接放长篇文本/图片？
群公告有字数上限，长内容会折叠；图片、压缩包无法长期存公告，更换内容要反复编辑，用链接一键跳转，随时更新无需改公告。

## 2. 群文件（微信群自带存储）
✅ 适合存放**可下载备份类文件**，作为在线链接的备用存档，不做主力查阅渠道
1. 表格：Excel版姜珮瑶完整作品年表、综艺时间线
2. 文档：在线文档导出的PDF备份（防止链接失效）
3. 小体积视频：采访高光cut、短视频片段
4. 小型图片压缩包：精选壁纸、剧照小合集

❌ 不适合：超大高清图包、几十G视频全集（微信群存储空间很小，容易爆满）
大图库、完整视频全部放网盘，网盘链接放进在线文档里。

## 3. 主力物料载体：在线文档+网盘链接（最推荐）
### 文字类（作品表、采访、台词、群规）→ 腾讯文档/飞书文档
优势：多人可查看、随时编辑更新、分目录清晰，手机点开直接浏览，不用下载
### 图片/视频大物料（写真、完整综艺、高清剧照）→ 阿里云盘/百度网盘
优势：存储空间无压力，按文件夹细分图集、视频，永久留存，分类清晰
